## 现行口径摘要（唯一保留）

现行口径：经营实体的资产与业务数据统一归 Global，区域只负责空间与现场引用；每人两账户（个人钱包 + 经营者唯一经营账户），雇佣走独立合同、合同绑经营实体；存档只写 Global 事实（Time / Economy / BusinessEntities / Employments / Leases / PlayerProfile）与 Scene 空间 / 名册 / 物品 / 现场队列，派生状态不入档；`bOperating` 为 `bOpen && 营业时段` 纯派生，人工开业只校验业态必需设施、运行期缺设施不系统关店；允许扣负的费用白名单仅贷款月供 / 工资 / 租金三项；打烊分流——店内已锁价预留 / 收银台工作点队列 / 结账继续完成，店外未进店门口队列清退并只记一次“白跑一趟”负满意度样本；经营实体 + 区域 + 必要合同由玩家在同一建造面板一次创建；V1 边界为单商圈、单玩家店、固定名册，不开放 NPC 招商模板 / 旅店 / 住宿，不含公共维护费与长椅。
