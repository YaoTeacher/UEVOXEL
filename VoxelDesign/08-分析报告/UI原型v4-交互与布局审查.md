# UI 原型 v4 交互与布局审查（纯 UX 视角）

| 项目 | 内容 |
|------|------|
| 审查对象 | voxel-ui-v4.html（1280×700 原型，经营/建造/探索三模式） |
| 审查范围 | **仅布局与交互逻辑**：屏幕分区、组件几何、跨模式一致性、操作流程。组件内部内容视为可替换，不审查 |
| 不审查 | 代码实现、数据模型（另行审查） |
| 参考 | BG3、神界原罪2、RimWorld、双点博物馆、天际线、CK3、风花雪月 |
| 日期 | 2026-08-11 |

---

## 0. 一句话结论

v4 的**内容设计**（区域面包屑、认识度、3D 确认浮标、工具模块化）是好的，但**容器设计**不合格：功能与信息没有按"归属层"分类，同一槽位在不同模式下几何位置和内容双双跳变，操作流的空间顺序与决策顺序错位。玩家每切一次模式都要重新学习屏幕。

修复方向不是重排内容，而是先定一套**"壳-槽"契约**：壳（槽位几何与行为）全模式锁死，瓤（槽位内容）按模式替换。

---

## 1. 现状盘点：屏幕分区与跨模式差异矩阵

v4 实际使用了 9 个屏幕区域。把三模式并排列出，问题一目了然：

| # | 区域 | 经营 | 建造 | 探索 | 跨模式一致性 |
|---|------|------|------|------|-------------|
| 1 | 左上 | 520px 经营 Grid（双TAB+数据+功能+建造入口） | **同经营**（仅换退出按钮） | 探索功能图标组 | ✗ 三种内容、两种宽度 |
| 2 | 左中 | — | — | 队伍竖条 top:110 | ✗ 仅探索存在 |
| 3 | 左下 Inspector | 选中卡 bottom:**12** | 选中卡 bottom:12 | 角色卡 bottom:**156** | ✗ 同组件底距跳变 |
| 4 | 顶中 | — | — | 回合条（常驻） | ✗ 仅探索存在 |
| 5 | 右上 | 面包屑+时间倍速+双滑杆+小地图+图层 | 同左 | 同左（无倍速，面包屑变纯文字） | ◐ 位置对，但交互深度跳变（面包屑可点→不可点） |
| 6 | 底部 | **空** | 三件套：工具条480px + 库600px + 参数260×180 | 150px 全宽行动条 | ✗ 无/有/全宽三种形态 |
| 7 | 顶部右角 | 设置齿轮 | 同 | 同 | ✓ 唯一全模式不变的元素 |
| 8 | 中央弹层 | 全屏功能页/对话框/业务弹窗 | 同 | 同 | ◐ 容器复用但语义混乱（见 §4.4） |
| 9 | 3D 场景浮标 | — | 确认/取消随实体 | — | — |

**唯二做到跨模式稳定的：设置齿轮和右上小地图列**（而设置齿轮还和小地图列分属两处）。这正是"切模式像换了个游戏"的直接原因。

## 2. 问题 A：功能与信息没有按"归属"分类

v4 里所有 UI 元素其实只属于四个归属层，但它们被随意撒在各处：

| 归属层 | 定义 | v4 中的成员 | 当前位置问题 |
|--------|------|------------|-------------|
| **世界层** | 关于"我在哪、什么时间、怎么看待这个世界" | 地图名/坐标、面包屑、小地图、时间/天气/倍速、切面/镜高滑杆、渲染图层、透视框列表 | 基本集中在右上 ✓，但倍速在探索模式消失、面包屑在探索模式变纯文字——同槽位交互深度跳变 |
| **模式层** | 当前模式的主操作 | 经营功能图标、建造工具/库/参数、探索技能/回合 | 散落在左上、左中、底部、顶中四个方向 |
| **实体层** | 关于"被选中的那个东西" | 角色卡、区域卡、选区信息（M5） | 左下卡 + 建造参数面板里的 M5 两处，且选中语义不统一（点区域=实体选中，画框=体素选中，可同时在场） |
| **系统层** | 与游戏世界无关的元操作 | 设置、ESC/暂停、保存 | 只有右上角一个齿轮，暂停/保存无入口 |

**分类原则建议**（也是 §5 槽位设计的依据）：

1. **世界层 → 顶部与右上角**：只看不动手的 glanceable 信息，贴屏幕边缘。
2. **模式层 → 底部**：手的主操作区，贴近视野下缘（BG3/天际线/RimWorld/双点全部如此，无例外）。
3. **实体层 → 右侧固定单槽**："选中"是跨模式概念（人选、区域选、体素选），容器必须唯一且位置固定。
4. **系统层 → 右上角聚合**：设置/保存/暂停收进一个系统菜单或 ESC 菜单，不单独占屏。

v4 把模式层（经营功能）放左上、实体层放左下、系统层只有齿轮——三个层都没落在参考游戏的共识位置上。

## 3. 问题 B：跨模式一致性的六处硬跳变

按"玩家肌肉记忆"排序，从最刺痛到最轻：

### B1 底部：无 → 三件套 → 全宽条，三种形态三种高度
- 经营：底部完全空（主操作在左上，违反"操作在底部"共识）
- 建造：居中工具条 480px（bottom:10）+ 库 600px（bottom:51）+ 参数 260px（bottom:56，右下）——**三个底边三个值，基线不齐**
- 探索：150px 全宽行动条
- 后果：玩家视线下缘的"操作带"位置每模式都要重定位。

### B2 实体卡底距：12px ↔ 156px 跳变
同一张卡在经营/建造贴底、在探索抬高 156px 避让行动条。卡片还和左中队伍条（top:110）、行动条内头像形成"角色信息三角"。

### B3 模式层入口方位分裂
经营功能在左上、建造工具在底中、探索功能在左上+行动条右端没有（回合条在顶中）。三个模式的主操作区方位各不相同。参考游戏里这一层**永远在底部**：BG3 行动条、天际线服务条、RimWorld Architect 栏、双点建造栏。

### B4 右上世界层交互深度跳变
面包屑在经营可点击定位、在探索变纯文字；倍速在探索直接消失。同位置组件的"可交互性"应按模式**降级**（变灰）而非**消失/变性**——消失让玩家怀疑"是不是这个功能没有了"。

### B5 模式切换入口三个方位
进建造=左上按钮；进探索=点小地图→全屏地图选择；退出建造=左上另一个按钮。且"点小地图切探索"混淆了两个概念：**看地图**（世界层动作）与**旅行/换场景**（模式层动作）。BG3 点小地图=开大地图查看，旅行是地图里的目的地点——两个动作两层界面。

### B6 探索模式内部还有一个未表达的状态分裂
一进探索就常驻回合条+AP 行动条 = 永远战斗中。战棋常识是**自由探索（即时）/回合遭遇（战棋）两个子态**：自由态无回合条、底部是功能条；遭遇态才有回合条与 AP。两个子态的切换就是 BG3 的"进入战斗"镜头语言。v4 把两个子态的 HUD 混为一屏。

## 4. 问题 C：操作流程与通用常识的冲突

### C1 建造流：决策顺序与空间顺序错位（核心痛点）

玩家的决策顺序是线性的：**选工具 → 选材料 → 画范围 → 调参数 → 确认**。

v4 的空间布局却是 Z 字形动线：

```
底部中央[工具条] → 上方[库] → 世界[画] → 右下[参数] → 世界边缘[3D确认浮标]
   眼手路径：下→上→中→右下→中    （五次大跳）
```

且库"按需出现"（有库工具才显示），出现时把工具条上方 160px 的世界视野遮掉——版面随工具类型伸缩，玩家无法预判。

**通用做法**（天际线/双点/RimWorld 一致）：操作序列=空间序列，沿底部一条带从左到右（或从右到左）排布决策顺序；参数是选中工具后的**就地展开**（天际线子面板向上弹），确认双通道（场景内浮标 + 底带按钮，互为冗余）。

### C2 查看流：选中→卡→按钮→全屏页，三级跳太深

点对象 → 左下弹卡 → 点卡上 24px 图标（无文字）→ 80% 屏全屏页。看一个营业时间要盖掉整个世界。

RimWorld/双点的常识：选中→**侧栏就地显示详情与常用操作**，只有真正复杂的编辑（技能树、排班表）才进大弹层。应分三级：

| 级别 | 内容示例 | 容器 |
|------|---------|------|
| 内联 | 营业开关、资金概览、员工在岗数 | 选中卡内 |
| 抽屉 | 营业时间、员工排班、库存 | 右侧半屏抽屉（世界仍可见） |
| 全屏 | 技能树、势力关系图、大地图 | 全屏页 |

### C3 模式切换流：入口方位与对称性

通用常识：**入口与出口同位**（开门和关门是同一个把手）。v4 进/出建造同位 ✓（左上按钮互换），但进探索（小地图）与回经营（地图选择器）不同位。三模式应有一个**固定位置的段控切换器**（经营|建造|探索），当前模式高亮，一次点击直达——CK3 地图模式组、双点速度段控都是这个形态。

### C4 弹层语义混乱

- **NPC 对话框**（紫色、底部 72% 宽）被复用为**区域业务数据表单**——叙事容器装系统表单，玩家预期错位。
- 全屏功能页、对话框、3D 浮标、库抽屉、图层弹出、面包屑下拉、选中卡——**7 种可关对象，无 ESC 优先级**。常识：ESC 逐层关闭，从最浮面吃到最底层（BG3/RimWorld 铁律）。
- 确认语义分裂：建造确认在 3D 浮标，区域确认在弹窗，对话框选项在底部——同类动作（确认一个决定）应至少有统一的主按钮形态与位置规律。

### C5 "选中"语义二元冲突

点区域（实体选中→左下卡）与画框（体素选中→M5 信息）在建造模式可同时在场，两个"选中"互不知道对方。RimWorld 铁律：**任意时刻全局只有一个选中**——点建筑开建筑卡、框选出操作条，互斥。选中模型统一是减少适应成本的前提：一个槽位、一种高亮语言、ESC/点空白清除。

## 5. 设计框架：六槽位壳层（"壳不动，瓤浮动"）

### 5.1 两条总原则

1. **世界始终全屏垫底，所有 UI 都是浮层**——面板显隐永远不引起世界重新排版。
2. **常驻槽位几何锁死，临时内容作为槽位的浮动上层**——浮动层（库、抽屉、弹窗）的出现/消失不改变任何常驻槽位的位置。

### 5.2 槽位契约（1280×700 基准）

```
┌────────────────────────────────────────────────────────┐
│ T 顶条 h36：左=位置面包屑 │ 中=情境章 │ 右=时间/资源/系统    │
├────┬───────────────────────────────────────┬──────────┤
│    │                                       │ 小地图    │
│ L  │                                       │ 导航组    │
│ 左 │                                       ├──────────┤
│ 轨 │         世界视野（全屏垫底）            │ I 实体槽  │
│ 48 │                                       │ w300     │
│ px │                                       │ (选中才有 │
│    │                                       │  内容)    │
├────┴───────────────────────────────────────┴──────────┤
│ B 底部带 h52：模式主操作（内容按模式替换，几何永远不变）      │
└────────────────────────────────────────────────────────┘
         C 中央弹层栈：对话/确认/全屏页（模态，逐层 ESC）
```

| 槽位 | 几何（锁定） | 归属层 | 行为契约 |
|------|-------------|--------|---------|
| **T 顶条** | 全宽×36px，top:0 | 世界层+系统层 | 左：位置面包屑（全模式可点定位）；中：情境章（经营=店名/营业态、建造="建造中·时间暂停"、探索自由态=地图名、遭遇态=回合序）；右：时间/倍速+核心资源+系统菜单（齿轮聚合设置/保存/帮助） |
| **R 导航组** | right:10，top:44，小地图 φ120-140 | 世界层 | 全模式全功能；查看类操作；图层/透视/滑杆收进一个"视角"弹出，不再摊两个滑杆常驻 |
| **L 左轨** | left:0，top:44→B 上方，w48 图标轨，点击展开 w260 抽屉 | 模式层（低频部分） | 全模式同构：图标轨常驻，抽屉是浮动层。经营=区域树/经营功能；建造=库四类别；探索=队伍/探索功能 |
| **B 底部带** | 全宽×52px，bottom:0（高度锁死） | 模式层（高频部分） | 内容整体按模式替换；扩展内容（库网格/技能扩展）是**底带上方的浮动抽屉**，出现不改变底带位置 |
| **I 实体槽** | right:10，w300，top:190（小地图下方）→B 上方 | 实体层 | **全局唯一选中容器**：角色卡/区域卡/体素选区互斥共槽；无选中时空槽（世界不被重排）；ESC/点空白清除 |
| **C 弹层栈** | 中央模态 or 右侧抽屉 w400 | 临时层 | 严格栈式：模态全屏页 > 抽屉 > 对话 > 浮标；ESC 逐层消化 |

### 5.3 三模式槽位映射（内容替换表）

| 槽位 | 经营 | 建造 | 探索·自由 | 探索·遭遇 |
|------|------|------|----------|----------|
| T·中 | 店名·营业态章 | "建造中 ⏸"章 | 地图名章 | **回合序条** |
| T·右 | 时间+倍速+资源全套 | 时间⏸+资源缩略 | 时间⏸ | 时间⏸ |
| L 轨 | 区域树、经营功能 | 库类别（方块/模板/家具/区域） | 队伍、道具/任务/地图 | 队伍 |
| B 带 | 快捷态：营业开关、进入建造、模式段控 | **工具带**：历史│工具格│材料槽│参数摘要│确认 | 功能条：技能/道具/结束动作 | **行动条**：队伍头像│技能(AP)│结束回合 |
| I 槽 | 区域/NPC 卡 | 参数+选区信息（选中对象时切对象卡） | 单位卡 | 单位卡+命中预报 |
| B 上方浮动 | — | 库网格抽屉（选材料时展开） | — | 技能详情/法术书 |
| C 栈 | 功能抽屉/对话 | 业务表单 Modal | 对话 | 战果/对话 |

**模式切换时玩家要重新适应的只剩 B 带与 L 轨的内容**——几何、位置、查看方式（I 槽）、系统入口（T 右）、ESC 行为全部不变。这就是"更少变化"的量化答案：9 个区域里 7 个锁定，2 个换内容。

### 5.4 建造模式：从 Z 字动线到线性动线

```
B 带（左→右 = 决策顺序）：
[↺↻] │ [工具格组] │ [材料槽] │ [参数摘要·点击展开右槽] │ [✓确认 ✕取消]
 全局      ↓           ↓              ↓                    └─ 双通道冗余：
 历史    选择工具   选材料自动      完整参数在 I 槽            3D 浮标（场景内）
        （图标+    带出对应工具                         与底带按钮同功能
         快捷键角标） （浮动抽屉网格）
```

- 库不再是独立面板，是"材料槽"的浮动展开层（选完即收）——消灭"按需出现的 600px 面板"。
- 参数面板与实体槽合并（I 槽）：建造时 I 槽=当前工具完整参数；点选了对象则切对象卡，再点回工具恢复参数。**一个槽位解决"参数太小"与"实体卡跳位"两个原有问题**。
- 确认双通道：3D 浮标给可发现性，底带按钮+快捷键（LMB 确认/RMB 取消）给效率。

## 6. 布局排版硬伤清单（与模式无关的通用问题)

| # | 问题 | 现状 | 建议基准 |
|---|------|------|---------|
| 1 | 字号过小 | 功能组标题 8px、tooltip 9px、标签 7-8px 大量出现 | 1080p 下正文≥12px、辅助≥10px、标签≥9px 加字距；8px 以下禁用 |
| 2 | 触控目标过小 | 功能图标 24px、小地图圆钮 26px、倍速钮 18px | 桌面鼠标 ≥28px，主操作 ≥32px |
| 3 | 图标无文字 | 经营功能、角色功能全靠 24px emoji + hover tooltip | 图标+文字标签（CK3/双点）或至少快捷键角标；tooltip 是补充不是唯一线索 |
| 4 | 底部基线不齐 | 库 bottom:51、工具条 bottom:10、参数 bottom:56 | 底部所有浮层锚定底带上缘，统一间距 |
| 5 | 宽度失衡 | 库 600px vs 工具条 480px vs 参数 260px | 同一容器族的宽度成体系（如 300/480/720 阶梯） |
| 6 | tooltip 方向 | 一律向下弹（top:32px），底部组件必出屏 | 下半屏向上弹、上半屏向下弹 |
| 7 | 圆角/色彩语言不统一 | 卡片 8px、建造 9px、对话 12px 紫系独立 | 圆角阶梯：控件5/卡片7-8/弹层12；紫色只留给 NPC 对话（叙事），系统弹窗用主色系 |
| 8 | z 层无规则 | 弹层30/31、图层弹出20、浮标7 | 定义层级表：世界<HUD<浮动抽屉<浮标<抽屉<模态<Toast |
| 9 | 退出/关闭图标歧义 | ✕ 同时用于关卡片、退建造、重置参数、取消放置 | 语义分图标：✕关面板、⏏退模式、⟲重置、ESC 提示常显 |
| 10 | 空态无设计 | 经营底部整段空、无选中时无槽位提示 | 空态也是设计：收起态底带放模式段控+快捷，空槽显示"点击世界对象查看" |

## 7. 迁移要点（v4 → v5 改什么）

按投入产出排序：

1. **定义六槽位壳**（T/R/L/B/I/C），把 v4 现有内容**原样归位**——内容零改动，先解决"跳变"。
2. **底部带统一 52px 高**：经营=快捷+模式段控；建造=工具带；探索=行动条。库/技能扩展改为底带上方的浮动抽屉。
3. **实体卡移到右槽**（小地图下方），消灭 bottom:12/156 跳变与角色信息三角。
4. **模式段控固定**（建议 T 条右端或 B 带右端）：经营|建造|探索 三态直达；小地图点击回归"看地图"，旅行在地图页内完成。
5. **建造带线性化**：历史│工具│材料│参数摘要│确认 按决策顺序排；参数与选区信息并入右槽。
6. **查看流三级化**：选中卡内联高频 → 右抽屉中频 → 全屏页仅留技能树/势力图/大地图。
7. **ESC 栈与图标语义表**（成本最低，收益立竿见影）。
8. **探索拆自由/遭遇两子态**：自由态 B=功能条、T 中=地图名；遭遇态 B=行动条、T 中=回合条；切换加镜头/动画提示。
9. **排版规范**：字号阶梯（12/10/9）、触控≥28px、图标配文字、底部基线统一、tooltip 方向规则。
