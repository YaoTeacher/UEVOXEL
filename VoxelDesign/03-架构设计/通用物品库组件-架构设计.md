## 1. 架构概述

### 1.1 设计原则

```
┌─────────────────────────────────────────────────┐
│          核心设计原则 (SOLID)                   │
├─────────────────────────────────────────────────┤
│                                                 │
│  S - 单一职责: 只负责物品列表展示和交互         │
│  O - 开闭原则: 通过配置扩展，无需修改代码       │
│  L - 里氏替换: 可作为子组件嵌入任何父组件       │
│  I - 接口隔离: 提供最小化公共接口               │
│  D - 依赖倒置: 依赖抽象（ConfigDataSubsystem）  │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 1.2 架构目标

1. **自给自足** - 组件自己管理初始化，无需外部干预
2. **配置驱动** - 通过 DEFAULT 配置控制行为
3. **高复用性** - 可用于多种场景（方块库、模板库、背包等）
4. **低耦合** - 与父组件通过代理通信

## 3. 模块设计

### 3.1 职责划分

#### UItemLibraryWidgetBase 职责

**核心职责：**
1. ✅ TAB 系统管理（创建、切换、状态更新）
2. ✅ 物品列表管理（加载、筛选、分页）
3. ✅ 搜索过滤
4. ✅ 用户交互处理（点击、切换）

**不负责：**
- ❌ 物品数据存储（由 ConfigDataSubsystem 负责）
- ❌ 物品业务逻辑（由父组件负责）
- ❌ 工具状态管理（由 StateComponent 负责）

#### 父组件职责

**M1_BuildLibraryModule 职责：**
1. ✅ 手持物品槽显示
2. ✅ 选中物品信息显示
3. ✅ 与工具系统交互
4. ✅ 处理物品点击事件

**不负责：**
- ❌ TAB 管理（由 ItemLibrary 负责）
- ❌ 物品列表加载（由 ItemLibrary 负责）

### 3.2 接口设计

#### 公共接口（最小化）

```cpp
/**
 * 公共接口：只暴露必要的初始化和控制接口
 */
class UItemLibraryWidgetBase
{
public:
    // === 核心接口 ===

    /** 一键初始化（外部只需调用此函数） */
    void Initialize();

    /** 刷新列表 */
    void RefreshItemList();

    /** 切换分类 */
    void SwitchToCategory(FString CategoryId);

    // === 配置属性 ===

    /** 最大查询类型TAG（DEFAULT 配置） */
   	UPROPERTY(EditAnywhere, BlueprintReadWrite)
    FGameplayTag MaxQueryTypeTag;

    /** 是否自动生成"全部"分类 */
   	UPROPERTY(EditAnywhere, BlueprintReadWrite)
    bool bAutoGenerateAllCategory = true;

    // === 代理事件 ===

    /** 物品点击事件（输出） */
   	UPROPERTY(BlueprintAssignable)
    FItemClickedSignature OnItemClicked;

    /** 创建物品槽位（输入） */
   	UPROPERTY(BlueprintAssignable)
    FCreateItemSlotSignature OnCreateItemSlot;
};
```

#### 内部接口（封装）

```cpp
/**
 * 内部接口：不对外暴露，可随意修改
 */
class UItemLibraryWidgetBase
{
private:
    // === 初始化相关 ===

    /** 自动生成基础分类 */
    TArray<FItemCategoryConfig> GenerateBasicCategories();

    /** 初始化 TAB 系统 */
    void InitializeCategoryTabs();

    /** 创建 TAB 按钮 */
    void CreateCategoryTabButton(const FItemCategoryConfig& Category);

    /** 更新 TAB 状态 */
    void UpdateCategoryTabStates();

    // === 物品管理 ===

    /** 根据 TAG 加载物品 */
    void InitializeItemsByType();

    /** 更新列表显示 */
    void UpdateItemListDisplay();

    /** 渲染当前页 */
    void RenderCurrentPageItems();

    // === 事件处理 ===

    /** TAB 点击 */
    void OnCategoryTabClicked(bool bChecked, FString CategoryId);

    /** 搜索文本改变 */
    void OnSearchTextChanged(const FText& Text);

    /** 分页按钮点击 */
    void OnPrevPageClicked();
    void OnNextPageClicked();
};
```

## 4. 数据流架构

### 4.1 初始化数据流

```
┌─────────────────────────────────────────────────┐
│ Step 1: 父组件调用 Initialize()                 │
│         ItemLibraryComponent->Initialize();     │
└──────────────────┬──────────────────────────────┘
                   ↓
┌─────────────────────────────────────────────────┐
│ Step 2: 生成基础分类                             │
│         CachedCategories = Generate...();       │
└──────────────────┬──────────────────────────────┘
                   ↓
┌─────────────────────────────────────────────────┐
│ Step 3: 初始化 TAB 系统                          │
│         InitializeCategoryTabs();               │
│         ├─ CreateCategoryTabButton("全部")      │
│         └─ DynamicTabButtons.Add(Button)        │
└──────────────────┬──────────────────────────────┘
                   ↓
┌─────────────────────────────────────────────────┐
│ Step 4: 加载物品数据                             │
│         InitializeItemsByType();                │
│         CDS = GetSubsystem<CDS>();              │
│         AllItems = CDS->GetItemTypeArray...();  │
└──────────────────┬──────────────────────────────┘
                   ↓
┌─────────────────────────────────────────────────┐
│ Step 5: 显示"全部"分类                           │
│         SwitchToCategory("All");                │
│         FilteredItems = AllItems;               │
│         RenderCurrentPageItems();               │
└─────────────────────────────────────────────────┘
```

### 4.2 用户交互数据流

#### 交互 1: 点击 TAB

```
用户点击 TAB 按钮
    ↓
OnCategoryTabClicked(CategoryId)
    ↓
SwitchToCategory(CategoryId)
    ├─ SelectedCategoryId = CategoryId
    ├─ CurrentPage = 0 (重置页码)
    ├─ UpdateCategoryTabStates() (更新视觉)
    └─ RenderCurrentPageItems() (重新渲染)
```

#### 交互 2: 点击物品

```
用户点击物品槽位
    ↓
OnItemSlotClicked(Item)
    ↓
OnItemClicked.Broadcast(Item->ItemTag)
    ↓
父组件处理: HandleItemClicked(ItemTag)
    ├─ 更新手持物品
    ├─ 更新选中信息
    └─ 通知 StateComponent
```

### 5.2 关键类说明

#### UItemLibraryWidgetBase

**设计模式：**
- **组合模式** - 作为子组件嵌入父组件

- **观察者模式** - 通过代理与父组件通信

**关键成员变量：**


## 8. 错误处理

### 8.1 错误场景

| 场景 | 处理方式 | 日志级别 |
|------|---------|---------|
| ConfigDataSubsystem 为空 | 返回空列表 | Warning |
| MaxQueryTypeTag 无效 | 跳过初始化 | Warning |
| CategoryTabContainer 为空 | 跳过 TAB 创建 | Warning |
| 物品数据为空 | 显示空列表 | VeryVerbose |

### 8.2 错误日志

```cpp
// 示例: ConfigDataSubsystem 为空
if (!CDS)
{
    UE_LOG(LogTemp, Warning,
        TEXT("ItemLibraryWidgetBase: ConfigDataSubsystem not found. "
             "Cannot initialize items with tag: %s"),
        *MaxQueryTypeTag.ToString());
    return;
}
```
