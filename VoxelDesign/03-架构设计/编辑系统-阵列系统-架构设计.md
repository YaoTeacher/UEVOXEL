## 1. 组件架构

### 1.1 组件层次结构

```
阵列系统
├── 阵列配置器（ArrayConfigurator）
│   └── 管理阵列参数
├── 定位点计算器（PlacementCalculator）
│   └── 计算阵列定位点
└── 曲线计算器（CurveCalculator）
    ├── 直线计算器（Linear）
    ├── 圆形计算器（Circular）
    ├── 贝塞尔计算器（Bezier）
    └── 样条计算器（Spline）
```

### 1.2 组件职责描述

**阵列配置器**
- 提供配置参数的设置接口
- 验证配置参数的有效性
- 管理配置状态

**定位点计算器**
- 根据配置计算定位点数组
- 协调曲线计算器
- 应用间隔模式和朝向

**曲线计算器**
- 实现各种曲线的分布算法
- 计算曲线上的点位置
- 计算曲线的切线方向（用于朝向）

### 1.3 组件依赖关系

```
UVoxelArrayConfigurator
    ↓ 使用
UVoxelPlacementCalculator
    ↓ 使用
UVoxelCurveCalculator（策略）
    ├── LinearCalculator
    ├── CircularCalculator
    ├── BezierCalculator
    └── SplineCalculator

输出：
FArrayPlacementConfig → TArray<FArrayPlacementPoint>
```

## 2. 接口定义

### 2.1 阵列配置接口

```
class UVoxelArrayConfigurator
{
    /**
     * 设置直线阵列参数
     */
    void ConfigureLinearArray(
        float Stride,
        FIntVector StartOffset,
        TArray<int32> Pattern);

    /**
     * 设置圆形阵列参数
     */
    void ConfigureCircularArray(
        float Radius,
        float StartAngle,
        float EndAngle,
        int32 Count);

    /**
     * 设置曲线阵列参数
     */
    void ConfigureCurveArray(
        ECurveType CurveType,
        TArray<FVector> ControlPoints,
        float Stride);

    /**
     * 设置朝向模式
     */
    void SetOrientationMode(
        EOrientationMode OrientationMode,
        EDiscreteRotation GlobalRotation,
        TMap<int32, EDiscreteRotation> PerPointRotations);

    /**
     * 验证配置有效性
     */
    bool ValidateConfig();
};
```

### 2.2 定位点计算器接口

```
class UVoxelPlacementCalculator
{
    /**
     * 计算阵列定位点
     */
    TArray<FArrayPlacementPoint> CalculatePlacementPoints(
        FArrayPlacementConfig& Config,
        FVector StartPoint,
        FVector EndPoint);

    /**
     * 应用间隔模式
     */
    TArray<FArrayPlacementPoint> ApplyPattern(
        TArray<FArrayPlacementPoint>& Points,
        TArray<int32> Pattern);

    /**
     * 应用朝向
     */
    void ApplyOrientation(
        TArray<FArrayPlacementPoint>& Points,
        FArrayPlacementConfig& Config);
};
```

### 2.3 曲线计算器接口

```
class UVoxelCurveCalculator
{
    /**
     * 计算直线上的点
     */
    TArray<FVector> CalculateLinearPoints(
        FVector Start,
        FVector End,
        int32 Count);

    /**
     * 计算圆周上的点
     */
    TArray<FVector> CalculateCircularPoints(
        FVector Center,
        float Radius,
        float StartAngle,
        float EndAngle,
        int32 Count);

    /**
     * 计算贝塞尔曲线上的点
     */
    TArray<FVector> CalculateBezierPoints(
        TArray<FVector> ControlPoints,
        int32 Count);

    /**
     * 计算样条曲线上的点
     */
    TArray<FVector> CalculateSplinePoints(
        TArray<FVector> ControlPoints,
        int32 Count);

    /**
     * 计算曲线长度
     */
    float CalculateCurveLength(
        ECurveType CurveType,
        TArray<FVector> ControlPoints);
};
```

### 2.4 数据结构接口

```
struct FArrayPlacementConfig
{
    // 基础参数
    float Stride;
    FIntVector StartOffset;
    TArray<int32> Pattern;
    int32 MaxCount;

    // 曲线参数
    ECurveType CurveType;
    TArray<FVector> ControlPoints;

    // 朝向参数
    EOrientationMode OrientationMode;
    EDiscreteRotation GlobalRotation;
    TMap<int32, EDiscreteRotation> PerPointRotations;
};

struct FArrayPlacementPoint
{
    FVector Position;
    EDiscreteRotation Rotation;

    FTransform GetTransform();
};
```

## 3. 数据流

### 3.1 直线阵列流程

```
玩家配置
  ↓
UVoxelArrayConfigurator::ConfigureLinearArray()
  - 设置步长、首个偏移、间隔模式
  ↓
UVoxelPlacementCalculator::CalculatePlacementPoints()
  - 计算起点到终点的距离
  - 除以步长得到实例数量
  - 线性插值分布定位点
  ↓
应用间隔模式
  - 根据Pattern数组过滤/重复点
  ↓
应用朝向
  - 根据OrientationMode设置旋转
  - 应用全局或独立朝向
  ↓
输出：定位点数组
```

### 3.2 圆形阵列流程

```
玩家配置
  ↓
UVoxelArrayConfigurator::ConfigureCircularArray()
  - 设置半径、角度范围、数量
  ↓
UVoxelPlacementCalculator::CalculatePlacementPoints()
  - 调用UVoxelCurveCalculator::CalculateCircularPoints
  - 极坐标转换为笛卡尔坐标
  ↓
应用朝向（朝向圆心）
  - 计算到圆心的向量
  - 设置旋转（lookat矩阵）
  ↓
输出：定位点数组
```

### 3.3 曲线阵列流程

```
玩家配置
  ↓
UVoxelArrayConfigurator::ConfigureCurveArray()
  - 设置曲线类型、控制点、步长
  ↓
UVoxelPlacementCalculator::CalculatePlacementPoints()
  - 调用曲线计算器
  - 根据CurveType选择算法
  - 沿曲线均匀分布定位点
  ↓
应用朝向（跟随曲线）
  - 计算曲线切线方向
  - 设置旋转（对齐切线）
  ↓
输出：定位点数组
```

### 3.4 预览更新流程

```
玩家调整参数
  ↓
UVoxelArrayConfigurator
  - 更新配置参数
  - 验证有效性
  ↓
UVoxelPlacementCalculator::CalculatePlacementPoints()
  - 重新计算定位点
  ↓
AVoxelTemplatePreviewActor::UpdateArrayPreview()
  - 更新现有MeshComponent的Transform
  - 创建/销毁Component（数量变化）
  ↓
显示：实时预览
```

## 4. 生命周期管理

### 4.1 阵列配置生命周期

```
未配置（Unconfigured）
  ↓ 玩家设置参数
配置中（Configuring）
  - 参数可能不完整
  ↓ 参数验证通过
已配置（Configured）
  ↓ 玩家调整参数
重新配置（Reconfiguring）
  ↓ 玩家确认或取消
完成/清理（Done/Cleanup）
```

### 4.2 定位点计算生命周期

```
未计算（NotCalculated）
  ↓ 配置变化
计算中（Calculating）
  - CPU计算定位点
  ↓ 计算完成
已计算（Calculated）
  ↓ 配置再次变化
重新计算（Recalculating）
  ↓ 释放内存
清理（Cleanup）
```

## 6. 扩展点

### 6.1 新增曲线类型

**步骤**：
1. 在 `ECurveType` 枚举中添加新类型
2. 在 `UVoxelCurveCalculator` 中实现计算方法
3. 在 `UVoxelPlacementCalculator` 中添加调用逻辑

**示例**：
```
enum class ECurveType : uint8
{
    Linear,
    Circular,
    Bezier,
    Spline,
    Spiral,  // 新增
};

TArray<FVector> CalculateSpiralPoints(...);
```

### 6.2 新增间隔模式

**步骤**：
1. 扩展 `Pattern` 数组支持复杂模式
2. 实现模式解析器
3. 在 `ApplyPattern()` 中应用新逻辑
