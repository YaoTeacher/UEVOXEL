# Preview系统设计文档

## 1. Controller及其Component功能拆分

### 1.1 架构概述

**核心原则**：Manager管理世界状态，Component管理玩家自己的功能

**组件架构**（6个组件）：
```
PlayerController（输入路由层）
├── StateComponent（数据存储层）
├── InteractComponent（业务逻辑层 + 输入状态存储）
├── VisualUIComponent（视觉表现层）
├── HistoryComponent（历史记录层）
└── PreviewActor（预览显示）- 独立Actor
```

---

### 1.2 各组件职责

#### AVoxelPlayerController
- **归属**：输入路由层
- **作用**：
  - 接收原始输入（键盘、鼠标、手柄）
  - 分发输入到InteractComponent
  - 相机控制
  - 组件生命周期管理
  - 系统访问（获取WorldSubsystem引用）
  - 输入模式切换

#### StateComponent
- **归属**：数据存储层
- **作用**：
  - 存储所有玩家状态数据
  - 提供状态访问器和修改器
  - 广播状态变更事件
  - **不做**：业务逻辑、输入检测、视觉更新

#### InteractComponent
- **归属**：业务逻辑层 + 输入状态存储
- **作用**：
  - 接收蓝图传入的体素索引
  - 存储输入状态（FirstPoint、SecondPoint）
  - 业务逻辑处理（包围盒计算、参数调整）
  - 协调其他组件（调用StateComponent、VisualUIComponent、HistoryComponent、WorldSubsystem）
  - 权限检查、成本检查
  - **不做**：射线检测（蓝图处理）、状态存储、视觉渲染、网格生成

#### VisualUIComponent
- **归属**：视觉表现层
- **作用**：
  - 持有PreviewActor
  - 调用PreviewActor的更新方法
  - 管理所有Gizmo（Translate、Rotate、Face）
  - 管理UI元素（高度碰撞）
  - **不做**：业务逻辑、输入检测、预览渲染（委托给PreviewActor）

#### HistoryComponent
- **归属**：历史记录层
- **作用**：
  - 管理撤销/重做栈
  - 记录操作日志
  - 统计信息

#### PreviewActor
- **归属**：预览显示（独立Actor）
- **作用**：
  - 显示预览网格（Wireframe、Inner、Thickness、Blueprint）
  - **不管理Gizmo**（由VisualUIComponent统一管理）
  - 根据流程状态更新预览渲染

---

### 1.3 依赖关系

```
PlayerController
├── StateComponent（数据层）
├── InteractComponent（业务层 + 输入状态）
│   → 接收蓝图输入（体素索引）
│   → 管理输入状态（FirstPoint、SecondPoint）
│   → 调用StateMachine（状态转换）
│   → 读写StateComponent（业务数据）
│   → 调用VisualUIComponent（视觉更新）
│   → 调用HistoryComponent（历史记录）
│   → 调用WorldSubsystem（执行编辑）
└── VisualUIComponent（视觉层）
    → 读取StateComponent（包围盒数据）
    → 调用PreviewActor（预览显示）
```

## 2. PreviewActor状态管理

### 2.1 状态设计

**3个流程状态**：
```
HIDDEN → BASE → EDIT
   ↑_______| (取消)
```

| 状态 | 说明 | 数据 | Gizmo | 预览 |
|------|------|------|-------|------|
| **HIDDEN** | 初始/隐藏 | 无 | 无 | 无 |
| **BASE** | 拖动定义底面 | FirstP + 动态SecondP | 无 | 2D包围盒（实时） |
| **EDIT** | 推拉任意面调整包围盒 | FirstP + SecondP + 动态Height/Min/Max | 12个Gizmo | 3D包围盒（实时） |

---

### 2.2 详细流程

#### 阶段1: HIDDEN → BASE（定义底面）

**操作流程**：
1. **按下鼠标**（第一个点）
   - 记录FirstP
   - 进入BASE状态
   - 显示单点预览

2. **拖动鼠标**
   - 实时计算从FirstP到鼠标位置的2D包围盒
   - 更新2D包围盒预览
   - 无Gizmo

3. **松开鼠标**（第二个点）
   - 记录SecondP
   - **自动进入EDIT状态**
   - Height初始为0
   - 显示12个Gizmo

---

#### 阶段2: EDIT状态（推拉任意面）

**进入EDIT时**：
- 数据：FirstP、SecondP已确定
- Height：初始为0
- 显示：12个Gizmo
- 预览：3D包围盒

**EDIT状态下的操作**：

1. **拖动Z向面定义高度**
   - 拖动顶面Gizmo → 调整Max.Z
   - 拖动底面Gizmo → 调整Min.Z

2. **拖动X/Y向面调整底面**
   - 拖动侧面Gizmo → 调整Min.X/Y 或 Max.X/Y

3. **旋转/移动PreviewActor**
   - 使用Actor控件组（6个Gizmo）

4. **其他操作**
   - 滚轮：调整旋转、厚度
   - 快捷键：切换对称模式等

---

#### 阶段3: 确认/取消

**确认编辑**：
- Enter键
- 点击UI确认按钮
- 执行编辑
- 清空数据
- 返回HIDDEN

**取消编辑**：
- Esc键
- 清空数据
- 返回HIDDEN

---

### 2.3 状态转换时序

```
初始: HIDDEN状态
    ↓
【按下鼠标左键】
    ↓
BASE状态
- FirstP已设置
- 拖动鼠标实时更新SecondP
- 显示2D包围盒预览
    ↓
【松开鼠标左键】
    ↓
EDIT状态
- FirstP、SecondP已确定
- Height初始为0
- 显示12个Gizmo
- 显示3D包围盒预览
    ↓
【拖动任意面】
    ↓
EDIT状态（持续）
- 动态更新包围盒
- 实时更新预览和Gizmo
    ↓
【Enter确认】或【Esc取消】
    ↓
HIDDEN状态
```

## 3. Gizmo管理

### 3.1 Gizmo分类

**12个Gizmo分为3组**（统一由VisualUIComponent管理）：

#### TranslateGizmos（3个）
- **XTranslateGizmo**：沿X轴移动
- **YTranslateGizmo**：沿Y轴移动
- **ZTranslateGizmo**：沿Z轴移动
- **作用**：沿轴移动预览位置

#### RotateGizmos（3个）
- **X轴旋转Gizmo**：绕X轴旋转
- **Y轴旋转Gizmo**：绕Y轴旋转
- **Z轴旋转Gizmo**：绕Z轴旋转
- **作用**：旋转预览对象

#### FaceGizmos（6个）
- **顶面Gizmo**：调整Max.Z
- **底面Gizmo**：调整Min.Z
- **前面Gizmo**：调整Max.Y或Min.Y
- **后面Gizmo**：调整Min.Y或Max.Y
- **右面Gizmo**：调整Max.X或Min.X
- **左面Gizmo**：调整Min.X或Max.X
- **作用**：调整包围盒的形状

---

### 3.2 管理方式

**归属**：所有Gizmo由VisualUIComponent统一管理

**理由**：
- Gizmo是UI交互元素，属于VisualUIComponent职责范围
- VisualUIComponent需要根据PreviewActor的包围盒同步Gizmo位置
- 为未来家具拖拽功能预留（Gizmo可用于拖拽家具）
- PreviewActor专注纯渲染，不处理交互逻辑

**分组管理**：
```cpp
class UVoxelControllerVisualUIComponent
{
private:
    // 移动Gizmo（3个轴）
    TObjectPtr<AVoxel3DUIActor> XTranslateGizmo;
    TObjectPtr<AVoxel3DUIActor> YTranslateGizmo;
    TObjectPtr<AVoxel3DUIActor> ZTranslateGizmo;

    // 旋转Gizmo（3个轴）
    TArray<TObjectPtr<AVoxel3DUIActor>> RotateGizmos;

    // 面Gizmo（6个面）
    TArray<TObjectPtr<AVoxel3DUIActor>> FaceGizmos;

    // 初始化方法
    void InitTranslateGizmos();
    void InitRotateGizmos();
    void InitFaceGizmos();

    // 显示控制
    void ShowTranslateGizmo(const FVector& Center);
    void HideTranslateGizmo();
    void ShowRotateGizmo(const FVector& Center);
    void HideRotateGizmo();
    void HideAllGizmos();
};
```

---

### 3.3 输入处理

**方式**：蓝图事件处理 + C++ 接口

**输入流程**：
```
用户点击/拖动Gizmo
    ↓
蓝图捕获输入事件
    ↓
蓝图计算Offset
    ↓
蓝图调用 C++ 方法：InteractComponent->MoveArea(Offset, Gizmo)
    ↓
C++ 更新 StateComponent
    ↓
StateComponent 广播 Request 更新
    ↓
VisualUIComponent 接收广播
    ↓
VisualUIComponent 更新 PreviewActor 渲染 + Gizmo 位置
```

**关键接口**：
- `InteractComponent::MoveArea(FVector Offset, AVoxel3DUIActor* Input)` - 蓝图调用的C++接口
- 蓝图负责输入检测和偏移量计算
- C++负责业务逻辑和状态更新

## 4. 完整操作流程

### 4.1 操作清单（按阶段）

#### 阶段1: 确定底面（BASE状态）

**步骤1.1: 点击第一个点**
- 操作：鼠标按下
- 输入检测：射线检测
- 坐标转换：世界坐标 → 体素索引
- 状态转换：HIDDEN → BASE
- 视觉反馈：显示第一个点标记

**步骤1.2: 拖动定义底面**
- 操作：鼠标拖动
- 输入检测：每帧射线检测
- 包围盒计算：FirstP + 当前鼠标位置 → 2D包围盒
- 预览更新：实时更新2D包围盒预览

**步骤1.3: 松开确认第二个点**
- 操作：鼠标松开
- 状态转换：BASE → EDIT
- 视觉反馈：显示12个Gizmo、3D包围盒预览

---

#### 阶段2: 调整包围盒（EDIT状态）

**步骤2.1: 拖动Z向面**
- 操作：拖动顶面/底面Gizmo
- Gizmo交互：检测拖动
- 包围盒计算：调整Min.Z或Max.Z
- 预览更新：实时更新3D包围盒

**步骤2.2: 拖动X/Y向面**
- 操作：拖动侧面Gizmo
- Gizmo交互：检测拖动
- 包围盒计算：调整Min.X/Y或Max.X/Y
- 预览更新：实时更新3D包围盒

**步骤2.3: 旋转/移动PreviewActor**
- 操作：拖动Actor控件组
- Gizmo交互：检测拖动
- 变换更新：调整位置/旋转
- 预览更新：实时更新3D包围盒

**步骤2.4: 参数调整**
- 操作：滚轮、快捷键
- 参数更新：旋转、厚度、对称
- 预览更新：实时更新3D包围盒

---

#### 阶段3: 确认与取消

**步骤3.1: 确认编辑**
- 操作：Enter键或UI按钮
- 数据收集：收集当前所有参数
- 执行编辑：调用WorldSubsystem
- 历史记录：保存到HistoryComponent
- 清理：清空数据、隐藏Gizmo、返回HIDDEN

**步骤3.2: 取消编辑**
- 操作：Esc键
- 清理：清空数据、隐藏Gizmo、返回HIDDEN

---

### 4.2 操作归属表

| 操作 | 执行位置 | 输入 | 输出 |
|------|---------|------|------|
| **射线检测** | 蓝图 | 原始输入 | 体素索引 |
| **输入状态管理** | InteractComponent | 体素索引 | FirstPoint、SecondPoint |
| **状态转换** | InteractComponent | 输入状态 | 状态转换请求 |
| **状态存储** | StateComponent | 状态数据 | 状态变更事件 |
| **业务逻辑** | InteractComponent | 状态数据 | 包围盒、参数 |
| **预览更新** | PreviewActor | 包围盒、参数 | 视觉显示 |
| **Gizmo管理** | VisualUIComponent | 包围盒 | Gizmo位置、可见性 |
| **Gizmo输入** | 蓝图 | 用户拖动 | MoveArea调用 |
| **历史记录** | HistoryComponent | 编辑数据 | 历史栈 |
| **执行编辑** | WorldSubsystem | 编辑请求 | 实际编辑 |

## 5. 核心设计原则

### 5.1 职责分离
- Controller：输入路由
- Component：各自职责单一
- Manager：管理世界状态

### 5.2 强关联内聚
- Gizmo由VisualUIComponent统一管理（UI交互元素）
- PreviewActor专注纯渲染
- 预览数据与预览显示在同一个Actor中

### 5.3 状态简化
- 3个流程状态（Hidden、Base、Edit）
- 状态转换清晰，逻辑简单

### 5.4 分组管理
- TranslateGizmos（3个移动轴）
- RotateGizmos（3个旋转轴）
- FaceGizmos（6个面）
- 统一由VisualUIComponent管理
