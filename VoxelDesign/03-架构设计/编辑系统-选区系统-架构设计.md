# 编辑系统-选区系统-架构设计

---

## 1. 组件架构

### 1.1 组件层次结构

```
选区系统
├── 选区数据层（Selection Data）
│   ├── 选区数据（FVoxelSelection）
│   └── 选区历史（SelectionHistory）
│
├── 选区工具层（Selection Tools）
│   ├── 单点工具（SingleVoxelTool）
│   ├── 几何工具（BoxSelectionTool, SphereSelectionTool等）
│   ├── 笔刷工具（BrushSelectionTool）
│   └── 魔棒工具（MagicWandTool）
│
└── 操作工具层（Operation Tools）
    ├── 移动工具（MoveTool）
    ├── 复制工具（CopyPasteTool）
    ├── 删除工具（DeleteTool）
    └── 替换工具（ReplaceTool）

**模板创建**: 通过UI按钮触发,非工具模式
- UI按钮 → StateComponent(选区数据) → InteractComponent → TemplateManager
```

### 1.2 组件职责描述

**选区数据层**
- 管理当前选区的体素数据
- 提供选区包围盒计算
- 记录选区操作历史
- 支持布尔运算组合

**选区工具层**
- 提供各种选区定义方式
- 支持加减选模式
- 实时反馈选区预览
- 修改选区数据

**操作工具层**
- 对当前选区执行编辑操作
- 与预览系统集成
- 与历史系统集成
- 与模板系统集成

### 1.3 组件依赖关系

```
选区工具层
  ↓ 修改
选区数据层
  ↓ 被使用
操作工具层
  ↓ 依赖
外部系统（BlockWorld, HistoryComponent, TemplateSystem）
```

## 2. 接口定义

### 2.1 选区数据结构

```cpp
USTRUCT(BlueprintType)
struct FVoxelSelection
{
    GENERATED_BODY()

    // === 核心数据 ===
    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Selection")
    TMap<FIntVector, FGameplayTag> SelectedVoxels;  // 位置→原始类型

    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Selection")
    FAreaCoverageFragment Bounds;  // 包围盒

    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Selection")
    FDateTime CreationTime;  // 创建时间

    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Selection")
    FDateTime ModificationTime;  // 修改时间

    // === 数据访问 ===

    /**
     * 获取选区体素数量
     */
    int32 GetCount() const;

    /**
     * 检查选区是否为空
     */
    bool IsEmpty() const;

    /**
     * 获取选区包围盒
     */
    FAreaCoverageFragment GetBounds() const;

    /**
     * 清空选区
     */
    void Clear();

    /**
     * 添加体素到选区
     */
    void AddVoxel(FIntVector Position, FGameplayTag OriginalType);

    /**
     * 从选区移除体素
     */
    void RemoveVoxel(FIntVector Position);

    /**
     * 检查体素是否在选区中
     */
    bool Contains(FIntVector Position) const;
};
```

### 2.2 选区工具基类接口

```cpp
UCLASS(Abstract)
class UVoxelSelectionTool : public UVoxelToolBase
{
    GENERATED_BODY()

public:
    /**
     * 执行选区操作
     * @param CurrentSelection 当前选区（可为空）
     * @param BooleanMode 布尔运算模式
     * @return 新的选区数据
     */
    virtual FVoxelSelection ExecuteSelection(
        const FVoxelSelection* CurrentSelection,
        ESelectionBooleanMode BooleanMode) = 0;

    /**
     * 获取选区预览（实时反馈）
     */
    virtual TArray<FIntVector> GetPreviewSelection() const = 0;

    /**
     * 检查选区工具配置是否有效
     */
    virtual bool IsValidConfiguration() const;

    // ==================== 带类型的选区计算 ====================

    /**
     * 计算选中的体素集合（带类型信息）
     * @param Request 编辑请求（包含几何信息和形状参数）
     * @param BlockSize 方块尺寸（用于坐标转换）
     * @param BlockWorld 体素世界子系统（用于查询方块类型）
     * @return 选中的体素位置和类型映射
     *
     * 为了支持模板系统,需要获取方块类型信息。
     * 原有的CalculateSelection保持不变,返回位置数组。
     */
    static TMap<FIntVector, FGameplayTag> CalculateSelectionWithTypes(
        const FVoxelEditRequest& Request,
        float BlockSize,
        UVoxelBlockWorldSubsystem* BlockWorld
    );

    /**
     * 计算选中的体素集合（带类型+布尔运算）
     * @param Request 编辑请求
     * @param BlockSize 方块尺寸
     * @param ExistingSelection 已存在的选择集合
     * @param OperationType 选择操作类型
     * @param BlockWorld 体素世界子系统
     * @return 选中的体素位置和类型映射
     */
    static TMap<FIntVector, FGameplayTag> CalculateSelectionWithTypes(
        const FVoxelEditRequest& Request,
        float BlockSize,
        const TMap<FIntVector, FGameplayTag>& ExistingSelection,
        ESelectionOperationType OperationType,
        UVoxelBlockWorldSubsystem* BlockWorld
    );
};
```

### 2.3 布尔运算模式

```cpp
UENUM(BlueprintType)
enum class ESelectionBooleanMode : uint8
{
    New UMETA(DisplayName = "新选"),           // 清空旧选区，使用新选区
    Add UMETA(DisplayName = "加选"),           // 新选区 ∪ 旧选区
    Subtract UMETA(DisplayName = "减选"),      // 旧选区 - 新选区
    Intersect UMETA(DisplayName = "交集")     // 新选区 ∩ 旧选区
};
```

## 3. 数据流

### 3.1 框选流程

```
玩家拖拽鼠标
  ↓
UVoxelBoxSelectionTool 更新 EndPosition
  ↓
实时预览：GetPreviewSelection()
  - 计算当前包围盒
  - 渲染半透明选区框
  ↓
玩家释放鼠标
  ↓
ExecuteSelection(CurrentSelection, BooleanMode)
  ↓
步骤1：计算包围盒
  - Min = StartPosition.Min(EndPosition)
  - Max = StartPosition.Max(EndPosition)
  ↓
步骤2：遍历包围盒
  - for (X = Min.X to Max.X)
  -   for (Y = Min.Y to Max.Y)
  -     for (Z = Min.Z to Max.Z)
  ↓
步骤3：查询体素类型
  - BlockWorld->GetVoxelType(FIntVector(X,Y,Z))
  - 过滤空气方块
  ↓
步骤4：应用布尔运算
  - New: 使用新选区
  - Add: SelectedVoxels.Append(NewVoxels)
  - Subtract: SelectedVoxels -= NewVoxels
  - Intersect: SelectedVoxels *= NewVoxels
  ↓
步骤5：更新包围盒
  - Bounds = CalculateBounds(SelectedVoxels)
  ↓
步骤6：更新时间戳
  - ModificationTime = FDateTime::Now()
  ↓
输出：FVoxelSelection
```

### 3.2 魔棒选择流程

```
玩家点击体素
  ↓
UVoxelMagicWandTool 设置 StartPosition
  ↓
读取起始体素类型
  - TargetType = BlockWorld->GetVoxelType(StartPosition)
  ↓
FloodFill 扩散遍历
  ↓
使用队列进行广度优先搜索
  - Queue.Enqueue(StartPosition)
  - Visited.Add(StartPosition)
  ↓
while (!Queue.IsEmpty())
  - CurrentPos = Queue.Dequeue()
  - 检查6个相邻方向
  - 如果相邻体素类型 == TargetType
    - 且未访问过
    - 添加到Visited
    - 加入Queue
  ↓
检查 MaxDistance 限制
  - 计算距离：Distance(StartPosition, CurrentPos)
  - 超过限制则停止该方向扩散
  ↓
应用布尔运算
  - 与框选相同逻辑
  ↓
输出：FVoxelSelection
```

### 3.3 移动流程

```
选区完成
  ↓
玩家选择移动工具
  ↓
显示三轴Gizmo
  ↓
玩家拖拽Gizmo轴
  ↓
实时预览：CalculateMovePreview(Offset)
  - 遍历 SelectedVoxels
  - PreviewPos = WorldPos + Offset
  - 渲染半透明体素
  ↓
玩家点击确认
  ↓
CalculateMoveModification(Offset)
  ↓
步骤1：计算删除（原位置）
  - 遍历 SelectedVoxels
  - OldEdits.Add(WorldPos, nullptr)  // nullptr表示删除
  ↓
步骤2：计算创建（新位置）
  - 遍历 SelectedVoxels
  - NewPos = WorldPos + Offset
  - NewEdits.Add(NewPos, OriginalType)
  ↓
步骤3：合并修改请求
  - Modification.Edits = OldEdits + NewEdits
  - 计算受影响的ChunkIndices
  ↓
记录历史
  - HistoryComponent->SaveHistoryRecord(Modification)
  ↓
执行修改
  - BlockWorld->BatchModifyVoxelData_Modification(Modification)
  ↓
更新选区
  - 遍历 SelectedVoxels
  - 更新位置：NewPos = WorldPos + Offset
  - 清空旧位置，添加新位置
  ↓
输出：移动成功
```

### 3.4 复制粘贴流程

```
选区完成
  ↓
玩家按 Ctrl+C
  ↓
CopyToClipboard(Selection)
  ↓
步骤1：深拷贝选区数据
  - ClipboardVoxels = Selection.SelectedVoxels
  - ClipboardBounds = Selection.Bounds
  ↓
步骤2：计算相对坐标
  - 遍历 ClipboardVoxels
  - RelativePos = WorldPos - Bounds.Min
  ↓
步骤3：存储到剪贴板
  - 全局静态变量或ClipboardComponent
  ↓
输出：复制成功

玩家按 Ctrl+V
  ↓
PasteFromClipboard()
  ↓
步骤1：从剪贴板读取
  - 读取 ClipboardVoxels
  - 读取 ClipboardBounds
  ↓
步骤2：显示Gizmo预览
  - 在鼠标位置显示预览
  - 实时跟随鼠标移动
  ↓
玩家点击目标位置
  ↓
CalculatePasteModification(TargetPosition)
  ↓
步骤1：计算世界坐标
  - 遍历 ClipboardVoxels
  - WorldPos = RelativePos + TargetPosition
  ↓
步骤2：构建修改请求
  - Modification.Edits.Add(WorldPos, OriginalType)
  ↓
步骤3：计算受影响区块
  - Modification.ChunkIndices.Add(ChunkIndex)
  ↓
记录历史
  - HistoryComponent->SaveHistoryRecord(Modification)
  ↓
执行修改
  - BlockWorld->BatchModifyVoxelData_Modification(Modification)
  ↓
更新选区
  - 新选区 = 粘贴后的体素位置
  ↓
输出：粘贴成功
```

### 3.5 保存模板流程（按钮触发，非工具）

```
选区完成
  ↓
玩家点击"保存为模板"按钮（非工具选择）
  ↓
StateComponent 提供选区数据
  ↓
InteractComponent 调用 TemplateManager
  ↓
显示模板创建UI
  - 输入名称、描述
  - 选择标签
  ↓
玩家确认
  ↓
TemplateManager::CreateFromSelection(Selection, Name, Description, Tags)
  ↓
步骤1：计算包围盒
  - MinCorner = SelectedVoxels.GetMin()
  - MaxCorner = SelectedVoxels.GetMax()
  - Size = MaxCorner - MinCorner + FIntVector(1,1,1)
  ↓
步骤2：计算锚点偏移（底面中心）
  - AnchorOffset.X = (Size.X - 1) / 2
  - AnchorOffset.Y = (Size.Y - 1) / 2
  - AnchorOffset.Z = 0
  ↓
步骤3：构建调色板
  - 3.1：收集唯一Tag（使用TSet自动去重）
    - 遍历 SelectedVoxels.Values（每个体素的FGameplayTag）
    - 过滤空气方块：`Voxel.Block.Air`
    - 过滤脚手架层级：`Voxel.Block.Scaffolding.*`
  - 3.2：排序调色板（确保稳定性）
    - 按TagName字典序排序
    - 目的：跨平台序列化一致性
  - 3.3：构建索引映射
    - Palette数组：索引0开始的连续数组
    - TagToIndex映射：TMap<FGameplayTag, int32>
  ↓
步骤4：转换体素数据
  - 遍历 SelectedVoxels（包含位置和类型）
  - 计算相对坐标（底面中心为原点）：RelativePos = WorldPos - (MinCorner + AnchorOffset)
  - 查找调色板索引：PaletteIndex = TagToIndex[BlockType]
  - 存储到VoxelData：VoxelData.Add(RelativePos, PaletteIndex)
  ↓
步骤5：填充元数据
  - TemplateName = Name
  - Description = Description
  - Tags = Tags
  - AuthorName = PlayerName
  - CreationDate = FDateTime::Now()
  - 统计信息：BlockCount = VoxelData.Num()
  ↓
步骤6：检测依赖（TODO）
  - 检查Palette中Tag所属MOD/DLC
  ↓
步骤7：保存为 .vxbp 文件
  - 生成缩略图（可选）
  - 调用 UVoxelTemplateFileIO::SaveToVXBPFile()
  - 保存到 Saved/VoxelTemplates/ 目录
  - 返回文件路径
  ↓
输出：UVoxelBuildingTemplateAsset（包含 FilePath）
```

## 4. 生命周期管理

### 4.1 选区数据生命周期

```
不存在（NonExistent）
  ↓ 玩家执行选区操作
激活中（Active）
  - 持久保存在PlayerController中
  - 切换工具不清空
  ↓ 玩家执行清空操作
清空（Cleared）
  ↓ 玩家执行新选区操作
再次激活（Active）
```

### 4.2 选区工具生命周期

```
未激活（Inactive）
  ↓ 玩家选择工具
激活中（Active）
  - 监听输入事件
  - 实时更新预览
  ↓ 玩家切换工具
清理（Cleanup）
  - 清理临时数据
  - 取消输入监听
  ↓
未激活（Inactive）
```

### 4.3 操作工具生命周期

```
未激活（Inactive）
  ↓ 玩家选择操作（有选区前提下）
预览中（Previewing）
  - 显示操作预览
  - 等待玩家确认
  ↓ 玩家确认或取消
执行中（Executing）
  - 计算修改数据
  - 执行编辑操作
  - 记录历史
  ↓
未激活（Inactive）
```
