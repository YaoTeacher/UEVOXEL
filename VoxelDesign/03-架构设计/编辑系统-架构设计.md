### 1.3 组件职责概述

#### **用户交互层**

**VoxelPlayerController**
- 接收玩家输入
- 持有所有Controller组件

**VoxelControllerInteractComponent**
- 协调所有编辑操作
- 调用BatchTool计算编辑请求
- 调用BlockWorld执行编辑
- 保存历史到HistoryComponent

**VoxelControllerStateComponent**
- 管理编辑状态（EditState, CurrentToolTag, ToolParameters）
- 使用GameplayTag工具层级管理当前工具（替代BuildState枚举）
- 提供状态查询和切换接口
- 工具Tag层级：
  - `Voxel.Tool.Selection` - 选区工具（定义选区）
    - `Voxel.Tool.Selection.SingleVoxel` - 单体素选择
    - `Voxel.Tool.Selection.SimpleGeometry` - 简单几何体选择
    - `Voxel.Tool.Selection.Brush` - 笔刷选择
  - `Voxel.Tool.Edit` - 编辑工具（修改世界）
    - `Voxel.Tool.Edit.SingleVoxel` - 单体素编辑
    - `Voxel.Tool.Edit.SimpleGeometry` - 简单几何编辑
    - `Voxel.Tool.Edit.Selection` - 选区操作（移动/复制/删除）
    - `Voxel.Tool.Edit.Template` - 模板放置
  - `Voxel.Tool.AreaEdit` - 区域编辑工具
    - `Voxel.Tool.AreaEdit.Create` - 创建区域
    - `Voxel.Tool.AreaEdit.Modify` - 修改区域

**VoxelControllerVisualUIComponent**
- 更新预览显示
- 显示选择框、编辑形状
- 显示UI提示和反馈

#### **工具层**

**UVoxelBatchEditTool**
- 计算批量编辑的体素位置
- 计算ChunkIndex
- 边界检测
- 生成FSingleEditRequest
- **特点**：无状态、纯静态、纯数学计算

**选择工具系列**
- **UVoxelSelectionTool**（基类）：定义选择接口
- **UVoxelBoxSelectionTool**：框选实现
- **UVoxelMagicWandTool**：魔棒选择实现
- **UVoxelPolygonTool**：多边形选择实现

#### **功能模块层**

**模板系统组件**：
- **FVoxelBuildingTemplate**：模板数据结构
- **ConfigDataSubsystem**：模板库管理
- **UVoxelTemplateMeshGenerator**：网格生成
- **UVoxelTemplatePreviewCache**：预览缓存
- **UVoxelBuildCoordinator**：建造协调

**阵列系统组件**：
- **FArrayPlacementConfig**：阵列配置
- **UVoxelArrayConfigurator**：配置管理
- **UVoxelPlacementCalculator**：定位点计算
- **UVoxelCurveCalculator**：曲线计算

#### **执行层**

**UVoxelBlockWorldSubsystem**
- 接收FSingleEditRequest
- 异步处理编辑请求
- 更新网格和导航

**UVoxelControllerHistoryComponent**
- 管理撤销/重做栈
- 记录编辑操作历史
- 统计编辑信息

## 3. 数据流

### 3.1 核心编辑流程

```
用户操作（框选形状）
    ↓
InteractComponent::RequestBatchVoxelEdit
    ↓
BatchTool::CalculateSingleEditRequest
    ├─ 识别：批量编辑
    ├─ 计算：几何形状 → BlockIndex
    ├─ 计算：BlockIndex → ChunkIndex
    └─ 输出：FSingleEditRequest
    ↓
BlockWorld::BatchModifyVoxelData_Single
    ↓
HistoryComponent::SaveEditSnapshot
```

### 3.2 模板采集流程

```
玩家框选体素
    ↓
选区系统：UVoxelBoxSelectionTool
    - 计算包围盒
    - 选择体素
    ↓
模板系统：SaveAsTemplate()
    - 计算相对坐标
    - 构建模板数据
    - 添加元数据
    ↓
输出：FVoxelBuildingTemplate
```

### 3.3 模板放置流程

```
玩家选择模板
    ↓
模板系统：UVoxelTemplatePreviewCache
    - 生成/获取预览网格
    ↓
预览系统：显示预览
    ↓
玩家配置阵列（可选）
    ↓
阵列系统：计算定位点
    ↓
玩家确认放置
    ↓
模板系统：UVoxelBuildCoordinator
    - 计算世界坐标
    - 构建修改请求
    ↓
核心编辑：BlockWorld执行
    ↓
历史系统：记录历史
```

### 3.4 阵列预览流程

```
玩家配置阵列参数
    ↓
UVoxelArrayConfigurator
    - 更新配置
    ↓
UVoxelPlacementCalculator
    - 计算定位点
    - 应用间隔模式
    - 应用朝向
    ↓
AVoxelTemplatePreviewActor::UpdateArrayPreview
    - 创建/销毁MeshComponent
    - 更新Transform
    ↓
实时预览更新
```

## 4. 生命周期管理

### 4.1 编辑操作生命周期

```
未编辑（NotEditing）
  ↓ 玩家开始操作
编辑中（Editing）
  ├─ 显示预览
  ├─ 计算编辑范围
  └─ 等待确认
  ↓ 玩家确认
执行中（Executing）
  ├─ 异步处理
  ├─ 更新网格
  └─ 保存历史
  ↓ 完成编辑
已编辑（Edited）
```

### 4.2 选择工具生命周期

```
未激活（Inactive）
  ↓ 工具切换
激活（Active）
  ↓ 玩家选择
选择中（Selecting）
  ↓ 玩家释放
选中完成（Selected）
  ↓ 保存/取消
未激活（Inactive）
```

### 4.3 模板数据生命周期

```
不存在（NonExistent）
  ↓ 玩家采集
创建（Created）
  ↓ 保存文件
已保存（Saved）
  ↓ 玩家加载
可用（Available）
  ↓ 玩家删除
废弃（Deprecated）
```
