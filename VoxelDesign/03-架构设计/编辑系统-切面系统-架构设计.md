# 编辑系统 - 切面系统 - 架构设计

> 版本：v1.0 | 日期：2026-07-21
> 状态：实施中

---

## 一、功能定义

切面（Slice）系统：玩家/编辑器按"最大渲染层"对场景进行纵向剖切。

| 行为 | 说明 |
|------|------|
| 超高体素半透明 | 体素世界层 `z ≥ SliceLayer` 且处于切面作用范围内的体素，以**屏幕门抖动（Masked + DitherTemporalAA）**半透明渲染 |
| 切面层顶面正常渲染 | 体素世界层 `z = SliceLayer-1`（切面层）的顶面正常不透明渲染，供展示、射线碰撞、交互 |
| 射线穿透交互 | 鼠标点击半透明超高体素时，射线穿透到切面层顶面，编辑作用于切面层 |
| 区域精确过滤 | 切面作用范围精确到**体素级**：选中区域时仅区域内体素虚化，区域外体素（含侧面墙壁）保持不透明且有碰撞 |
| 家具/生物同步虚化 | 区域内、世界 Z 高度大于切面层的家具/生物材质走抖动虚化 |

---

## 二、层语义定义

```
EditSliceLayer = N（UI 显示的层数，整数，范围 [0, MaxSliceLayer]）
SliceHeight    = N × BlockLength（切面世界 Z 高度，厘米）

体素世界层 z 的语义：
  - z ∈ [0, N-1]  -> 不透明（含切面层 N-1，其顶面 = N×BlockLength = SliceHeight）
  - z ≥ N         -> 半透明（切面作用范围内）
```

体素层 `z` 与家具/生物世界 Z 的对应：家具世界 Z ∈ [z×BL, (z+1)×BL]，材质判定 `WorldPos.Z > SliceHeight` 与体素 `z ≥ N` 一致。

## 三、核心算法：三域面分流（精确范围 + 墙壁碰撞）

### 3.1 三域划分

网格生成时，每个体素按"实体性 × 切面作用域"划分为三个域，替代原有的二值 Opaque 判定：

```
Dom(X) = Air                               （非实体 / 空气）
       | Ghost                             （实体 且 InSliceScope(X)）
       | Opaque                            （实体 且 !InSliceScope(X)）

InSliceScope(X) = (X.世界层Z >= SliceLayer)
                  && AreaFilter(X)

AreaFilter(X):
  - AreaMode == 0（全局）         -> true
  - AreaMode == 1（白名单）        -> X ∈ 任一区域盒（体素索引空间 IsInsideOrOn）
  - AreaMode == 2（黑名单）        -> X ∉ 所有区域盒
```

`INT32_MAX` 的 `SliceLayer` 表示"无切面"，`InSliceScope` 恒为 false，三域退化为原始 `Air/Opaque` 二域 -> 与原有逻辑完全等价。

### 3.2 面生成规则

替代原 `CurrentBlockOpaque == CompareBlockOpaque` 二值判定：

| Current | Compare | 结果 | 归属 Section | 碰撞 |
|---------|---------|------|-------------|------|
| 同域 | 同域 | 不生成 | - | - |
| Opaque | 任意非 Opaque | Opaque 方面 | **0 不透明** | ✅ |
| 任意非 Opaque | Opaque | Opaque 方面（反向） | **0 不透明** | ✅ |
| Ghost | Air | Ghost 方面 | **1 半透明** | ❌ |
| Air | Ghost | Ghost 方面（反向） | **1 半透明** | ❌ |

**等价表述**：Opaque 对任何异域都生成自己的 Section0 面；Ghost 只对 Air 生成 Section1 面；Ghost 与 Opaque 交界只生成 Section0 面（归属 Opaque 方）。

### 3.3 关键不变式（精确性保证）

- **切面层顶面生成**：切面层（Opaque，z=N-1）上方是 Ghost/Air -> Opaque 对异域生成 Section0 面 ✓（展示 + 射线 + 交互）
- **区域边界侧面墙壁碰撞**：区域外体素（Opaque）朝向区域内的立面 -> Opaque 对异域生成 Section0 面 -> **不透明且有碰撞** ✓（满足"侧面墙壁碰撞"需求）
- **Ghost 与 Opaque 交界不重复生成** -> 无 z-fight ✓
- **Ghost 之间不生成内部面** -> 顶点数不爆炸 ✓
- **范围精确到体素级**：逐体素世界索引 vs 区域盒 `IsInsideOrOn` 判定（区域覆盖本质是体素索引空间轴对齐盒，AABB 判定即精确，无不规则形状近似）✓

### 3.4 双 Section 渲染与碰撞

```
Chunk 网格 = Section 0（不透明） + Section 1（半透明，可能为空）

Section 0:
  - 材质：SharedChunkMID（WorldTextureArray_Mat）
  - BlendMode: BLEND_Masked
  - bCreateCollision = true   <- 切面层顶面 + 区域外墙壁可射线/可碰撞/进 NavMesh

Section 1:
  - 材质：SharedChunkTranslucentMID（M_ChunkTranslucent）
  - BlendMode: BLEND_Masked + DitherTemporalAA
  - bCreateCollision = false  <- 射线天然穿透，命中切面层顶面；不进 NavMesh
```

**交互层零改动**：射线穿过无碰撞的 Section1，自然命中 Section0 的切面层顶面；`GetBlockIndexByPosition(Hit.Location)` 自动正确；导航不受半透明体素影响。

## 四、数据流与重建管线

### 4.1 状态层（不变）

```
UVoxelBuildStateComponent
  - EditSliceLayer (int32)
  - bSliceEnabled (bool)
  - SliceFilterMode (ESliceFilterMode: All / PlayerManaged)
  - OnSliceChanged 委托
  - GetEditSliceWorldHeight() = EditSliceLayer × BlockLength
  - GetMaxSliceLayer() = 世界 Z 维度
```

### 4.2 触发与分发

```
UI (WBP_SliceHeightPanel)
  -> SetEditSliceLayer / SetSliceEnabled / SetSliceFilterMode
  -> OnSliceChanged
  -> UVoxelPreviewComponent::HandleSliceHeightChanged
  -> ApplySliceVisuals()
      ├─ ① UVoxelBlockWorldSubsystem::ApplySlice(SliceHeight, bEnabled, AreaConfig)
      │      ├─ 计算 SliceLayer = round(SliceHeight / BlockLength)
      │      ├─ 目标 chunk = 视野内 LoadedChunks
      │      │    白名单模式且选中区域/父区域存在 -> 仅与区域盒相交的 chunk（chunk 级预筛，精确性由逐体素判定保证）
      │      ├─ 缓存当前 Slice 快照（SliceLayer + AreaMode + AreaBoxes）到 Subsystem
      │      ├─ dirty chunk -> UpdateChunkState -> WToCalculate（复用异步队列）
      │      └─ bEnabled=false / SliceLayer=Max -> SliceLayer 置 INT32_MAX 重建恢复
      └─ ② ApplySliceToFurnitureAndCreatures(AreaConfig)
             └─ 跳过 AGreedyChunk（消除 SharedChunkMID 污染）
                家具/生物 MID 设置 IsCheckZTrans/BasicZ/Area* 参数（材质走 MF_SliceDither）
```

### 4.3 重建管线（复用现有异步队列）

```
ApplySlice 标记 dirty chunk -> WToCalculate
  -> ProcessCalculateUpdates: BuildChunkContext（注入当前 Slice 快照）-> 异步 GenerateMeshData（三域双输出）
  -> CalculateChunk(FIntMeshDataPair) -> ModifyChunkMesh(双 MeshData)
  -> ApplyChunk -> ApplyMeshRender（双 Section：Section0 + Section1）

节流特性（天然）：
  - UpdateChunkState 对已在 WToCalculate 的 chunk 幂等跳过
  - BuildChunkContext 出队时读取 Subsystem 当前 Slice 快照 -> 连续拖动滑杆自动取最新值
  - ProcessCalculateUpdates 每帧限制并发任务数；ProcessRenderUpdates 3ms 时间片
```

### 4.4 编辑管线一致性

**所有触发 chunk 重建的路径统一经过 `BuildChunkContext`** -> 自动注入当前 Slice 快照：

- 挖掘/放置单体素
- 笔刷编辑
- 选区填充/剪切/粘贴/移动
- 区域编辑

**关键效果**：挖掉切面层块后，下层原被遮挡的顶面在重建时按三域规则生成（下层是 Opaque，上方变 Air）-> 无破洞 ✓。

## 五、区域过滤

### 5.1 区域数据来源

`ComputeSliceAreaConfig()`（VoxelPreviewComponent）按优先级组装：

| 优先级 | 条件 | AreaMode | AABB 来源 |
|--------|------|----------|-----------|
| 1 | 当前选中区域 | 1 白名单 | 选中区域的 AreaCoverage 盒 |
| 2 | 玩家自有顶级区域 | 1 白名单 | 最近 8 个自有区域盒 |
| 3 | 无自有区域，排除别人的 | 2 黑名单 | 最近 8 个他人区域盒 |
| - | 都没有 | 0 全局 | - |

### 5.2 精确性

- 区域覆盖 `FAreaCoverageFragment` 本质是**体素索引空间轴对齐盒**（MinIndex/MaxIndex 闭区间 + CoreOffsetIndex）
- 逐体素判定 `IsInsideOrOn(盒)` = 精确范围，无不规则形状近似
- 区域盒上限 8 个（TakeNearest），与材质 Custom 节点上限一致；超出按距离取最近 8 个（已知近似，文档记录）

### 5.3 作用对象

| 对象 | 区域过滤方式 | 精确性 |
|------|-------------|--------|
| 体素地形 | CPU 逐体素世界索引 vs 区域盒 | 体素级精确 |
| 家具/生物 | 材质 Custom 节点逐像素 WorldPosition vs 区域盒 | 像素级精确 |

## 六、材质层

### 6.1 体素 Chunk 材质

| 材质 | 用途 | BlendMode | OpacityMask |
|------|------|-----------|-------------|
| `WorldTextureArray_Mat` | Section 0 不透明 | Masked | `DitherTemporalAA(CameraDepthFade × Color.A)` |
| `M_ChunkTranslucent`（新建） | Section 1 半透明 | Masked | `DitherTemporalAA(SliceOpacity(0.35) × CameraDepthFade × Color.A)` |

**关键改造**：移除原 `WorldTextureArray_Mat` 中的 Z 判定链（If_0/If_4/Multiply_2/Custom/Divide/Floor/Add/Multiply_5/WorldPosition 及 BasicZ/IsCheckZTrans/Area*/BlockLength 参数）-> Z 判定改由 CPU 三域分流负责，材质去参数化。

**纹理参数名统一**：`Color/Rough/Normal` -> `BaseColorArray/NormalArray/ORMArray`（对齐 C++ `GetSharedChunkMID` 设置的参数名）。

### 6.2 家具/生物材质

新建 **`MF_SliceDither` 材质函数**（从原 WorldTextureArray_Mat 迁移区域过滤逻辑）：

```
输入：WorldZ, BasicZ, IsCheckZTrans, AreaMode, AreaCount, AreaBoxMin_0..7, AreaBoxMax_0..7
逻辑：
  - AreaFilter = Custom HLSL（白名单/黑名单逐盒判定）
  - SliceActive = IsCheckZTrans × AreaFilter
  - VoxelLayerTop > BasicZ -> 半透明阈值
  - 输出：抖动遮罩（0=裁掉, 1=不透明, 0.35=半透明）
```

接入：
- `M_Furniture`：插入 MF_SliceDither -> OpacityMask，BlendMode -> Masked
- 生物材质（Material_004/019 等）：同样接入 MF_SliceDither

### 6.3 SharedChunkMID 污染修复

**根因**：`ApplySliceToFurnitureAndCreatures` 遍历全场景 AActor，包含 AGreedyChunk -> 每 chunk 按自身位置向共享 SharedChunkMID 覆写 IsCheckZTrans -> last-writer-wins -> PlayerManaged 白名单模式下绝大多数 chunk 在区域外 -> 全局开关被置 0 -> BasicZ 改了也无效。

**修复**：`ApplySliceToActor` 增加 `Actor->IsA<AGreedyChunk>()` 跳过判定。
