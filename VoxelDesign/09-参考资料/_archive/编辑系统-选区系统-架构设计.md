## 1. 组件架构

### 1.1 整体架构层次

```
┌─────────────────────────────────────────────────────────────┐
│ 第一层：核心数据层                        │
│                                                             │
│  FVoxelSelection（选区数据结构）                             │
│  • SelectedVoxels: TSet<FIntVector>                         │
│  • Bounds: FAreaCoverageFragment                            │
│  • CreationTime: FDateTime                                  │
│  • ModificationHistory: TArray<FSelectionChange>            │
│                                                             │
│  职责：存储选区状态,提供访问接口                             │
└──────────────────────────┬──────────────────────────────────┘
                           ↑ 被修改
                           │
┌──────────────────────────┴──────────────────────────────────┐
│ 第二层：选区工具层                 │
│                                                             │
│  ┌──────────┬──────────┬──────────┬────────────────────┐   │
│  │ 单点工具  │ 几何工具  │ 笔刷工具  │ 魔棒工具            │   │
│  └──────────┴──────────┴──────────┴────────────────────┘   │
│                                                             │
│  职─────────────────────────────────────────────────────┐   │
│  │ IVoxelSelectionDefiner（统一接口）                   │   │
│  │  • DefineSelection() 定义选区                       │   │

│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  职责：提供不同的选区定义方式,修改第一层数据                   │
└──────────────────────────┬──────────────────────────────────┘
                           │ 操作

┌──────────────────────────┴──────────────────────────────────┐
```

### 1.2 组件职责描述

#### **FVoxelSelection（选区数据）**

**职责**:
- 存储当前选中的体素集合
- 提供选区访问接口
- 记录选区修改历史
- 管理选区生命周期

**关键属性**:
```cpp
struct FVoxelSelection
{
    TSet<FIntVector> SelectedVoxels;      // 选中的体素
    FAreaCoverageFragment Bounds;         // 包围盒
    FDateTime CreationTime;               // 创建时间
    TArray<FSelectionChange> History;     // 修改历史
};
```

#### **单点工具 (UVoxelSinglePointSelector)**

**职责**:
- 处理单体素选择
- 最简单的选区定义方式
- 不支持实时调整

**特点**:
- 点击即选中
- 切换模式自动清空
- 支持布尔运算

#### **几何工具 (UVoxelGeometrySelector)**

**职责**:
- 通过数学参数定义形状选区
- 支持三维几何(盒、球、圆柱)
- 支持二维几何(矩形、圆形)
- 支持多边形

**特点**:
- 参数化定义
- Gizmo实时调整
- 切换模式保留

#### **笔刷工具 (UVoxelBrushSelector)**

**职责**:
- 通过涂抹轨迹定义选区
- 支持固定形状(圆形、方形)
- 支持滚轮缩放大小

**特点**:
- 自由绘制
- 持续修改
- 切换模式保留
- 支持布尔运算

#### **魔棒工具 (UVoxelMagicWandSelector)**

**职责**:
- 从起始点自动扩散选区
- 基于连通性(Flood Fill)
- 支持类型匹配

**特点**:
- 智能扩展
- 连通性检测
- 切换模式保留
- 支持布尔运算

#### **移动工具 (UVoxelMoveOperation)**

**职责**:
- 移动选中的体素到新位置
- 支持三轴Gizmo交互
- 支持精确输入

**依赖**:
- 必须有预选区

#### **复制/粘贴工具 (UVoxelCopyPasteOperation)**

**职责**:
- 复制选中体素到剪贴板
- 粘贴到目标位置
- 支持多次粘贴

**依赖**:
- 复制必须有预选区
- 粘贴不需要预选区

#### **删除工具 (UVoxelDeleteOperation)**

**职责**:
- 删除选中的体素
- 显示确认对话框
- 支持撤销

**依赖**:
- 必须有预选区

#### **替换工具 (UVoxelReplaceOperation)**

**职责**:
- 替换选中体素的类型
- 支持材质选择
- 支持撤销

**依赖**:
- 必须有预选区

#### **填充工具 (UVoxelFillOperation)**

**职责**:
- 在选区内执行填充操作
- 支持四种模式: 填充、替换、删除、完全修改
- 支持撤销

**依赖**:
- 必须有预选区

#### **保存模板工具 (UVoxelSaveTemplateOperation)**

**职责**:
- 将选中体素保存为模板
- 生成预览缩略图
- 保存到模板库

**依赖**:
- 必须有预选区
- 关联蓝图系统

### 1.3 组件依赖关系

```
FVoxelSelection（核心数据）
    ↑ 被修改
    │
选区工具层
    ├─ 单点工具 → FVoxelSelection
    ├─ 几何工具 → FVoxelSelection
    ├─ 笔刷工具 → FVoxelSelection
    └─ 魔棒工具 → FVoxelSelection
    ↓

    ├─ 移动工具 ⇒ FVoxelSelection
    ├─ 复制工具 ⇒ FVoxelSelection

    ├─ 填充工具 ⇒ FVoxelSelection
    └─ 保存模板工具 ⇒ FVoxelSelection
    ↓

```

## 2. 接口定义

### 2.1 选区定义器接口

```cpp
/**
 * 选区定义器 - 统一抽象
 */
class IVoxelSelectionDefiner
{
public:
    /**
     * 定义选区
     * @param WorldContext 世界上下文
     * @return 选中的体素集合
     */
    virtual TSet<FIntVector> DefineSelection(
        const FVoxelWorldContext& WorldContext
    ) = 0;

    /**
     * 获取选区包围盒
     */
    virtual FAreaCoverageFragment GetBounds() const = 0;

    /**
     * 是否支持实时调整
     */
    virtual bool SupportsRealtimeAdjustment() const = 0;

    /**
     * 切换模式是否保留
     */
    virtual bool PersistsAcrossModes() const = 0;

    /**
     * 是否支持布尔运算
     */
    virtual bool SupportsBooleanOps() const = 0;
};
```

### 2.2 布尔运算接口

```cpp
/**
 * 布尔运算模式
 */
enum class ESelectionBooleanMode : uint8
{
    New,        // 新选：清空旧选区，创建新选区
    Add,        // 加选：并集（新选区 ∪ 旧选区）
    Subtract,   // 减选：差集（旧选区 - 新选区）
    Intersect   // 交集：新选区 ∩ 旧选区
};

/**
 * 布尔运算执行器
 */
class UVoxelBooleanExecutor
{
public:
    /**
     * 执行布尔运算
     * @param OldSelection 旧选区
     * @param NewSelection 新选区
     * @param Mode 运算模式
     * @return 运算后的选区
     */
    static TSet<FIntVector> ExecuteBooleanOp(
        const TSet<FIntVector>& OldSelection,
        const TSet<FIntVector>& NewSelection,
        ESelectionBooleanMode Mode
    );
};
```

### 2.3 操作工具接口

```cpp
/**
 * 选区操作工具 - 基础接口
 */
class IVoxelSelectionOperation
{
public:
    /**
     * 验证是否可以执行操作
     */
    virtual bool CanExecute(
        const FVoxelSelection& Selection
    ) const = 0;

    /**
     * 执行操作
     */
    virtual FVoxelEditModification Execute(
        const FVoxelSelection& Selection,
        UVoxelBlockWorldSubsystem* BlockWorld
    ) = 0;

    /**
     * 是否需要预选区
     */
    virtual bool RequiresSelection() const = 0;
};

/**
 * 直接操作工具 - 基础接口
 */
class IVoxelDirectOperation
{
public:
    /**
     * 执行操作
     */
    virtual FVoxelEditModification Execute(
        const FVoxelOperationParams& Params,
        UVoxelBlockWorldSubsystem* BlockWorld
    ) = 0;

    /**
     * 操作后是否自动生成选区
     */
    virtual bool AutoGeneratesSelection() const = 0;
};
```

## 3. 数据流

### 3.1 选区构建流程

```
用户操作（点击/拖拽/Gizmo）
    ↓
检测布尔运算模式
├─ 无修饰键 → ESelectionBooleanMode::New
├─ Shift → ESelectionBooleanMode::Add
├─ Alt → ESelectionBooleanMode::Subtract
└─ Shift+Alt → ESelectionBooleanMode::Intersect
    ↓
选区工具定义新选区
├─ 单点工具 → {Point}
├─ 几何工具 → CalculateShapeVoxels()
├─ 笔刷工具 → CalculateBrushVoxels()
└─ 魔棒工具 → FloodFillSelection()
    ↓
布尔运算执行
NewSelection ⊕ OldSelection → ResultSelection
    ↓
更新选区数据
FVoxelSelection::SelectedVoxels = ResultSelection
    ↓
更新历史
FVoxelSelection::History.Add({Operation, Timestamp, Count})
    ↓
触发UI更新
VisualUIComponent::UpdateSelectionHighlight()
```

### 3.2 选区操作流程

```
用户选择操作工具
    ↓
检查选区
IF Selection.IsEmpty() THEN
    提示"请先选择区域"
    RETURN
END IF
    ↓
执行操作
Operation.Execute(Selection, BlockWorld)
    ↓
生成历史记录
HistoryRecord = CreateHistoryRecord(Operation, Selection)
    ↓
执行编辑
BlockWorld::BatchModifyVoxelData_Modification(Modification)
    ↓
保存到撤销栈
HistoryComponent::PushToUndoStack(HistoryRecord)
    ↓
选区处理
├─ 保留选区（默认）
└─ 或清空选区（可选）
```

### 3.3 直接操作流程

```
用户选择直接操作工具
    ↓
设置参数
├─ 新增体素：选择材质
├─ 几何体：选择形状、调整参数
└─ 蓝图：选择模板、定位
    ↓
执行操作
Operation.Execute(Params, BlockWorld)
    ↓
生成编辑结果
Modification = Operation.GetResult()
    ↓
生成历史记录
HistoryRecord = CreateHistoryRecord(Operation)
    ↓
自动生成选区
FVoxelSelection::SelectedVoxels = Modification.GetAffectedVoxels()
    ↓
触发UI更新
VisualUIComponent::UpdateSelectionHighlight()
```

## 4. 生命周期管理

### 4.1 选区数据生命周期

```
未初始化（Uninitialized）
    ↓ 首次选择操作
激活（Active）
    ↓ 持续修改（布尔运算）
    ↓ 手动清空或切换直接操作工具
未初始化
```

**各阶段功能**：

**未初始化**
- 功能：无有效选区
- 限制：选区操作工具不可用

**激活**
- 功能：有有效选区
- 可用操作：所有选区操作工具
- 持久化：切换工具保留

### 4.2 选区工具生命周期

```
未激活（Inactive）
    ↓ 工具切换
激活（Active）
    ↓ 用户交互
定义中（Defining）
    ↓ 用户确认
完成（Completed）
    ↓ 工具切换
未激活（Inactive）
```

**各阶段功能**：

**未激活**
- 功能：工具未使用
- 限制：不响应输入

**激活**
- 功能：等待用户输入
- 状态：无有效选择

**定义中**
- 功能：实时显示选择预览
- 限制：不能执行其他操作

**完成**
- 功能：已生成选区
- 可用：切换到其他工具

### 4.3 操作工具生命周期

```
未激活（Inactive）
    ↓ 工具切换
激活（Active）
    ↓ 执行操作
完成（Completed）
    ↓ 工具切换
未激活（Inactive）
```

**选区操作工具**：
- **激活**：必须有选区才能激活
- **完成**：执行完成后自动切换回未激活

**直接操作工具**：
- **激活**：随时可以激活
- **完成**：执行后自动生成选区

## 6. 工具切换规则

### 6.1 切换矩阵

| 从 \ 到 | 选区工具 | 选区操作工具 | 直接操作工具 |
|---------|---------|-------------|-------------|
| **选区工具** | 保留选区 | 保留选区 | 保留选区（提示） |
| **选区操作工具** | 保留选区 | 保留选区 | 保留选区（提示） |
| **直接操作工具** | 保留选区 | 保留选区 | 替换选区 |

### 6.2 切换提示

**情况1：选区工具 → 直接操作工具**
```
用户在"几何选区"模式
当前有选区（150体素）
    ↓
用户切换到"新增体素"工具
    ↓
提示："当前选区将被保留，可用其他方式修改"
    ↓
选项：
├─ [继续] - 保留选区
├─ [清空] - 清空选区
└─ [取消] - 不切换工具
```

**情况2：直接操作工具 → 直接操作工具**
```
用户在"几何体建造"模式
当前有自动生成的选区（200体素）
    ↓
用户切换到"新增体素"工具
    ↓
自动清空旧选区
    ↓
新操作将生成新选区
```

## 7. 扩展点

### 7.1 新增选区工具

**步骤**：
1. 继承 `IVoxelSelectionDefiner`
2. 实现 `DefineSelection()` 方法
3. 在工具注册系统中注册

**示例**：
```
class UVoxelLassoSelector : public IVoxelSelectionDefiner
{
    TSet<FIntVector> DefineSelection(...) override
    {
        // 套索选择逻辑
    }
};
```

### 7.2 新增操作工具

**选区操作**：
1. 继承 `IVoxelSelectionOperation`
2. 实现 `Execute()` 方法
3. 必须有选区才能执行

**直接操作**：
1. 继承 `IVoxelDirectOperation`
2. 实现 `Execute()` 方法
3. 自动生成选区
