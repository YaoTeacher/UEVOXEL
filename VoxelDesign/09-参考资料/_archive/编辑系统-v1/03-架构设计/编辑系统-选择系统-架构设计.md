## 1. 组件架构

### 1.1 组件层次结构

```
选择系统
├── 选择工具基类（SelectionTool Base）
│   └── 定义统一接口和通用逻辑
├── 框选工具（Box Selection Tool）
│   └── 包围盒选择实现
├── 魔棒工具（Magic Wand Tool）
│   └── 连通性选择实现
└── 多边形工具（Polygon Tool）
    └── 多边形区域选择实现
```

### 1.2 组件职责描述

**选择工具基类**
- 定义选择操作的统一接口
- 管理选中体素集合（`SelectedVoxels`）
- 管理选中包围盒（`SelectionBounds`）
- 提供选择后的操作接口（复制、删除、保存模板）

**框选工具**
- 通过两个点定义包围盒
- 遍历包围盒内的体素
- 支持按类型过滤（只选特定方块）
- 支持反选操作

**魔棒工具**
- 从起始点扩散连通区域
- 匹配相同类型的方块
- 使用广度优先搜索
- 支持 Flood Fill 算法

**多边形工具**
- 通过多个顶点定义多边形
- 使用点在多边形内算法
- 支持任意形状选择

### 1.3 组件依赖关系

```
UVoxelSelectionTool（基类）
    ↑ 继承
    |
    ├── UVoxelBoxSelectionTool
    ├── UVoxelMagicWandTool
    └── UVoxelPolygonTool

依赖关系：
选择工具 → VoxelBlockWorldSubsystem（读取方块）
选择工具 → FVoxelBuildingTemplate（生成模板）
选择工具 → FVoxelEditModification（生成修改）
```

## 2. 接口定义

### 2.1 选择工具基类接口

```
class UVoxelSelectionTool : public UVoxelToolBase
{
    // === 状态查询 ===

    /**
     * 获取选中的体素集合
     */
    TSet<FIntVector> GetSelectedVoxels() const;

    /**
     * 获取选中包围盒
     */
    FAreaCoverageFragment GetSelectionBounds() const;

    /**
     * 检查是否有有效选择
     */
    bool HasValidSelection() const;

    /**
     * 获取选中的体素数量
     */
    int32 GetSelectedCount() const;

    // === 选择操作 ===

    /**
     * 清除选择
     */
    void ClearSelection();

    /**
     * 反选
     */
    void InvertSelection();

    // === 选择后操作 ===

    /**
     * 将选中内容复制为修改数据
     * @param BlockWorld 用于读取方块类型
     * @return 修改数据（包含方块映射和区块索引）
     */
    FVoxelEditModification CopySelected(
        UVoxelBlockWorldSubsystem* BlockWorld);

    /**
     * 将选中内容删除为修改数据
     * @param BlockWorld 用于读取方块类型
     * @return 修改数据
     */
    FVoxelEditModification DeleteSelected(
        UVoxelBlockWorldSubsystem* BlockWorld);

    /**
     * 将选中内容保存为模板
     * @param BlockWorld 用于读取方块类型
     * @param TemplateName 模板名称
     * @param AuthorName 作者名称
     * @return 模板数据
     */
    FVoxelBuildingTemplate SaveAsTemplate(
        UVoxelBlockWorldSubsystem* BlockWorld,
        FString TemplateName,
        FString AuthorName);
};
```

### 2.2 框选工具接口

```
class UVoxelBoxSelectionTool : public UVoxelSelectionTool
{
    /**
     * 设置包围盒（两个点定义）
     * @param PointA 起点（世界坐标索引）
     * @param PointB 终点（世界坐标索引）
     */
    void SetBoundingBox(
        FIntVector PointA,
        FIntVector PointB);

    /**
     * 根据包围盒选择体素
     * @param Bounds 包围盒
     * @param BlockWorld 用于读取方块类型
     * @param bIncludeAir 是否包含空气方块
     */
    void SelectFromBoundingBox(
        FAreaCoverageFragment Bounds,
        UVoxelBlockWorldSubsystem* BlockWorld,
        bool bIncludeAir = false);

    /**
     * 根据包围盒选择特定类型的体素
     * @param Bounds 包围盒
     * @param BlockWorld 用于读取方块类型
     * @param BlockType 方块类型（空表示所有类型）
     */
    void SelectFromBoundingBoxByType(
        FAreaCoverageFragment Bounds,
        UVoxelBlockWorldSubsystem* BlockWorld,
        FGameplayTag BlockType);
};
```

### 2.3 魔棒工具接口

```
class UVoxelMagicWandTool : public UVoxelSelectionTool
{
    /**
     * 从起始点执行魔棒选择
     * @param StartPoint 起始体素位置
     * @param BlockWorld 用于读取方块类型
     * @param bSameTypeOnly 是否只选择相同类型
     * @param MaxDepth 最大扩散深度
     */
    void SelectFromMagicWand(
        FIntVector StartPoint,
        UVoxelBlockWorldSubsystem* BlockWorld,
        bool bSameTypeOnly = true,
        int32 MaxDepth = 1000);
};
```

## 3. 数据流

### 3.1 框选流程

```
玩家操作（Gizmo拖拽）
  ↓
UVoxelBoxSelectionTool::SetBoundingBox()
  - 记录起点和终点
  - 计算包围盒
  ↓
UVoxelBoxSelectionTool::SelectFromBoundingBox()
  - 遍历包围盒内的体素坐标
  - 过滤空气方块（可选）
  - 存储到 SelectedVoxels
  - 计算包围盒 MinIndex/MaxIndex
  ↓
UVoxelControllerVisualUIComponent
  - 显示选择框预览
  ↓
完成：选择集可用
```

### 3.2 魔棒选择流程

```
玩家点击体素
  ↓
UVoxelMagicWandTool::SelectFromMagicWand()
  - 获取起始方块类型
  - 初始化 BFS 队列
  - 广度优先扩散：
    - 检查6个邻居
    - 匹配类型
    - 添加到队列
  - 去重处理
  ↓
输出：SelectedVoxels
```

### 3.3 保存模板流程

```
玩家确认保存
  ↓
UVoxelSelectionTool::SaveAsTemplate()
  - 计算包围盒Min角作为参考点
  - 遍历 SelectedVoxels
  - 转换为相对坐标（RelativePos = WorldPos - MinCorner）
  - 构建模板数据：
    - BuildingData（复用FVoxelEditModification）
    - TemplateName, AuthorName
    - CreationDate, VersionString
  - 添加到模板库
  ↓
输出：FVoxelBuildingTemplate
```

## 4. 生命周期管理

### 4.1 选择工具生命周期

```
未激活（Inactive）
  ↓ 工具切换
激活（Active）
  ↓ 玩家开始选择
选择中（Selecting）
  ↓ 玩家释放鼠标
选中完成（Selected）
  ↓ 保存/取消/执行操作
未激活（Inactive）
```

**各阶段功能**：

**未激活**
- 功能：工具未使用
- 限制：不响应输入

**激活**
- 功能：等待玩家输入
- 状态：无有效选择

**选择中**
- 功能：实时显示选择框
- 限制：不能执行其他操作

**选中完成**
- 功能：显示选中体素
- 可用操作：复制、删除、保存模板

## 6. 扩展点

### 6.1 新增选择方式

**步骤**：
1. 继承 `UVoxelSelectionTool`
2. 实现选择逻辑方法
3. 在 `VoxelEditorModeSubsystem` 中注册

**示例**：
```
class UVoxelLassoSelectionTool : public UVoxelSelectionTool
{
    void SelectFromLasso(
        TArray<FVector> Points,
        UVoxelBlockWorldSubsystem* BlockWorld);
};
```

### 6.2 新增选择后操作

**步骤**：
1. 在基类中添加新操作方法
2. 提供默认实现或虚函数
3. 派生类可覆盖实现

**示例**：
```
// 基类添加
virtual FVoxelAreaData SaveAsArea(...);

// 派生类覆盖
FVoxelAreaData UVoxelBoxSelectionTool::SaveAsArea(...)
{
    // 自定义实现
}
```
