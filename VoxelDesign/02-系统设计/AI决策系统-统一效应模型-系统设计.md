## 1. 核心命题

**任何会改变实体的东西，成品只有两种形态：**

- **修改**：对数值的即时改变，应用即弃（账留在记忆层，数值留在容器里）
- **Buff**：挂进实体 Buff 列表的实例，自管生命周期（时长到期 / 条件失效 / 驱散）

来源只有区别，形态没有区别：

| 来源 | 例子 | 形态 |
|------|------|------|
| 种族/职业/特质（身份层） | 矮人 +体质；强壮 ×1.2 负重 | 常驻修改——不挂实例，读取时查配置 |
| 装备 | 铁剑 +攻击 | Buff（装备系统发放，穿着存续） |
| 记忆事件 | "他打过我" → 对他 −30 | 写入时发修改/Buff；唤起按条目快照重放打折（见记忆文档） |
| 阈值触发 | 饥饿过阈 → 效率 ×0.7 | Buff（条件存续，条件失效自消） |
| 环境/区域 | 丰收节物价 ×0.9 | Buff（区域系统扇出发放） |
| 瞬时事件 | 一次性扣血/扣钱 | 修改（应用即弃） |

旧版"时效策略四枚举（永久/衰减/条件/在场）"作废：时效不是效应的分类维度，是 Buff 实例的生命周期配置。**塑变/情绪/状态/特质只是内容层叫法，不是机制分类**——塑变 = 指向九维的修改；情绪 = 指向 Mood 的修改 + 承载语义与 Remedy 的 Buff；特质 = 身份层常驻修改包 + 获得规则。

## 2. 容器分离与万物可改

**可修改体接口**：任何可被修改的实体（NPC / 物品 / 区域 / 店铺……）= 一组 Tag 键控的命名容器 + 一个 Buff 列表。

- 容器三种：**数值容器**（Needs.Hunger、PersonalityDim.*、Item.Durability、Area.Safety）、**Tag 容器**（TraitTags、Item.Tags、Area.Tags）、**Map 容器**（关系 `TMap<对方ID,…>`、职业资格轨 `TMap<ProfessionTag,…>`）
- NPC 侧两个效应容器分离：**特质列表**（身份层，无生命周期，获得即常驻，读取时查配置）与 **Buff 列表**（运行时实例，自管生死）——统一的只是修改器结构与读取入口
- **万物可改，无例外名单**：身份轴（种族/性别/职业）、九维、关系程度、物品属性、区域属性都可以是修改目标；NPC = 基础数据（身份+七围+九维底子）+ 容器群 + Buff 列表

## 3. 修改器不寻址——"改谁"由挂载与发放决定

参照 GAS（GameplayEffect 无目标字段，Apply 到谁的 ASC 就改谁）与 RimWorld（Hediff 挂在哪个 Pawn 就改谁）：**修改器只写"改哪个属性、怎么改"，不写"改谁"**。Tag 只回答"改哪个属性"，每种实体类型有自己的键命名空间（Creature.* / Item.* / Area.*）。

```
修改器（概念型）= { 键, 操作, 值, 条件 }     ← 无目标字段
  操作 = 数值: Add/Multiply/Override ｜ Tag 容器: Add/Remove ｜ Buff 列表: Grant/Remove(按键/按来源)
```

Map 容器需要第二维（关系的对方、职业的哪条轨）：**子键在发放时由发放端解析填入**，修改器结构不含角色枚举。

**统一管线（全游戏单入口）**：

```
触发源（事件/道具/装备/区域/特质/成长/剧本，各系统自己的发放端）
  → 发放端：解析目标实体列表 + 填子键（角色→具体实体→关系对方ID）
  → ApplyMods(实体, 修改列表)
       数值 → 立即结算进容器，应用即弃
       Tag  → 增/删
       Buff → 建实例挂入列表
  → 容器变更广播 → UI / AI / 需求系统刷新
```

跨实体效应全部在发放端完成：

- **社交事件**：角色（自己/施动者/受动者/在场者）写在**事件资产配置**里，触发时事件管线把角色解析成实体、逐个发修改/Buff
- **装备传导**：装备系统监听穿/脱，读物品"佩戴效应"配置 → 给穿戴者发 Buff（来源=该物品），脱下按来源移除
- **区域扇出**：区域 Buff 生效时给区域内实体逐个发 Buff（进区发、出区收），实体读取时只看自己

**来源追溯**：Buff 实例记来源{发放系统, 源实体/源Buff ID}；源消亡时广播，宿主按来源清理——链式生命周期（区域→店→人）解耦成单向通知。

**读取铁律**：任何实体算自己的有效值只读自己的容器 + 自己的 Buff 列表，不存在"沿区域→店铺→人找一圈"的归属链查询。

**引用值求值时机**：Buff/即时修改的引用值在**发放时**快照为常量（存续期内被引值变了不追溯，与强度快照同规则）；身份层常驻修改不挂实例、读取时从配置求值。

## 4. 读取与聚合

```
有效值(X) = (基础值 + Σ加) × Π乘，覆盖最后
Σ 来源 = 身份层配置的常驻修改（特质/种族，读配置）+ 活跃 Buff 实例（读列表，按强度快照折算）
钳制归属性定义（九维 ±50、需求 0~Max），不归修改器
```

- 决策系统与UI的效应数值只有这一个读取入口：关系值、Mood、面板属性、工作效率等；V1经营认知集合按§5直接读写，不走数值修改器聚合
- 聚合结果（CachedBaseAttributes 等）只允许作为**性能缓存**，随容器/Buff 列表变更失效重算；权威 = 容器 + 配置 + Buff 列表
- 档位（微醺/大醉）：累积量是 Dynamics 数值，Buff 配置声明"累积量区间 → 档位 → 各档修改器组"，实例侧零额外字段
- 驱散 = RemoveBuff 操作——驱散也是效应
- **白捡的能力**：性格可被临时修改（"喝醉时 Sociality 虚高" = 指向九维的 Buff）；性格塑变 = 指向九维的修改——基础层唯一回写通道走同一根管子

## 5. 集合的数值化（"修改任何数据"的边界）

修改器的数值操作只有加 / 乘 / 覆盖，适用于数值化的关系值、诉求计数器等容器（见记忆 / 关系文档），不将V1店铺认知强行数值化。

- V1 `KnownShopIds` 是NPC所有的 `TSet<BusinessEntityId>`，只记知道这家店铺生意，不是Area集合；仅老店预置、简化路过发现、交易完成写入，不经过记忆强度 / 衰减 / 锚定管线，不增加首客保护。
- `BusinessEntityId` 是全局稳定经营 ID（GUID，规则见[总纲 §2.7](/VoxelDesign/02-系统设计/AI决策系统-系统设计.md)）；不再使用 `ShopId` 别名。路过 / 导航另经经营实体区域组件取得 `AreaRef={SceneId,AreaId}`，Home / Work 仍空间。
- 完整版本认知强度与时间扩展留后续专项，不作为V1字段或修改器运行规则。经营资产 / 业务唯一归Global `BusinessEntities`，区域只空间 / 校验、不持业务镜像；本次只同步经营ID与认知边界，不改变其他效应管线。

## 6. 配置侧：效果是查出来的，不是存出来的

| Tag 种类 | 配置资产 | 现状 |
|---------|---------|------|
| `Trait.*` | `UCreatureTraitDefinition`（AttributeConfigs/DerivedFormulas/DemandConfigs/PersonalityModelPresets + 获得规则） | 已有 |
| `Race/Profession` | 种族/职业模板 | 已有 |
| `Buff.*` | **UBuffDefinition（新建）**：修改器组 + 生命周期（时长/条件/衰减）+ 档位区间 + RemedyTag + 外化引用 | 待建 |
| `Memory.*`（记忆解读） | **UEventInterpretationSet 解读规则集**（挂 Event.* Tag 层级继承，见记忆模型 §3） | 待建 |
| `Equip.*` | 物品定义（佩戴效应由装备系统转发） | 已有 |
| `Area.*` | 区域配置 + 区域自身 Buff 列表 | 待建 |

配置是单一事实源：改一处配置，全图实体效果一起变；存档只存 Buff 实例 {配置引用, 强度快照, 激活时间, 来源} + 容器当前值，轻巧且耐配置变更。

## 7. 与记忆层的接口

条目建成时，解读输出**当场求值并整体快照**（修改器组 + 强度标量）写入记忆条目，发放走 ApplyMods（带来源事件ID）。**唤起 = 按条目快照重放**（普通记忆打折，锚点不打折），不回头查规则、不查配置——规则改动与性格漂移不影响旧记忆。条目消亡与事实休眠归事件系统 §8。细节归《AI决策系统-记忆模型-系统设计.md》。

## 8. 修改器数据结构（未定稿，数据设计环节再定）

概念结构已定（§3：键/操作/值/条件，无目标字段）；**具体字段组织未定稿**。参考草案：

```
FModCommand {
  键:   FGameplayTag        // 前缀即容器类型
  子键: 可选（Map 容器用，发放端填）
  操作: Add | Multiply | Override | AddTag | RemoveTag | GrantBuff | RemoveBuff
  值:   常量 | 引用{源编址, 系数, 平移} | 曲线资产 | Buff 参数{资产Tag, 强度, 时长}

}
```
