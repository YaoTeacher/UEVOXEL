## 1. 系统边界

**负责**：屏幕分区的语义与判据、经营/建造/探索三模式的分区内容、锚与底带的内容来源规则、检查器与容器的职责分工、身份裁剪、时间与时停规则。

**不负责**：经营业务规则（[经营操作卷](/VoxelDesign/02-系统设计/AI决策系统-经营操作-系统设计.md)）、组件与生命周期（[UI 系统架构设计](/VoxelDesign/03-架构设计/UI系统-架构设计.md)）、控件样式与主题（`DA_VoxelUITheme`，见项目 AGENTS.md）。

## 2. 六区模型

屏幕由六个分区构成，三个模式共用同一套分区，只换内容。

| 分区 | 语义 | 判据 | 是否随选中变化 |
|---|---|---|---|
| **锚** | 你在哪、你有什么 | 玩家当前的身份与地点 | **不变** |
| **检查器** | 你正看着的这一个是什么 | 世界中选中的单个对象 | **变** |
| **世界** | 世界与镜头 | 全局 | 不变 |
| **底带** | 这个模式里的主动作 | 当前模式 + 锚的主域 | 随主域变，不随点选变 |
| **个人域** | 跨区域都成立的我自己 | 玩家本人 | 不变 |
| **容器** | 入口点开之后的地方 | 由入口决定 | 变 |

两条硬规则：

1. **锚不随选中变，检查器随选中变。** 点任何东西都不改变锚；锚只在玩家切换主域时变。
2. **检查器跨模式只有一套卡。** 角色卡在经营模式点员工、在探索模式点队友是同一张卡，只是可用动作不同。

## 3. 三模式 × 六区

| 分区 | 经营 | 建造 | 探索 |
|---|---|---|---|
| **锚** | 我的产业：主域切换、资金、客流、口碑星级、营业灯、设置组 | 同一产业锚 + 退出建造 | 场景锚：场景名、环境、危险度、目标进度、扎营、切换场景 |
| **检查器** | 区域（非自有）、子区域、家具、角色、体素选区 | 当前工具参数 / 选中的家具与区域 | 队友、敌人、物体、区域 |
| **世界** | 时钟、日历、小地图、渲染图层、剖切框、倍速、镜头高度 | 同左 + 建造暂停提示 | 场景坐标、危险度、小地图、视野 |
| **底带** | 业务按键（作用对象 = 锚的主域） | 工具带 + 确认 / 取消 | 队伍头像 + 快捷道具 + 行动条 |
| **个人域** | 资产、背包、任务、认识、势力 | 同左 | 同左 |
| **容器** | 业务列表页（列表行在容器内展开，不改检查器） | 材料库、历史记录 | 对话、技能表 |

**建造模式下的检查器**：工具参数与选中对象共用同一块位置，二选一显示——选中了对象显示对象卡，没选中显示当前工具参数。不允许同一边角同时挂两块面板。

## 4. 锚

**内容来源** = 主域类型 × 我的身份。

### 4.1 摘要行

| 主域类型 | 摘要 |
|---|---|
| 店铺 / 摊位 | 资金、收入/时、营业灯、满意度、客流、**在岗 n/m（点开人员页）**、**缺货（点开货页）**、口碑星级 |
| 商圈 | 资金、收入/时、商铺数、客流、满意度 |
| 旅店 | 同店铺 + 入住率 |
| 住房 | 资金、租金、租客、到期 |
| 公共设施（后续版本） | 资金、使用人次、维护状态 |
| 探索（锚换内容） | 场景名、环境、危险度、目标进度 |

### 4.2 设置组

固定在锚内的低频入口，按经营与空间归属分别提交：

| 入口 | 覆盖 | 可见/授权来源 |
|---|---|---|
| 编辑业务 | 经营实体名称/LOGO；子区域空间名称/类型 | 实体有效经营关系允许的产权人/经营人 |
| 权限 | 空间准入类别、战斗许可、默认访问，不赋予产权或经营身份 | 有效授权 |
| 营业时段 | 经营实体的周营业时间 | 相应经营权限，非区域字段 |
| 开业 / 停业 | 独立操作，只手动写入并存档 bOpen | 当前有效经营人，创建默认 false |
| 产权 / 租约 / 任命 | 专用业务流程，不能通过普通资料 Setter 变更 | 各业务有效授权 |
| 定位 | 有 AreaRef 时聚焦真实空间；图外无空间不提供 | 任何可见该空间者 |

**装修不进锚**。进入建造模式就是装修，入口是底带的模式段控，不设第二个装修入口。

### 4.3 主域

- 主域 = 玩家当前管理的经营实体，按 `Global.BusinessEntities` 与有效经营关系切换；商圈、店铺、图外生意共用基础模型并按类型组合模块，经营实体是资产与业务唯一所有者。
- `BusinessEntityId` 全局稳定（GUID，规则见[总纲 §2.7](/VoxelDesign/02-系统设计/AI决策系统-系统设计.md)）；不使用 `ShopId` 别名。空间组件可选，引用 `AreaRef={SceneId,AreaId}`；区域树只是空间导航，子区域有 AreaId 不是经营实体。
- 主域只列我通过有效产权/经营关系有权管理的主体，别人或我仅打工的店不进锚；没有主域时保留世界区与个人域。
- 经营与空间注册/存档分别编排，不从区域树镜像产业登记；区域仅范围/父子/定位/准入校验，不持 Owner/Manager 权属、bOpen、目录、订单、声誉或租约。
- 建造同一侧栏拉范围/摆模板预览 → 填名称、类型/业态、经营意图等 → 单次 Confirm 概念请求 CreateBusinessWithArea（OperatorId、BusinessKind、Name、BusinessIntent、ParentBusinessEntityId、空间草稿等；请求 class 待定）→ Controller→业务门面→实体/空间存储→事件→UI，创建实体、空间、关系、必要 Lease/首期；先有效 Lease 后真写租户建筑/家具，不跳详情补建生意、不手动绑定。子区域只创建空间、关联现有主体。
- 产权/经营人由有效授权及租约/任命设定，不自由填值；普通资料仍名称/LOGO等，合同不走普通 Setter。M13a 纯导航是待迁移代码事实，不限制最终创建。
- V1 只预置商圈玩家标准租杂货店；NPC 空店/模板邀请同一连续面板，候选同意条款及产权授权后先 Lease 再真落位，NPC 模板招商/完整客房后续。住客限时使用而非客房 Manager，门按有效授权查询。换租户沿用同一经营实体、删区域不注销实体（已定）；招图外换工待定。

## 5. 底带

### 5.1 构成（经营模式）

只有一个左对齐的组：**作用域标签 + 业务按键**（见 5.2）。

模式切换、时间、在岗人数都不在这里——它们各有唯一入口：

| 东西 | 唯一入口 |
|---|---|
| 经营 ⇄ 建造 | 锚的「建造 / 退出建造」按钮 |
| 进探索 | 小地图 → 大地图 → 选目的地旅行（回主地图用锚的「⏏ 主地图」） |
| 时间暂停与倍速 | 环境卡的时钟本身（点开） |
| 在岗人数 | 锚摘要行的「🧑‍🍳 n/m」，点开人员页 |

### 5.2 业务按键来源

按键集合 = **主经营实体类型 × 有效经营关系/授权 × 该实体组合模块具备的能力**，三者取交集，不按空间区域身份判断。

| 按键 | 店铺/摊位 | 旅店 | 商圈 | 住房 | 公共设施 |
|---|:--:|:--:|:--:|:--:|:--:|
| **人员** | ✓ | ✓ | ✓ | — | — |
| **货** | ✓ | ✓（房型、房价、预订与入住） | — | — | — |
| **资产** | — | — | ✓（租约、维修工单） | ✓（租约） | — |
| **活动** | ✓ | ✓ | ✓（集市、节庆、摊位） | — | — |
| **许可** | ✓ | ✓ | ✓ | ✓ | ✓ |
| **统计** | ✓ | ✓ | ✓ | ✓ | ✓ |

店铺 5 键、商圈 5 键、住房与公共设施 2 键。**旅店的预订列表在"货"里**，不单独开键——预订只能当面办理，店里需要的只是订单表。

> **V1 边界**：上表为通用能力分类，V1 只预置商圈玩家标准租杂货店；旅店/住房/完整客房、NPC 模板招商、公共设施及其按钮均留后续版本，不由此表增加 V1 场景。资产页按已确认范围保留租约列表/维修工单。bOperating=bOpen&&有效时段 纯派生，只 bOpen 手动且入档，无自动资格复检。

### 5.3 底带不做的事

- 不放"改区域字段"的入口（那些在锚的设置组）；
- 不放层级很深的列表（列表在容器里）；
- 不因世界中点选而换内容（只有主域切换才换）；
- **不放模式段控与时间**：两者已在别处各有一个入口，底带再放一份就是双份状态；
- **不放人员头像行**：店铺十余人时横排放不下，人数是状态不是列表，留在锚的摘要行。

## 6. 检查器

### 6.1 装什么

| 对象 | 卡片内容 |
|---|---|
| 经营实体（可通过真实空间选中） | 经营模块的营业/时段/目录/声誉及有效产权人/经营人；空间准入另查 AreaRef，按查看权限/认识度裁剪，不把营业或权属归区域 |
| 子区域 / 家具 | 类型、功能、状态槽、占用 |
| 角色 / 敌人 / 队友 | 认识度、九维、属性、需求、状态、记忆、关系 |
| 体素选区 | 范围、材料、数量 |

### 6.2 卡片只放两样东西

1. **信息**（上面这些）；
2. **此刻能对它做的 1~3 个动作**：是我的 → 「管理」跳锚主域；我在打工 → 「我的班次」；我只是顾客 → 「进去消费」/「预订」；商圈管理人对租户 → 「查看租约」。

检查器**不放完整功能列表**。功能入口在锚和底带，检查器不重复。

### 6.3 检查器与容器的分工

| 来源 | 详情在哪 |
|---|---|
| 在世界里点选 | 检查器 |
| 在容器的列表里点一行 | 容器内展开（不改检查器） |

理由：世界里点选带空间上下文，列表里点行带表格上下文。两个详情面分开，避免同一次点击在两处各弹一次。

## 7. 容器

业务按键点开的列表页住这里。**统一居中面板**，不再是侧边抽屉：普通宽度 760，含表格的用 880，高度上限 640（超出在面板内滚动）。

- 所有弹出（业务列表、大地图、收购地契、区域表单、NPC 对话）同一套几何：居中、圆角、同宽档位、共用一层遮罩；
- 遮罩挡住世界里的一切交互；点遮罩、ESC、右上 ✕ 三者都能关；
- 面板叠面板时（例如资产页里点收购地契），后开的盖在前面的上面，关闭后回到前一个；

| 入口 | 列表 |
|---|---|
| 人员 | 名册、劳动安排矩阵（排班 / 工作优先级）、工单 |
| 货 | 商品目录、采购与在途、补货规则；旅店为房型 + 预订 |
| 资产 | 租约列表、维修工单 |
| 活动 | 进行中 / 已完成活动 |
| 许可 | 许可清单（已获得 / 可申请 / 条件不足） |
| 统计 | 业务 / 资金 / 人员 / 口碑 / 营销五段，口碑按群体轴切换 |

全屏模态只留给需要专注确认的打断性操作（收购地契、转让所有权、区域业务表单），日常经营操作不进全屏。

**为什么不用侧边抽屉**：侧边抽屉只遮住屏幕一条边，剩下的空间看起来可点但实际是死的；同一份列表在两个位置（右侧抽屉 / 居中模态）出现，玩家要记两套关闭方式。统一居中后只有一种形态。

## 8. 个人域

固定在左侧竖排，跨三个模式都在：

| 入口 | 内容 |
|---|---|
| **资产** | 初始人物持有的两钱包/业务账户（余额 + 有效权限）、我的实物资产与合同记录、划转；物品/结构产权日志保留独立来源，不因空间包含转移租户资产 |
| **背包** | 物品 |
| **任务** | 进行中任务与势力委托 |
| **认识** | 我认识的人与认识程度 |
| **势力** | 四势力关系值、等级、当前 BUFF、近期互动 |

初始两钱包/业务账户由人物持有，账户查看与划转按有效业务权限；经营实体引用业务所需账户，区域不持资金真值。实物资产产权按独立日志/合同记录，不因归入空间范围转移。

## 9. 身份裁剪

同一份数据按身份裁显示范围，不同身份不共用同一套按钮：

| 身份 | 锚 | 底带业务键 | 检查器 |
|---|---|---|---|
| **有效产权人** | 有，仅产权及授权范围；不当然拥有经营操作 | 按实体模块与授权裁剪；仅兼经营人时可开关店 | 按有效查看权限 |
| **有效经营人** | 有，不含产权转让 | 按经营关系与组合模块裁剪 | 按有效查看权限 |
| **雇员** | 无，不列我仅打工的店 | 我的班次与工单等劳动范围 | 公开店铺信息及本人劳动信息 |
| **路人 / 限时住客** | 无 | 无产业管理键 | 按公开信息/认识度/有效限时使用授权裁剪，住客不是客房 Manager |

**不做的做法**：让雇员看到店主的完整面板但把按钮置灰。看见即知情，置灰等于泄露经营情报。

---

## 10. 时间与时停

- **打开任何面板都不暂停时间**，靠暂停键与倍速自己控（双点医院、RimWorld、矮人要塞、过山车之星同做法）；
- **建造模式暂停**（沿用现有实现，`DefaultEngine.ini` 与建造流程已有）；
- 检查器、容器、模态都不改变时间流速；
- ESC 逐层关闭：模态 → 容器 → 检查器卡片 → 暂停菜单。
