## 1. 系统上下文

### 1.1 系统边界

**阵列系统负责**：
- 配置阵列放置参数（步长、间隔、朝向等）
- 计算阵列中的所有定位点
- 支持多种分布模式（直线、圆形、曲线）
- 提供定位点的朝向控制

**阵列系统不负责**：
- 模板数据的生成（由模板系统负责）
- 网格渲染（由预览系统负责）
- 体素世界修改（由BlockWorldSubsystem负责）

### 1.2 外部依赖

**依赖的系统**：
- **模板系统**：提供模板数据和基础网格
- **预览系统**：显示阵列预览
- **编辑执行系统**：执行最终的体素修改

**被依赖的系统**：
- **UI系统**：阵列配置面板
- **预览系统**：更新阵列预览显示

### 1.3 输入输出

**输入**：
- 阵列配置（步长、间隔、朝向、曲线类型）
- 起点和终点（世界坐标）
- 模板数据（用于计算尺寸）

**输出**：
- 定位点数组（位置 + 旋转）
- 阵列预览更新请求

## 2. 核心概念

### 2.1 基础概念

**定位点（PlacementPoint）**
- 定义：阵列中单个模板实例的位置和朝向
- 组成：世界坐标位置、离散朝向（6个值）
- 用途：阵列预览和建造的基本单位

**步长（Stride）**
- 定义：相邻两个实例之间的距离
- 类型：FLOAT（米）
- 计算：根据模板尺寸和玩家配置

**间隔模式（Pattern）**
- 定义：生成实例的重复模式
- 格式：数组 `[生成N个, 跳过M个]`
- 示例：`[3, 2]` = 生成3个，跳过2格

**离散朝向（DiscreteRotation）**
- 定义：体素的6个标准朝向
- 取值：`+X, -X, +Y, -Y, +Z, -Z`
- 用途：保持体素对齐，避免45度旋转

### 2.2 组合概念

**阵列配置（ArrayPlacementConfig）**
- 基础参数：步长、首个偏移、最大数量
- 间隔配置：模式数组
- 曲线配置：类型、控制点
- 朝向配置：全局朝向、单点覆盖

**曲线类型（CurveType）**
- 直线（Linear）：两点之间线性插值
- 圆形（Circular）：沿圆周均匀分布
- 贝塞尔（Bezier）：沿贝塞尔曲线分布
- 样条（Spline）：沿样条曲线平滑分布

**朝向模式（OrientationMode）**
- 跟随曲线（FollowCurve）：朝向曲线切线方向
- 固定方向（FixedDirection）：使用统一朝向
- 朝向中心（LookAtCenter）：朝向圆心方向

### 2.3 行为概念

**直线阵列计算**
- 输入：起点、终点、步长
- 过程：计算距离 → 确定数量 → 线性插值
- 输出：沿直线的定位点数组

**圆形阵列计算**
- 输入：圆心、半径、起始角度、结束角度、数量
- 过程：计算弧长 → 确定角度间隔 → 极坐标转换
- 输出：沿圆周的定位点数组

**曲线阵列计算**
- 输入：控制点数组、步长
- 过程：计算曲线长度 → 确定采样点 → 参数化计算
- 输出：沿曲线的定位点数组

**间隔模式应用**
- 输入：原始定位点数组、间隔模式
- 过程：应用模式规则 → 过滤或重复点
- 输出：处理后的定位点数组

### 2.4 概念关系

```
玩家配置
  ↓
阵列配置器
  ↓ 组合
配置参数
  ↓
定位点计算器
  ↓ 使用
曲线计算器
  ↓
定位点数组
  ↓ 应用
间隔模式、朝向
  ↓
预览系统 / 建造执行
```

## 3. 设计原则

### 3.1 架构原则

**配置驱动**
- 所有阵列行为由配置参数控制
- 配置可序列化保存
- 支持配置预设

**可扩展性**
- 曲线类型可扩展
- 间隔模式可组合
- 朝向规则可定制

**模块化**
- 定位点计算独立于渲染
- 曲线计算可单独测试
- 各组件职责清晰

### 3.2 接口设计原则

**参数验证**
- 所有配置参数需要验证
- 提供清晰的错误提示
- 防止无效配置

**结果可预测**
- 相同配置产生相同结果
- 计算过程确定性
- 便于调试和测试

### 3.3 数据管理原则

**吸附到网格**
- 定位点自动吸附到体素网格
- 使用 `FMath::FloorToInt()` 转换
- 避免半格子位置

**朝向离散**
- 只使用6个标准朝向
- 不支持任意角度旋转
- 保持体素对齐

**配置持久化**
- 阵列配置可保存为预设
- 支持配置的导入导出
- 便于玩家复用

### 3.4 性能原则

**按需计算**
- 只在配置变化时计算
- 缓存计算结果
- 避免重复计算

**优化策略**
- 简单配置实时响应
- 复杂配置延迟计算
- 提供计算进度反馈

## 4. 系统约束

### 4.1 技术约束

**坐标系统**
- 定位点使用 POSITION（`FVector`）表示世界坐标
- 朝向使用离散枚举（6个值）
- 吸附到体素网格

**曲线算法**
- 直线：线性插值
- 圆形：三角函数计算
- 贝塞尔：De Casteljau算法或Bezier曲线公式
- 样条：Catmull-Rom或B样条

**数据结构**
- 配置使用结构体（`FArrayPlacementConfig`）
- 定位点使用数组（`TArray<FArrayPlacementPoint>`）
- 不使用动态类型

### 4.2 性能约束

**计算性能**
- 定位点计算 < 1ms（简单配置）
- 定位点计算 < 10ms（复杂配置）
- 预览更新 < 10ms（50个实例）

**数量限制**
- 建议阵列数量 < 100个
- 最大数量可配置（防止意外）
- UI提示性能风险

### 4.3 业务约束

**交互限制**
- 必须有明确的起点和终点
- 必须支持实时预览
- 必须支持配置取消

**朝向限制**
- 只支持6个离散朝向
- 不支持45度旋转
- 保持体素对齐

## 5. 设计目标

### 5.1 功能目标

**核心功能**
1. 直线阵列配置和计算
2. 步长、首个偏移、间隔模式
3. 朝向控制（全局和独立）
4. 实时预览更新

**扩展功能**
1. 圆形/弧形阵列
2. 贝塞尔曲线阵列
3. 样条曲线阵列
4. 配置预设保存

### 5.2 质量目标

**可维护性**
- 配置结构清晰
- 计算逻辑独立
- 易于新增曲线类型

**可测试性**
- 每个曲线算法可独立测试
- 配置验证可测试
- 边界条件清晰

### 5.3 用户体验目标

**易用性**
- 配置参数直观易懂
- 预览实时反馈
- 错误提示清晰

**灵活性**
- 支持多种分布模式
- 支持复杂间隔配置
- 支持独立朝向控制
