## 1. 系统概述

### 1.1 设计目标

`UItemLibraryWidgetBase` 是一个**自给自足**的通用物品浏览组件，提供统一的物品列表展示和交互功能。

**核心目标：**
- ✅ **零配置启动** - 外部只需调用 `Initialize()` 即可完成初始化
- ✅ **DEFAULT 配置** - 通过蓝图默认值配置最大查询类型 TAG
- ✅ **自动生成 TAB** - 自动创建"全部"等基础分类
- ✅ **数据驱动** - 从 `ConfigDataSubsystem` 自动加载物品数据
- ✅ **高复用性** - 可用于方块库、模板库、背包、材料库等场景

### 1.2 应用场景

| 模块 | MaxQueryTypeTag | 说明 |
|------|-----------------|------|
| M1_BuildLibraryModule | `Voxel.Block` | 方块库 |
| M1b_TemplateLibraryModule | `Voxel.Template` | 模板库 |
| BackpackWidget (TODO) | `Voxel.Item` | 背包系统 |
| MaterialLibraryWidget (TODO) | `Voxel.Item.Material` | 材料库 |

## 2. 功能设计

### 2.1 核心功能

#### 功能 1: 一键初始化

**接口：**
```cpp
UFUNCTION(BlueprintCallable, Category = "ItemLibrary|Init")
void Initialize();
```

**自动完成：**
1. 生成基础分类 TAB（"全部"）
2. 从 `ConfigDataSubsystem` 加载符合 `MaxQueryTypeTag` 的所有物品
3. 显示"全部"分类的物品列表
4. 初始化分页系统

**使用示例：**
```cpp
void UM1_BuildLibraryModule::NativeConstruct()
{
    Super::NativeConstruct();

    if (ItemLibraryComponent)
    {
        ItemLibraryComponent->Initialize();  // 一行代码完成所有初始化
    }
}
```

#### 功能 2: 自动 TAB 生成

**配置项：**
```cpp
UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "ItemLibrary|Config")
bool bAutoGenerateAllCategory = true;
```

**生成逻辑：**
- 自动创建"全部"分类（显示所有物品）
- 使用 `UButton` 作为 TAB 按钮
- 自动绑定点击事件
- 自动更新选中状态

**未来扩展：**
- 根据物品 TAG 结构智能生成子分类
- 支持自定义分类配置

#### 功能 3: 大类 TAG 控制

**配置项：**
```cpp
UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "ItemLibrary|Config")
FGameplayTag MaxQueryTypeTag;
```

**配置方式：**
- 在蓝图的 `Defaults` 面板中配置
- 运行时不需要修改

**作用：**
- 限制物品查询范围
- 只显示指定类型及其子类型的物品
- 例如：`Voxel.Block` 只显示方块类物品

#### 功能 4: 物品列表管理

**核心接口：**
```cpp
// 切换分类
void SwitchToCategory(FString CategoryId);

// 刷新列表
void RefreshItemList();

// 搜索过滤
void OnSearchTextChanged(const FText& Text);
```

**功能特性：**
- 分页显示（每页 20 个物品）
- 搜索过滤（按物品名称）
- 分类筛选（TODO）

#### 功能 5: 物品点击事件

**代理：**
```cpp
UPROPERTY(BlueprintAssignable, Category = "ItemLibrary|Event")
FItemClickedSignature OnItemClicked;
```

**使用方式：**
```cpp
// M1 绑定事件
ItemLibraryComponent->OnItemClicked.AddDynamic(
    this,
    &UM1_BuildLibraryModule::HandleItemClicked
);
```

## 3. 数据流设计

### 3.1 初始化流程

```
┌─────────────────────────────────────────────────┐
│ 1. 外部调用 Initialize()                        │
└──────────────────┬──────────────────────────────┘
                   ↓
┌─────────────────────────────────────────────────┐
│ 2. GenerateBasicCategories()                   │
│    生成"全部"分类配置                            │
└──────────────────┬──────────────────────────────┘
                   ↓
┌─────────────────────────────────────────────────┐
│ 3. InitializeCategoryTabs()                    │
│    创建 TAB 按钮并绑定事件                      │
└──────────────────┬──────────────────────────────┘
                   ↓
┌─────────────────────────────────────────────────┐
│ 4. InitializeItemsByType()                     │
│    从 ConfigDataSubsystem 加载物品              │
│    CDS->GetItemTypeArrayByTag<FVoxelItemBase>(  │
│        MaxQueryTypeTag                          │
│    )                                            │
└──────────────────┬──────────────────────────────┘
                   ↓
┌─────────────────────────────────────────────────┐
│ 5. SwitchToCategory("All")                     │
│    显示所有物品列表                              │
└─────────────────────────────────────────────────┘
```

### 3.2 用户交互流程

```
┌─────────────────────────────────────────────────┐
│ 用户点击 TAB 按钮                                │
└──────────────────┬──────────────────────────────┘
                   ↓
┌─────────────────────────────────────────────────┐
│ OnCategoryTabClicked(CategoryId)               │
└──────────────────┬──────────────────────────────┘
                   ↓
┌─────────────────────────────────────────────────┐
│ SwitchToCategory(CategoryId)                   │
│ - 更新选中状态                                   │
│ - 筛选物品列表（TODO）                           │
│ - 重置到第一页                                   │
└──────────────────┬──────────────────────────────┘
                   ↓
┌─────────────────────────────────────────────────┐
│ RenderCurrentPageItems()                       │
│ 渲染当前页的物品槽位                             │
└─────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────┐
│ 用户点击物品槽位                                 │
└──────────────────┬──────────────────────────────┘
                   ↓
┌─────────────────────────────────────────────────┐
│ OnItemSlotClicked(Item)                        │
└──────────────────┬──────────────────────────────┘
                   ↓
┌─────────────────────────────────────────────────┐
│ OnItemClicked.Broadcast(Item->ItemTag)         │
│ 触发代理事件，通知父组件                         │
└─────────────────────────────────────────────────┘
```

### 4.3 物品槽位

**控件类型：** 自定义 Widget（由父组件创建）

**创建方式：**
- 通过代理 `OnCreateItemSlot` 触发
- 父组件在处理函数中创建并添加 Widget

**示例：**
```cpp
// M1 模块创建 BuildSlotWidget
UUserWidget* UM1_BuildLibraryModule::HandleCreateItemSlot(FGameplayTag ItemTag)
{
    UBuildSlotWidget* SlotWidget = CreateWidget<UBuildSlotWidget>(this, BuildSlotWidgetClass);
    SlotWidget->InitSlotData(ItemTag, Icon);
    return SlotWidget;
}
```
