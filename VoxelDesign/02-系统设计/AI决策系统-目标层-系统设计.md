## 1. 定位：内在模型最后一块

需求层回答"去做什么"，状态层回答"以什么状态做"，**目标层回答"为什么活"**——NPC 的跨时段向往。

没有目标层的 NPC 是应激体：饿了吃、痛了医、困了睡，全是当下反应。目标层给 NPC 长期方向，让"攒钱开店""复仇""成为药剂师"这类跨天跨月的行为模式从系统里**长出来**，而不是编排出来。

## 2. 划界：什么配叫目标

**目标 = 一次性里程碑：兑现后永久关闭，成为履历与身份的一部分。** 只指向三类：

- **身份类**：开店、转职、技能大成
- **关系类**：追求、成家、修复关系
- **了断类**：复仇、报恩、雪耻

**消费永不进目标层**：满足后会回来的（饿、想买、想社交）是需求；满足后才关闭的是目标。"攒钱买贵物"不是目标——价格过滤拦着，欲望脉冲反复来，钱自然攒着，买得起那天成交：现有需求通道已经涌现了这个行为，不立目标。

## 3. 五条铁律（业务逻辑全部）

### 3.1 目标如何产生

**唯一来源是事件，没有第二条通道。**

- 解读规则集的种子段声明"此类事件可种什么向往"（见《AI决策系统-记忆模型-系统设计.md》§3）：被羞辱 → 想自己开店；挚友被杀 → 想复仇；被药剂师救治 → 想成为药剂师
- 事件发生时不一定种：性格过滤——好胜者被羞辱才种开店的心，随和者骂完就过去
- 新生成 NPC 走同一条路：backstory 管线从 0 岁模拟人生事件到当前年龄，期间事件按运行时同一规则种种子，**生成期零特殊通道**。35 岁的 NPC 带着"18 岁被羞辱种下、从未实现的开店梦"出场，不是生成器发的

### 3.2 目标如何变化

每个目标有一团火（强度），**火是唯一的生命值**：

- **添柴**：相关事件反复发生（又被老板骂、看到空铺招租、又见到富商太太戴那条项链）
- **熄灭**：长期无人添柴，慢慢淡；血仇级锚点不熄
- **烧过线**：从"心里想想"变"真去追"。线的高低由性格调制——野心家一点就着，安分的人烧不开
- **受挫**：追了长期无进展 → 心情变差 + 火加速流失（有耐心的人撑得久）
- **死亡只有两条路：兑现，或火烧光**（淡忘删除 / 留遗憾印记）。**条件不满足永远不致死**——25 岁没当成大魔导师，梦想不关闭，45 岁练成照样兑现。想表达时间紧迫感，事件种植时加的是强度与叙事文本，不是截止判定

### 3.3 NPC 如何依据目标行动

**目标不产生行为，目标改写缺口地形。** 融合点两个：

1. **扭曲旧缺口**：执念经由需求参数修改与情绪通道起作用（吃饭对付、睡不好、没心思娱乐）——目标自身不配任何"行为修改"，一切走统一效应模型
2. **生成新缺口**：达成路径的前提 − 现状 = 次级缺口（缺钱/缺门路/缺技能/缺资格），进缺口池，与饥饿口渴**平起平坐**参与同一个评分

**攒钱不是目标教的，是预算被预定的**：资金缺口 = 达成路径的价格（商品价/委托费，世界已有数据）− 钱包；可支配预算 = 钱包 − 资金缺口；消费评分里原有的价格上限项自动收紧。欲望没动——他还想吃大餐，是大餐在评分里变贵了。预算是评分项不是铁律：强度低经常**破功**（冲动消费 → 后悔 → 写入记忆），强度高才攒得住。自律与挣扎全是评分对抗的涌现。

**顺序不编排**：钱不够时委托候选无效（前提不满足），钱缺口先凸显；钱够了门路凸显；都齐了委托胜出。"先攒钱 → 找门路 → 委托"是前提依赖的涌现，没有计划表。

### 3.4 没有实现会有什么效果

- 短期：挫败 → 情绪低迷 → 经 MoodMod 通道改变行为（现有机制）
- 外化：回闪频率与闲聊提起权重随强度上升——目标写在脸上，旁人（含玩家）能从行为异常读出他心里烧着什么（心不在焉/花钱变抠/老打听事）
- 长期：火磨光 → 淡忘或留遗憾锚点（喝酒时念叨"当年那条项链"）；锚点保底磨不光 → **终身执念**：画像伴随一生，只影响情绪与话题，指挥不动腿
- 任何情况下都没有"判定失败自动删除"

### 3.5 实现了会有什么效果

- 兑现时刻 = 大事件：强正面情绪 + 永久记忆（"梦想成真"锚点）+ 周围人可见（八卦素材）
- 目标关闭入履历；身份类兑现直接改身份轴——开店成功他就是真店主，资格轨/排班/收入全变
- 兑现事件本身能种新种子：店开起来了 → 想开分店。**链式循环，世界自己往前滚**
- 兑现的情绪由解读规则输出决定：复仇兑现可以是畅快 + 空虚的复合；仇敌病死（谓词满足但归因非我）→ 目标关闭，但留"没能亲手"的复杂一笔

## 4. 匹配与缺口判定逻辑（系统设计）

目标与需求、Remedy 是**同一套缺口驱动机制**，区别只在生命周期（需求周期性 / Remedy 清除即关 / 目标里程碑关闭）。

**谓词**：目标存的"想要什么" = 对容器状态的期望条件（我拥有项链X / 我有药剂师轨Lv.3 / 仇敌.Alive==false）。条件只管两件事——**检测兑现、匹配行为**；永远不做死刑判决。

**效果索引**：内容加载时把全部商品/服务/交互/流程的效果声明倒排成"效果 → 行为"索引，运行时只查表。两个数据来源：

1. 资产上已有的效果字段（商品效果与价格、Buff 的 RemedyTag、交互的效果与前提）
2. 行为类型语义的登记（购买=钱换物、雇佣=入职业轨、委托=服务方交付——行为类型是有限的几十个，每类登记一次；新商品/新店型/新职业是数据，自动被已登记的语义覆盖）

**缺口判定四步**：

1. 谓词拆出期望键 → 查索引得路径集合（复仇 → 委托杀手[直接交付] + 自己动手[推进]）
2. 逐路径取前提（写在路径资产自身配置上，目标侧零配置）对照 NPC 现状
3. 不满足的前提 = 缺口（数值缺口带差额：钱差 4200；存在性缺口布尔：无门路）
4. 每个缺口再查同一索引找填料行为 → 进评分，得分随目标强度放大；直接交付谓词的完成型路径 ≫ 推进型

**不递归**：填料行为的前提不再展开。缺口池是平的，顺序靠"前提不满足则候选无效"涌现。

**评估时机**：事件驱动，零轮询——激活时全量一次，之后订阅容器变更广播（钱包/认知/资格轨/锚点死亡），变了哪条重算哪条。

## 5. 全链走查（验证案例）

### 5.1 买奢侈品（展示预算预定与破功）

```
T0  种植：宴会上因穿戴寒酸被讥讽 → 解读规则集种子段声明可种种子"拥有{那件首饰}"，
    锚点=那条项链 → 性格过滤：好胜者种下且基础强度高
    → 同帧写入羞辱记忆（记忆层原通道）；此刻行为零变化（种子沉睡）
T1  喂养：橱窗看到/闲聊听到/又见到富商太太 → 强度上涨 → 过线转活跃
    （无人添柴则淡掉，种子死，什么都没发生过）
T2  活跃后每个评分周期（世界数据自动约束，目标侧零配置）：
    项链价 2000（商品配置）− 钱包 300 → 资金缺口 1700
    → 可支配预算 < 0 → 消费评分的价格项惩罚拉满
    · 下馆子变对付一顿——欲望没动，大餐分数被价格压死
    · 加班/接私活评分升高——钱缺口在池，赚钱行为的效果命中它
    · "购买项链"候选：前提"钱≥2000"不满足 → 候选无效，不进场
    · 闲聊提起项链的权重升高 → 朋友回"那家店月底打折"
      → 她开始等打折（计划性涌现）
T3  破功：心情差+朋友劝+店庆打折 → 大餐分数冲过收紧的预算
    → 饭后写入"又没忍住"：情绪下行 + 挫败 → 强度被磨一点
T4a 兑现：攒够 → 预算释放 → 购买候选生效且胜出 → 到店买下
    → 大情绪脉冲 + 永久记忆"梦想成真" + 锚点
    → 她戴着出席社交场合 → 别人社交比较 → 可能给别人种新种子（链式循环）
T4b 失败：收入太低攒不动 / 项链被别人买走 → 永远无进展 → 挫败磨强度
    → 磨光：淡忘留遗憾锚点；或锚点保底：终身执念伴随一生
```

### 5.2 成为药剂师（展示多阶段路径靠事件反馈导航）

```
T0  种植：病了半年被药剂师治好（被救治事件）→ 利他者容易种"我也想救人"
T2  活跃后（谓词 = 拥有药剂师资格轨Lv.X）：
    · 资格缺口 → 索引命中：药店打工（雇佣流程）/ 拜师（服务）/ 读药理书（商品）
    · 他不知道先走哪条，直接去药店求职 → 被拒（店主招聘看资质）
    → 拒绝事件写入记忆 + 挫败——学习路径不是规划出来的，是被拒绝事件撞出来的
    · 技能缺口凸显 → 买书自学（钱缺口叠加 → 预算收紧）
    · 训练与面包店 Duty 时段抢时间 → 业余苦练或辞职
      （Loyalty 与目标强度对抗决定去留，辞职流程已有）
T4a 兑现：资格轨到级 → "梦想成真"事件 → 身份轴更新，收入/排班/社交圈全变
    → 兑现事件种新种子："开自己的药店"
T4b 失败：多年无人雇 → 磨光淡忘，或终身执念"我当年要是成了药剂师"
```

### 5.3 暗杀仇人（展示多路径竞争与风险螺旋）

```
T0  种植：挚友被杀 → 种子"让{凶手}付出代价"，锚点=仇敌（Grudge 轨已在烧）
    → 竞争性高才种；血仇锚点保底——这团火磨不光
T2  活跃后（谓词 = 仇敌.Alive==false）：
    索引命中两条路径：委托杀手（完成型：前提=委托费+认知门路）/
    自己动手（推进型：前提=战斗力+行踪+他敢——谨慎性格把这条评分压低）
    缺口自动分解：钱缺口 → 攒钱；门路缺口 → 打听/混三教九流场所；
    动手线：战斗力缺口 → 练武/买武器；行踪缺口 → 踩点候选
T3  螺旋（系统咬合自然长出，无一处是"暗杀目标配置"）：
    · 踩点/打听与 Duty、睡眠抢时段 → 翘班熬夜 → 工作表现差
      → 被老板警告 → 丢工作 → 钱缺口更大（下行螺旋）
    · 打听时话题权重高 → 朋友说漏嘴 → 八卦传染（记忆复制管线）
      → 传闻到仇人耳朵 → 仇人的目标系统可能因此种下对他的种子（冤冤相报）
T4a 兑现：委托成交 → 仇敌死亡归因于他 → 谓词满足
    → 情绪由解读规则输出决定：畅快+空虚复合；后果链：家属可能种种子；治安/侦探介入
T4b 特殊分叉：仇敌病死——谓词满足但归因非我
    → 目标关闭，留"没能亲手"的复杂情绪（解读规则按归因分支）
```

**三链共同结论**：目标侧永远只有"想要什么（事件种的）+ 强度"。价格、预算、前提、路径、外化、传染——全部来自世界已有数据与系统。目标层不存在类型表，"怎么达成"的知识长在商品、服务、流程、交互上，长在世界里。

## 6. 效率

- **构建期（一次）**：索引扫全资产效果声明，毫秒级；热重载重建
- **激活/变化（罕见）**：哈希查表 + 条件求值，每 NPC 每游戏天零点几次；增量重算只动受影响缺口
- **每次决策（唯一持续成本）**：活跃目标加几条到十几条候选进加法核，浮点级。决策事件驱动非 tick、图外 NPC 零开销（日程出场判据已定案），目标层完全继承
- **唯一要盯**：候选总量膨胀——由候选收集上限控制（总纲 §4.2：候选数 3-10），不走 LOD（LOD 只降演出与执行，决策与数据层不降档，见 §18（[NPC卷](/VoxelDesign/02-系统设计/AI决策系统-NPC个体与决策-系统设计.md)））
