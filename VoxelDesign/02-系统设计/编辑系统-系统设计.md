## 1. 系统上下文

### 1.1 系统边界

**编辑系统负责**：
- 玩家对体素世界的所有编辑操作
- 单体素编辑（放置、删除、替换）
- 批量编辑（盒、球、圆柱等形状）
- 选区功能（框选、魔棒、多边形、笔刷）
- 模板功能（采集、预览、放置、分享）
- 阵列功能（直线、圆形、曲线分布）
- 撤销/重做管理

**编辑系统不负责**：
- 体素世界的持久化存储（由VoxelGameInstance管理）
- 网格渲染的底层实现（复用UE渲染系统）
- 物理模拟（由物理系统负责）
- AI决策（由AI系统负责）

### 1.2 外部依赖

**依赖的外部系统**：
- **VoxelBlockWorldSubsystem**：体素世界数据的读写
- **VoxelGameInstance**：场景管理、保存加载
- **ConfigDataSubsystem**：方块类型和配置数据
- **Input系统**：玩家输入检测

**被依赖的系统**：
- **UI系统**：编辑UI、工具栏
- **AI系统**：NPC的建造行为
- **物理系统**：碰撞检测

### 1.3 输入输出

**输入**：
- 玩家的输入操作（鼠标、键盘）
- 编辑工具选择
- 编辑参数（形状、类型、尺寸等）

**输出**：
- 体素世界的修改请求
- 网格更新
- 历史记录
- 预览更新

## 2. 系统架构概述

### 2.1 核心设计原则

1. **Component-Based Architecture** - 每个玩家拥有独立的组件，支持多玩家
2. **职责分离** - 不同的子系统负责不同的功能
3. **无状态工具层** - 批量编辑工具为纯数学计算
4. **统一几何执行模型** - 几何编辑使用 `FSingleEditRequest`；经营组合创建意图见 §5.2，不强制塞入体素请求
5. **可扩展性** - 支持新增工具和功能模块

### 2.2 子系统划分

```
编辑系统
├── 核心编辑系统（Core Editing）
│   ├── InteractComponent（协调层）
│   ├── BatchTool（批量计算）
│   ├── BlockWorld（执行层）
│   └── HistoryComponent（历史管理）
│
├── 选区系统（Selection System）
│   ├── 选区工具基类
│   ├── 框选工具
│   ├── 魔棒工具
│   └── 多边形工具
│
├── 模板系统（Template System）
│   ├── 模板管理
│   ├── 网格生成
│   ├── 预览缓存
│   ├── 序列化分享
│   └── 建造执行
│
└── 阵列系统（Array System）
    ├── 阵列配置器
    ├── 定位点计算器
    └── 曲线计算器
```

### 2.3 架构分层

```
┌─────────────────────────────────────────────────────────────┐
│ 用户交互层（User Input）                                     │
│ - InputSystem: 检测玩家输入                                 │
│ - UI: 显示工具栏、预览                                        │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│ 协调层（Coordination）                                     │
│ - VoxelControllerInteractComponent: 协调编辑操作           │
│ - VoxelControllerStateComponent: 管理编辑状态              │
│ - VoxelControllerVisualUIComponent: 更新预览               │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│ 工具层（Tools）                                             │
│ - UVoxelBatchEditTool: 批量编辑计算（无状态）               │
│ - UVoxelSelectionTool: 选择工具基类                        │
│   ├── UVoxelBoxSelectionTool: 框选                          │
│   ├── UVoxelMagicWandTool: 魔棒选择                        │
│   └── UVoxelPolygonTool: 多边形选择                       │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│ 功能模块层（Feature Modules）                               │
│ - 模板系统：模板管理、网格生成、预览缓存                     │
│ - 阵列系统：配置管理、定位点计算、曲线分布                   │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│ 执行层（Execution）                                         │
│ - UVoxelBlockWorldSubsystem: 执行体素修改                   │
│ - UVoxelControllerHistoryComponent: 管理历史记录            │
└─────────────────────────────────────────────────────────────┘
```

## 3. 子系统功能概述

### 3.1 核心编辑系统

**功能**：
- 单体素编辑：放置、删除、替换单个体素
- 批量编辑：按形状（盒、球、圆柱）编辑大量体素
- 形状预览：实时显示编辑范围
- 编辑执行：异步处理编辑请求
- 撤销/重做：支持编辑操作的历史管理

**核心组件**：
- **VoxelControllerInteractComponent**：协调编辑操作
- **VoxelBatchEditTool**：批量编辑的数学计算
- **VoxelBlockWorldSubsystem**：执行体素修改
- **VoxelControllerHistoryComponent**：管理历史记录

**数据模型**：
- `FVoxelEditRequest`：编辑请求（输入）
- `FVoxelGeometryDesc`：几何描述
- `FSingleEditRequest`：完整的编辑请求（包含历史数据）

**相关文档**：
- [编辑系统-架构设计-v1](/VoxelDesign/03-架构设计/编辑系统-架构设计-v1.md) - v2.0核心架构

### 3.2 选区系统

**功能**：
- 框选：通过包围盒选择体素
- 魔棒选择：通过连通性选择相同类型体素
- 多边形选择：通过多边形区域选择体素
- 反选：反转选择状态
- 选择后操作：复制、删除、保存为模板

**核心组件**：
- **UVoxelSelectionTool**：选择工具基类
- **UVoxelBoxSelectionTool**：框选实现
- **UVoxelMagicWandTool**：魔棒选择实现
- **UVoxelPolygonTool**：多边形选择实现

**数据模型**：
- `TSet<FIntVector>`：选中体素集合
- `FAreaCoverageFragment`：选中包围盒
- 输出：`FVoxelEditModification`、`FVoxelBuildingTemplate`

**相关文档**：
- [编辑系统-选区系统-系统设计](/VoxelDesign/02-系统设计/编辑系统-选区系统-系统设计.md)
- [编辑系统-选区系统-架构设计](/VoxelDesign/03-架构设计/编辑系统-选区系统-架构设计.md)

### 3.3 模板系统

**功能**：
- 模板采集：从选区数据生成模板数据
- 模板管理：加载、保存、删除模板
- 预览生成：从模板生成预览网格
- 预览缓存：管理已生成网格的缓存
- 模板建造：单体和阵列放置
- 序列化分享：导出/导入分享代码

**核心组件**：
- **FVoxelBuildingTemplate**：模板数据结构
- **UVoxelTemplateLibrary**：模板库管理
- **UVoxelTemplateSerializer**：序列化器
- **UVoxelTemplateMeshGenerator**：网格生成器
- **UVoxelTemplatePreviewCache**：预览缓存
- **UVoxelBuildCoordinator**：建造协调器

**数据模型**：
- `FVoxelBuildingTemplate`：模板数据（复用`FVoxelEditModification`）
- 相对坐标：基于包围盒Min角
- 锚点：固定为底面中心
- 分享代码格式：`"BP:" + Base64(Zlib(Serialize(Template)))`

**相关文档**：
- [编辑系统-模板系统-系统设计](/VoxelDesign/02-系统设计/编辑系统-模板系统-系统设计.md)
- [编辑系统-模板系统-架构设计](/VoxelDesign/03-架构设计/编辑系统-模板系统-架构设计.md)

### 3.4 阵列系统

**功能**：
- 阵列配置：步长、间隔、朝向、曲线类型
- 定位点计算：根据配置计算阵列中的所有实例位置
- 曲线分布：直线、圆形、贝塞尔、样条
- 间隔模式：支持复杂的生成/跳过模式
- 朝向控制：全局朝向和单点独立朝向

**核心组件**：
- **FArrayPlacementConfig**：阵列配置结构
- **UVoxelArrayConfigurator**：配置管理器
- **UVoxelPlacementCalculator**：定位点计算器
- **UVoxelCurveCalculator**：曲线计算器（策略模式）
- **FArrayPlacementPoint**：定位点数据结构

**数据模型**：
- 曲线类型：`ECurveType`（Linear, Circular, Bezier, Spline）
- 朝向模式：`EOrientationMode`（FollowCurve, Fixed, LookAtCenter）
- 离散朝向：6个标准方向（`+X, -X, +Y, -Y, +Z, -Z`）
- 间隔模式：数组 `[生成N个, 跳过M个]`

**相关文档**：
- [编辑系统-阵列系统-系统设计](/VoxelDesign/02-系统设计/编辑系统-阵列系统-系统设计.md)
- [编辑系统-阵列系统-架构设计](/VoxelDesign/03-架构设计/编辑系统-阵列系统-架构设计.md)

### 3.5 预览系统交互

**系统定位**：
预览系统是一个独立的渲染辅助系统，**服务于编辑系统**，负责实时显示编辑操作的可视化反馈。

**功能**：
- 实时预览：显示编辑操作的实时效果
- 状态管理：管理预览的显示状态（HIDDEN/BASE/EDIT/CONFIRM）
- 模式切换：根据编辑类型切换预览模式（None/SingleVoxel/SimpleGeometry/ComplexBlueprint）
- Gizmo显示：显示编辑控件的交互控制
- 性能优化：预览网格缓存和复用

**核心组件**：
- **AVoxelPreviewActor**：预览渲染Actor，负责实际的网格显示
- **VoxelControllerVisualUIComponent**：UI组件，管理PreviewActor的生命周期
- **EPreviewInteractionState**：预览流程状态枚举
- **EPreviewMode**：预览模式枚举

**数据模型**：
- `FVoxelEditRequest`：完整的编辑请求，包含渲染需要的所有数据
- 当前工具（CurrentToolTag）：决定预览模式（GameplayTag工具层级）
- 流程状态（PreviewState）：控制渲染阶段
- 几何描述（Geometry）：用于计算渲染位置和形状

**工具Tag层级**：
- `Voxel.Tool.Selection` - 选区工具（定义选区）
  - `Voxel.Tool.Selection.SingleVoxel` - 单体素选择
  - `Voxel.Tool.Selection.SimpleGeometry` - 简单几何体选择
  - `Voxel.Tool.Selection.Brush` - 笔刷选择
- `Voxel.Tool.Edit` - 编辑工具（修改世界）
  - `Voxel.Tool.Edit.SingleVoxel` - 单体素编辑
  - `Voxel.Tool.Edit.SimpleGeometry` - 简单几何编辑
  - `Voxel.Tool.Edit.Selection` - 选区操作（移动/复制/删除）
  - `Voxel.Tool.Edit.Template` - 模板放置
- `Voxel.Tool.AreaEdit` - 区域编辑工具
  - `Voxel.Tool.AreaEdit.Create` - 创建区域
  - `Voxel.Tool.AreaEdit.Modify` - 修改区域

**预览模式映射**：
| 工具Tag | 预览模式 | 说明 |
|--------|---------|------|
| (无工具) | None | 无预览 |
| Voxel.Tool.Selection.* | SelectionPreview | 选区框预览 |
| Voxel.Tool.Edit.SingleVoxel | SingleVoxel | 单体素预览 |
| Voxel.Tool.Edit.SimpleGeometry | SimpleGeometry | 简单几何体预览 |
| Voxel.Tool.Edit.Template | ComplexBlueprint | 复杂蓝图预览 |

## 4. 子系统间关系

### 4.1 选区系统 ↔ 核心编辑系统

**关系：选区系统为核心编辑提供选择能力**

```
选区系统
  ↓ 提供
选区数据（SelectedVoxels + Bounds）
  ↓
核心编辑系统
  ├─ 读取选区数据 → 生成 FVoxelEditModification
  ├─ 执行复制/删除操作
  └─ 更新预览显示
```

**接口**：
- `UVoxelSelectionTool::CopySelected()` → `FVoxelEditModification`
- `UVoxelSelectionTool::DeleteSelected()` → `FVoxelEditModification`

### 4.2 选区系统 ↔ 模板系统

**关系：选区系统为模板系统提供数据来源**

```
选区系统
  ↓ 提供
选区数据
  ↓
模板系统
  ↓ 执行
采集模板 → FVoxelBuildingTemplate
```

**接口**：
- `UVoxelSelectionTool::SaveAsTemplate()` → `FVoxelBuildingTemplate`
- 输入：选区数据、模板名称
- 输出：模板数据

### 4.3 模板系统 ↔ 阵列系统

**关系：阵列系统使用模板系统的模板进行放置**

```
模板系统
  ↓ 提供
模板数据
  ↓
阵列系统
  ↓ 计算
定位点数组（位置+朝向）
  ↓
模板系统
  ↓ 执行
模板建造 → FVoxelEditModification
```

**接口**：
- 阵列系统：接收模板尺寸（用于自动步长计算）
- 模板系统：接收定位点数组（用于建造）

### 4.4 模板系统 ↔ 预览系统

**关系：模板系统生成预览，预览系统负责显示**

```
模板系统
  ↓ 生成
预览网格（FChunkMeshData）
  ↓
预览系统
  ↓ 显示
更新PreviewActor
```

**接口**：
- `UVoxelTemplateMeshGenerator::GenerateMeshDataForTemplate()`
- `AVoxelTemplatePreviewActor::UpdateArrayPreview()`

### 4.5 阵列系统 ↔ 预览系统

**关系：阵列系统更新预览显示**

```
阵列系统
  ↓ 提供
定位点数组
  ↓
预览系统
  ↓ 更新
阵列预览（多个MeshComponent）
```

**接口**：
- `AVoxelTemplatePreviewActor::UpdateArrayPreview()`
- 输入：基础网格 + 定位点数组

## 5. 数据流图

### 5.1 模板采集流程

```
玩家框选体素
  ↓
选区系统：UVoxelBoxSelectionTool
  - 计算包围盒
  - 选择体素
  ↓
模板系统：UVoxelSelectionTool::SaveAsTemplate()
  - 计算相对坐标
  - 构建模板数据
  - 添加元数据
  ↓
输出：FVoxelBuildingTemplate
```

### 5.2 模板放置流程（单体）

下图只适用于已有有效授权下的普通几何模板放置，不是新经营实体创建设计。用于新商圈/店铺或租户入驻时，复用当前范围/模板预览，在同一建造侧栏填写名称、类型/业态与经营意图等必要信息后，单次 Confirm 概念请求 `CreateBusinessWithArea`（OperatorId、BusinessKind、Name、BusinessIntent、ParentBusinessEntityId、空间草稿等；请求 class 待定），经 Controller → 业务门面创建实体、空间、经营关系及必要 Lease/首期，再调用现有建造执行。有租户建筑/家具时有效 Lease 必须先于真写入；不要求先创建区域、跳详情补建生意或手动绑定。产权/经营人依有效授权及租约/任命确定，不能自由填值取得权利。

经营实体统一存 `Global.BusinessEntities`；`BusinessEntityId` 全局稳定（GUID，规则见[总纲 §2.7](/VoxelDesign/02-系统设计/AI决策系统-系统设计.md)），不使用 `ShopId` 别名。可选空间组件关联 `AreaRef={SceneId,AreaId}`；子区域创建仅空间并关联现有主体。经营与空间注册编排分开不镜像，几何执行/撤销算法不因此改变。M13a 纯导航仅为待迁移代码事实，不约束最终创建 UI。V1 只预置商圈玩家标准租杂货店；NPC 空店/模板邀请同一连续面板确认候选、条款与产权授权，先 Lease 再落位，完整模板招商/客房留后续。实体创建默认 `bOpen=false`，并非开业。

```
玩家选择模板
  ↓
模板系统：UVoxelTemplatePreviewCache
  - 生成/获取预览网格
  ↓
预览系统：AVoxelPreviewActor
  - 显示预览
  ↓
玩家确认放置
  ↓
模板系统：UVoxelBuildCoordinator
  - 计算世界坐标
  - 构建修改请求
  ↓
核心编辑系统：VoxelBlockWorldSubsystem
  - 执行修改
  ↓
历史系统：VoxelControllerHistoryComponent
  - 记录历史
```

### 5.3 模板放置流程（阵列）

下图仅为已有有效授权下的普通几何阵列放置；涉及新经营实体/租户建筑或家具时，遵循 §5.2 的同侧栏组合确认及有效 Lease前置，不能直接阵列执行绕过经营业务。本次不增加批量经营创建方案或更改阵列/撤销算法。

```
玩家配置阵列
  ↓
阵列系统：UVoxelArrayConfigurator

  ↓

  - 计算世界坐标

  ↓
核心编辑系统：VoxelBlockWorldSubsystem
  - 执行修改
```

## 6. 扩展点

### 6.1 新增选择方式

**方法**：继承 `UVoxelSelectionTool`

**示例**：
```cpp
class UVoxelLassoSelectionTool : public UVoxelSelectionTool
{
    void SelectFromLasso(TArray<FVector> Points);
};
```

### 6.2 新增批量编辑形状

**方法**：在 `UVoxelBatchEditTool` 中添加形状计算

**示例**：
```cpp
static TArray<FIntVector> CalculateConeVoxels(...);
```

### 6.3 新增曲线类型

**方法**：
1. 在 `ECurveType` 枚举中添加新类型
2. 在 `UVoxelCurveCalculator` 中实现计算方法
3. 在 `UVoxelPlacementCalculator` 中添加调用

**示例**：
```cpp
enum class ECurveType : uint8
{
    Linear, Circular, Bezier, Spline,
    Spiral, Helix  // 新增
};
```

### 6.4 新增模板功能

**方法**：扩展 `FVoxelBuildingTemplate` 结构

**示例**：
```cpp
struct FVoxelBuildingTemplate
{
    // 新增：模板变体
    UPROPERTY()
    TArray<FIntVector> VariantOffsets;

    // 新增：模板组合
    UPROPERTY()
    TArray<FString> SubTemplates;
};
```

## 7. 设计原则

### 7.1 复用优先

**数据模型复用**：
- ✅ 模板系统复用 `FVoxelEditModification`
- 几何编辑执行使用 `FSingleEditRequest`；经营组合创建先走 §5.2业务门面，不绕过有效 Lease再执行几何
- ✅ 几何描述使用 `FVoxelGeometryDesc`

**逻辑复用**：
- ✅ 阵列建造复用单体建造逻辑
- ✅ 选择工具复用工具基类
- ✅ 网格生成复用现有算法

### 7.2 职责分离

**选区系统**：
- ✅ 只负责选择，不负责编辑执行
- ✅ 只负责计算，不负责渲染

**模板系统**：
- ✅ 只负责模板数据，不负责网格渲染细节
- ✅ 只负责建造逻辑，不负责撤销实现

**阵列系统**：
- ✅ 只负责配置和计算，不负责渲染实现
- ✅ 只负责定位点，不负责网格生成

### 7.3 可测试性

**无状态工具**：
- ✅ `UVoxelBatchEditTool` 无状态，易于单元测试
- ✅ 所有计算方法为静态，无副作用

**独立组件**：
- ✅ 每个子系统可独立测试
- ✅ 接口清晰，便于Mock

## 8. 性能考虑

### 8.1 缓存策略

**预览网格缓存**：
- 数量上限：20个模板（可配置）
- 清理策略：基于活跃度（20次操作未使用）
- 内存占用：约10-40 MB

**数据缓存**：
- 模板数据延迟加载
- 预览网格按需生成

### 8.2 异步处理

**编辑执行**：
- 异步队列处理
- 多线程支持
- 边界检测优化

### 8.3 内存优化

**稀疏存储**：
- 模板只存储实体方块
- 不存储空气方块

**数据共享**：
- 阵列预览共享基础网格
- 每个实例只存储Transform
