## 1. 需求总结

### 1.1 核心工作流

```
选择 → 移动/复制粘贴/删除替换/保存模板
```

选择工具是编辑系统的**基础工具**，后续所有编辑操作都基于选区数据。

### 1.2 功能清单

#### 选择后操作
- ✅ **移动**: 三轴Gizmo拖拽 + 锚点控制 + 轴向限制
- ✅ **复制/粘贴**: 复制到剪贴板 + Gizmo定位预览
- ✅ **删除/替换**: 直接删除 + 类型替换
- ✅ **保存模板**: 保存为 `FVoxelBuildingTemplate`

#### 选区数据管理
- ✅ **加减选模式**: Shift加选、Alt减选、Ctrl新选
- ✅ **选择历史**: 记录最近10次选择
- ✅ **隐藏/显示高亮**: 切换选中高亮显示
- ✅ **生命周期**: 切换工具保留，切换编辑模式清除

#### 预览和反馈
- ✅ **实时高亮预览**: 选中体素高亮显示
- ✅ **统计信息显示**: 数量、包围盒尺寸
- ✅ **操作进度反馈**: 耗时操作显示进度
- ✅ **拖拽预览包围盒**: 框选时实时预览

## 2. 与现有系统的集成

### 2.1 用户交互层集成

**VoxelPlayerController**
- 接收选择工具输入事件
- 路由到对应组件

**VoxelControllerStateComponent**
- 新增状态: `EVoxelToolOpType::Select`
- 子状态: 选择中、选中完成、移动预览、粘贴预览
- 生命周期: 切换工具时清除选区数据

**VoxelControllerInteractComponent**
- 协调选择操作
- 协调移动/复制的预览和确认
- 历史记录集成

**VoxelControllerVisualUIComponent**
- 选择框渲染
- 选中高亮
- Gizmo渲染
- 预览渲染
- UI反馈

### 2.2 工具层集成

**UVoxelSelectionTool (基类)**
- 复用现有接口: `GetSelectedVoxels()`, `GetSelectionBounds()`
- 复用现有接口: `CopySelected()`, `DeleteSelected()`, `SaveAsTemplate()`
- 新增接口:
  ```cpp
  FVoxelEditModification CalculateMoveModification(FIntVector Offset);
  TArray<FIntVector> CalculateMovePreview(FIntVector Offset);
  TArray<FIntVector> CalculatePastePreview(FIntVector TargetPosition);
  ```

**UVoxelBoxSelectionTool / UVoxelMagicWandTool / UVoxelPolygonTool**
- 按架构文档实现选择逻辑
- 支持加减选模式

### 2.3 功能模块层集成

**模板系统**
- `SaveAsTemplate()` 复用现有接口
- 反向操作: 从模板加载为选区数据

**阵列系统**
- 选择内容作为阵列单元
- 集成点: 选择完成后显示"创建阵列"按钮

### 2.4 执行层集成

**UVoxelBlockWorldSubsystem**
- 移动 = 删除原位置 + 新位置创建
- 复制粘贴 = 批量创建

**UVoxelControllerHistoryComponent**
- 撤销/重做支持
- 记录选区数据变化

## 3. 历史记录系统

### 3.1 扩展操作类型枚举

```cpp
UENUM(BlueprintType)
enum class EVoxelToolOpType : uint8
{
    // === 基础操作 ===
    Build       UMETA(DisplayName = "建造),
    Destruct    UMETA(DisplayName = "破坏,
    Paint       UMETA(DisplayName = "涂色,
    Select      UMETA(DisplayName = "选择,
    Sample      UMETA(DisplayName = "吸管,

    // === 组合操作 ===
    Move        UMETA(DisplayName = "移动,         // = Destruct + Build
    CopyPaste   UMETA(DisplayName = "复制粘贴  // = Build (with source)
};
```

### 3.2 复用现有历史记录结构

**FVoxelEditHistoryRecord** - 最小化扩展

```cpp
USTRUCT(BlueprintType)
struct FVoxelEditHistoryRecord
{
    // === 现有字段（复用） ===
    UPROPERTY()
    TSet<FVoxelEdit> Edits;

    UPROPERTY()
    EVoxelControllerEditState EditMode; // ← 未来替换为 EVoxelToolOpType

    UPROPERTY()
    TArray<FIntVector> ChunkIndices;

    UPROPERTY()
    FText Description;

    // === 新增字段（支持选区数据恢复） ===
    UPROPERTY()
    TSet<FIntVector> SelectedVoxels;  // 记录选区数据

    UPROPERTY()
    FAreaCoverageFragment SelectionBounds; // 选择包围盒
};
```

### 3.3 操作映射关系

| 操作类型 | Edits 记录内容 | SelectedVoxels |
|---------|--------------|---------------|
| **Select** | 空 | 当前选区数据 |
| **Move** | (A→None), (B→None), (A'→Block), (B'→Block) | 移动前选区数据 |
| **CopyPaste** | (A→Block), (B→Block) | 粘贴后的选区数据 |
| **Destruct** | (A→None), (B→None) | 删除前选区数据 |
| **Replace** | (A→NewType), (B→NewType) | 替换前选区数据 |

### 3.4 撤销/重做行为

**撤销移动**:
1. 恢复体素到原位置
2. 恢复选区数据

**撤销选择**:
- 清空当前选区数据
- 恢复上一次选区数据

## 4. 数据流设计

### 4.1 框选 → 移动流程

```
1. 用户拖拽框选
   ↓
2. 计算包围盒 → 实时预览
   ↓
3. 释放鼠标 → 执行选择
   ↓
4. 记录历史: Selection 操作
   ↓
5. 显示三轴 Gizmo
   ↓
6. 用户拖拽轴 → 实时预览移动
   ↓
7. 用户点击确认
   ↓
8. 记录历史: Move 操作 (Edits + SelectedVoxels)
   ↓
9. 执行移动: 删除原位置 + 创建新位置
   ↓
10. 保存到 UndoStack
```

### 4.2 复制 → 粘贴流程

```
1. 选择完成
   ↓
2. Ctrl+C → 复制到剪贴板
   ↓
3. Ctrl+V → 显示 Gizmo 预览
   ↓
4. 用户拖拽定位 → 实时预览
   ↓
5. 用户点击确认
   ↓
6. 记录历史: CopyPaste 操作
   ↓
7. 执行粘贴: 批量创建
   ↓
8. 保存到 UndoStack
```

## 5. 交互设计

### 5.1 选择工具交互

**框选 (Box Selection)**
- 鼠标左键拖拽: 框选
- Shift + 拖拽: 加选
- Alt + 拖拽: 减选
- 实时预览包围盒

**魔棒 (Magic Wand)**
- 单击体素: 选择连通区域
- Shift + 单击: 加选
- Alt + 单击: 减选
- 支持类型匹配

**多边形 (Polygon)**
- 点击添加顶点
- 双击闭合选择
- Esc 取消

### 5.2 Gizmo 移动控制

#### 输入方式

| 输入 | 效果 | 对齐 |
|------|------|------|
| **拖拽轴** | 自由移动 | ✅ 实时对齐体素格 |
| **滚轮** | 沿锁定轴向步进 1格 | ✅ 强制对齐 |
| **方向键** | 沿锁定轴向步进 1格 | ✅ 强制对齐 |
| **Shift + 方向键** | 沿锁定轴向步进 10格 | ✅ 强制对齐 |
| **按住轴 + 输入距离** | 精确移动（如输入 "+5" 或 "-3"） | ✅ 强制对齐 |

#### 精确输入对话框

**触发方式**:
- 按住 X/Y/Z 轴 Gizmo
- 或按键盘 X/Y/Z 键

**显示内容**:
```
┌─────────────────────────┐
│ 沿 X 轴移动              │
├─────────────────────────┤
│ 距离: [___] 格          │
│                         │
│ 提示: 输入正负值         │
│  如: +5, -3             │
├─────────────────────────┤
│ [取消]      [确认]      │
└─────────────────────────┘
```

**行为**:
- 输入 "+5" → 沿正方向移动 5 个体素格
- 输入 "-3" → 沿负方向移动 3 个体素格
- 回车或点击确认 → 应用移动
- Esc 或点击取消 → 关闭对话框

#### 锚点控制

- **默认**: 包围盒中心
- **可切换到**: 8个角点
- **UI按钮**: "中心" / "角点"

#### 轴向限制

- **无修改**: 自由移动
- **Shift**: 限制到单轴
- **Ctrl**: 限制到平面

### 5.3 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+C | 复制选中 |
| Ctrl+V | 粘贴 |
| Ctrl+X | 剪切 |
| Del | 删除选中 |
| Ctrl+Z | 撤销 |
| Ctrl+Y / Ctrl+Shift+Z | 重做 |
| Esc | 取消选择/取消操作 |
| Shift | 加选模式 |
| Alt | 减选模式 |
| X / Y / Z | 锁定轴向 + 精确输入对话框 |
| G | 切换Gizmo显示 |
| 方向键 | 沿锁定轴向移动1格 |
| Shift + 方向键 | 沿锁定轴向移动10格 |
| 滚轮 | 沿锁定轴向移动1格 |

## 6. 预览和反馈系统

### 6.1 视觉反馈

**选择高亮**:
- 遍历 `SelectedVoxels`
- 渲染 DebugLines 或半透明材质
- 支持隐藏/显示切换

**包围盒预览**:
- 框选拖拽时实时显示
- 使用 `FAreaCoverageFragment` 计算边界
- 线框渲染

**移动预览**:
- 半透明体素显示移动后位置
- 实时跟随 Gizmo 拖拽
- 对齐体素格

**粘贴预览**:
- 半透明体素显示粘贴位置
- Gizmo 定位
- 确认前可调整

### 6.2 UI 反馈

**统计信息**:
```
已选中: 15 个体素
包围盒: 10×5×3
```

**操作进度**:
- 魔棒选择时显示进度条
- 大量体素操作时显示进度

**确认对话框**:
- 删除操作: 确认对话框
- 替换操作: 选择目标类型 UI
- 精确移动: 输入距离对话框

## 7. 技术约束

### 7.1 性能约束

- 单次选择不超过 10,000 个体素
- UI 响应时间 < 100ms
- 预览渲染 60 FPS

### 7.2 坐标系统

- 必须使用 INDEX (`FIntVector`)
- 遵循编码规范
- 移动强制对齐体素格

### 7.3 数据结构

- 选区数据: `TSet<FIntVector>`
- 包围盒: `FAreaCoverageFragment`
- 历史记录: `FVoxelEditHistoryRecord` (扩展)
