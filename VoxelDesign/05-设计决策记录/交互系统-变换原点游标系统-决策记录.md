## 背景

### 需求来源

体素编辑工具（几何体/模板/家具）在 EDIT 阶段，需要通过 Gizmo 进行旋转操作。当前旋转中心固定为几何体中心，无法绕任意点旋转。需要引入类似 Blender 的"3D 游标（Cursor）"概念，允许用户自定义变换原点。

### 当前问题

1. **旋转原点固定**：只能绕几何中心旋转，无法绕角点、边中点等自定义位置旋转
2. **镜像/缩放受限**：无法绕游标位置做镜像翻转或缩放
3. **FP/Center 缓存冗余**：`FVoxelGeometryDesc::Center` 作为"缓存"存在，但又参与 `operator==`，语义模糊

### 设计目标

- 支持两种变换原点模式：**物体中心（ObjectCenter）** / **游标（Cursor）**
- 游标模式下旋转时物体做**轨道运动**（位置 + 旋转都改变）
- 游标世界坐标固定，可独立放置（类似 Blender 3D Cursor）
- Cursor 模式：`PivotWorld = GetGeometricCenter()` - 自动保持为物体中心

## 核心字段定义

```cpp
UENUM(BlueprintType)
enum class EVoxelPivotMode : uint8
{
    ObjectCenter    UMETA(DisplayName = "物体中心"),
    Cursor          UMETA(DisplayName = "游标")
};
```

### FVoxelGeometryDesc 修改

```cpp
USTRUCT(BlueprintType)
struct FVoxelGeometryDesc
{
    // === 纯几何（不变）===
    FAreaCoverageFragment Box;
    FRotator Rotation = FRotator::ZeroRotator;
    bool bIsRegular = false;
    EBatchShapeType ShapeType = EBatchShapeType::Null;
    int32 Thickness = 0;

    // === 变换原点（新增）===
    /** 当前变换原点模式 */
    UPROPERTY(EditAnywhere, BlueprintReadWrite)
    EVoxelPivotMode PivotMode = EVoxelPivotMode::Cursor;

    /** 游标世界坐标（仅 Cursor 模式有效） */
    UPROPERTY(EditAnywhere, BlueprintReadWrite)
    FVector PivotWorld = FVector::ZeroVector;

    /** 获取变换原点：ObjectCenter→几何中心, Cursor→游标位置 */
    FVector GetPivotWorld(float BlockLength) const
    {
        if (PivotMode == EVoxelPivotMode::Cursor)
        {
            return PivotWorld;
        }
        return GetGeometricCenter(BlockLength);
    }

    // === 删除的字段 ===
    // 删除 FVector Center         → 几何中心改为实时计算 GetGeometricCenter()
    // 删除 bool bCenterInitialized → 不需要缓存
    // 删除 void InitCenter()       → 不需要初始化缓存
    // 删除 void Recenter()         → 轨道旋转后直接更新 Box，不需要重定位中心
    
    // === 操作方法 ===
    void MoveGEO(FIntVector Delta);      // 仅更新 Box（不涉及 Center）
    bool ModifyCoverage(...);            // 仅更新 Box
    void RotateGEO(FRotator Delta);     // 仅更新 Rotation

    // === operator== ===
    bool operator==(const FVoxelGeometryDesc& Other) const
    {
        return Box == Other.Box
            && Rotation == Other.Rotation
            && bIsRegular == Other.bIsRegular
            && ShapeType == Other.ShapeType
            && Thickness == Other.Thickness;
            // 注意：PivotMode 和 PivotWorld 不参与一致性比较
    }
};
```

## 关键决策 1: Center 字段删除，改为实时计算

### 决策

删除 `FVector Center` 缓存字段，`GetCenter()` 改为实时计算（重命名为 `GetGeometricCenter()`）。

### 理由

| 考虑 | 分析 |
|------|------|
| **语义冲突** | `Center` 既是"几何中心"又是"变换原点"的候选，引入 Pivot 后语义更模糊 |
| **缓存无意义** | 几何中心从 Box 计算很简单（`(MinPos + MaxPos)*0.5*BlockLength`），不需要缓存 |
| **轨道旋转后** | 轨道旋转会直接更新 `Box` 位置，不需要维护 `Center` |
| **operator== 污染** | 当前 `Center` 参与 `operator==` → 导致两个相同几何体（Center 不同）被判定为不相等 |

### 影响

- `GetCenter()` → 重命名为 `GetGeometricCenter()`，实时计算，无缓存
- `operator==` 删除 `Center` 比较 → `Box + Rotation + bIsRegular + ShapeType + Thickness` 相同就是同一几何体
- 29 处调用 `GetCenter()` 保持语义不变（仍获取几何中心），只有 `HandleGizmo_Rotate` 和 Gizmo 显示改用 `GetPivotWorld()`

## 关键决策 2: 新增 GetPivotWorld() 分流

### 决策

`GetCenter()` 语义不变（永远返回几何中心），新增 `GetPivotWorld()` 根据 `PivotMode` 返回对应值。

### 理由

| 考虑 | 分析 |
|------|------|
| **语义不混淆** | 29 处调用方不需要知道 PivotMode，它们要的就是几何中心 |
| **调用方改动小** | 仅 `HandleGizmo_Rotate` 和 Gizmo 显示 2 处改用 `GetPivotWorld()` |
| **可读性** | `GetPivotWorld` 方法名明确表达"获取变换原点"的意图 |

```cpp
FVector GetPivotWorld(float BlockLength) const
{
    return (PivotMode == EVoxelPivotMode::Cursor)
        ? PivotWorld
        : GetGeometricCenter(BlockLength);
}
```

## 关键决策 3: 轨道旋转行为

### 决策

Cursor 模式下旋转时，物体**绕游标做轨道运动**，即：旋转角度改变 + 物体位置同时改变（类似 Blender 默认行为）。

### 轨道旋转公式

```
Pivot      = PivotWorld                              // 变换原点（游标位置）
GeoCenter  = GetGeometricCenter(BlockLength)         // 当前几何中心
Offset     = GeoCenter - Pivot                       // 从 Pivot 到几何中心的向量
NewOffset  = DeltaRotation.RotateVector(Offset)      // 旋转这个向量
NewGeoCenter = Pivot + NewOffset                     // 新几何中心
DeltaWorld = NewGeoCenter - GeoCenter                // 位移差值
DeltaIndex = WorldDeltaToIndexDelta(DeltaWorld)      // 转为体素索引偏移

// 应用到 Box
Box.MinIndex += DeltaIndex
Box.MaxIndex += DeltaIndex
Rotation     += DeltaRotation
// PivotWorld 不变（游标世界坐标固定）
```

### 与 ObjectCenter 模式的区别

| 模式 | `GetPivotWorld()` | 旋转效果 |
|------|-------------------|---------|
| ObjectCenter | 几何中心 | `Offset = 0` → `NewGeoCenter = GeoCenter` → 原地旋转 |
| Cursor | `PivotWorld`（游标位置） | `Offset ≠ 0` → 轨道运动 |

同一个公式，两种模式自然兼容：

```cpp
void HandleGizmo_Rotate(FRotator DeltaRotation)
{
    FVector Pivot = GetPivotWorld(BlockLength);
    FVector GeoCenter = GetGeometricCenter(BlockLength);
    
    FVector Offset = GeoCenter - Pivot;
    FVector NewOffset = DeltaRotation.RotateVector(Offset);
    FVector NewGeoCenter = Pivot + NewOffset;
    
    // 更新 Box 位置
    FVector DeltaWorld = NewGeoCenter - GeoCenter;
    FIntVector DeltaIndex = UChunkUtilsFunction::WorldDeltaToIndexDelta(DeltaWorld, BlockLength);
    Box.MinIndex += DeltaIndex;
    Box.MaxIndex += DeltaIndex;
    
    // 更新旋转（增量累加到 Rotation）
    Rotation += DeltaRotation;
    // 注意：增量需要正确处理 FRotator 的 Pitch/Roll/Roll 分别累加
    
    // PivotWorld 不变
}
```

## 关键决策 4: 游标放置交互

### 游标 Actor

新建 `AVoxelPivotCursorActor`：
- 视觉：十字线 + 圆环（`UMeshComponent`，无碰撞，纯渲染）
- 碰撞：`USphereComponent`，`UI` Collision Profile（`ECC_GameTraceChannel6`）
- 显隐：仅在 `EDIT` 阶段且 `PivotMode == Cursor` 时显示
- 生命周期：由 `UVoxelControllerVisualUIComponent` 管理（创建于 `SetPreviewState(EDIT)`，销毁于覆盖/退出的新放置）

### 放置方式

| 方式 | 操作 | 说明 |
|------|------|------|
| **拖拽放置** | 按住 Gizmo 拖拽 | 游标 Actor 响应鼠标拖拽（类似 Gizmo 拖拽），`PivotWorld` 每帧更新 |
| **吸附物体中心** | 按钮"游标→中心" | `PivotWorld = GetGeometricCenter()` - 设置游标到当前物体中心 |
| **物体移到游标** | 按钮"中心→游标" | 更新 `Box`，使 `GetGeometricCenter() = PivotWorld` - 移动物体到游标位置 |

### 游标拖拽交互流程

```
1. 鼠标点击游标 Actor → 命中 ECC_GameTraceChannel6
2. HandleMouseInput 判断为游标拖拽 → 进入 CursorDrag 状态
3. TickComponent 每帧更新：
   - 地面射线检测（ECC_GameTraceChannel1）获取鼠标位置
   - 更新 PivotWorld = 世界坐标（吸附到体素网格）
   - 更新游标 Actor 位置
4. 鼠标松开 → 退出 CursorDrag 状态
```

### 游标独立于物体

- 游标是独立的世界坐标点，不跟随物体移动（Translate Gizmo 拖拽物体时游标不动）
- 切换 PivotMode 时，游标只是视觉上显/隐切换
