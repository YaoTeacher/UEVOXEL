## 一、需求概述

为选区工具（`Tool_Selection_*`）实现特殊的预览显示逻辑：

### 展示内容

1. **WireframeMesh**: 最大边界框（固定，不随鼠标框选移动）
2. **ProceduralMesh**: 实际选中的体素（动态，随鼠标框选移动）
3. **InnerMesh**: 本次操作的影响范围
   - **单体素模式**: 鼠标位置
   - **几何体模式**: 当前正在调参的几何体范围

### 2.2 核心实现逻辑

#### 编辑工具版本（`UpdateSimpleGeometryPreview`）

```cpp
void AVoxelPreviewActor::UpdateSimpleGeometryPreview(
    const FVoxelEditRequest& Request,
    float BlockLength)
{
    // 1. WireframeMesh: 几何体外框
    UpdateMeshByShape(WireframeMesh, EBatchShapeType::Box, OuterBounds, ...);

    // 2. InnerMesh: 本次操作影响范围（几何体填充区域）
    UpdateMeshByShape(InnerMesh, Request.Geometry.ShapeType, FillBounds, ...);

    // 3. ThicknessMesh: 挖空/扩张边界（如果有厚度）
    if (Request.Geometry.Thickness != 0)
    {
        UpdateMeshByShape(ThicknessMesh, EBatchShapeType::Box, ThicknessBounds, ...);
    }

    // 4. BlueprintMesh: 隐藏（编辑工具不使用）
    BlueprintMesh->SetHiddenInGame(true);
}
```

#### 选区工具版本（`UpdateSimpleGeometryPreviewWithSelection`）

```cpp
void AVoxelPreviewActor::UpdateSimpleGeometryPreviewWithSelection(
    const FVoxelEditRequest& Request,
    float BlockLength,
    const TArray<FIntVector>& SelectedVoxels)
{
    // 1. WireframeMesh: 最大边界（固定）
    UpdateMeshByShape(WireframeMesh, EBatchShapeType::Box, BaseBounds, ...);

    // 2. ProceduralMesh: 实际选中的体素（动态）
    if (SelectedVoxels.Num() > 0)
    {
        // 清空之前的网格
        BlueprintMesh->ClearMeshSection(0);

        // 为每个选中的体素创建立方体网格
        for (const FIntVector& VoxelIndex : SelectedVoxels)
        {
            FVector VoxelWorldPos = FVector(VoxelIndex) * BlockLength;
            FVector BoxMin = VoxelWorldPos;
            FVector BoxMax = VoxelWorldPos + FVector(BlockLength);

            AddCubeMeshData(Vertices, Triangles, Normals, UVs, VertexColors,
                BoxMin, BoxMax, VertexOffset);
        }

        // 创建网格
        BlueprintMesh->CreateMeshSection_LinearColor(0, Vertices, Triangles, Normals, UVs, VertexColors);
        BlueprintMesh->SetHiddenInGame(false);
    }

    // 3. InnerMesh: 隐藏（使用ProceduralMesh替代）
    InnerMesh->SetHiddenInGame(true);

    // 4. ThicknessMesh: 隐藏（选区工具不使用）
    ThicknessMesh->SetHiddenInGame(true);
}
```

### 2.3 VisualUIComponent调用逻辑

```cpp
void UVoxelControllerVisualUIComponent::HandleBuildModeParamsUpdated()
{
    FGameplayTag CurrentToolTag = CachedStateComponent->GetBuildState();

    // ==================== 选区工具 ====================
    if (CurrentToolTag == FCoreTags::Tool_Selection_SimpleGeometry)
    {
        // 计算选区数据（实际选中的体素）
        FVoxelEditRequest Request = CachedStateComponent->GetCurrentEditRequest();
        TArray<FIntVector> SelectedVoxels = UVoxelSelectionTool::CalculateSelection(Request, BlockLength);

        // 使用选区版本的方法更新预览
        PreviewActor->UpdateSimpleGeometryPreviewWithSelection(Request, BlockLength, SelectedVoxels);
    }
    // ==================== 编辑/区域工具 ====================
    else if (CurrentToolTag == FCoreTags::Tool_Edit_SimpleGeometry ||
             CurrentToolTag == FCoreTags::Tool_AreaEdit_Create ||
             CurrentToolTag == FCoreTags::Tool_AreaEdit_Modify)
    {
        FVoxelEditRequest Request = CachedStateComponent->GetCurrentEditRequest();
        PreviewActor->UpdateSimpleGeometryPreview(Request, BlockLength);
    }
}
```

## 三、选区预览数据流

```
用户操作（鼠标拖拽）
    ↓
StateComponent::TmpGeometry (临时几何数据)
    ↓
VisualUIComponent::HandleBuildModeParamsUpdated()
    ↓
UVoxelSelectionTool::CalculateSelection()  // 计算实际选中的体素
    ↓
PreviewActor::UpdateSimpleGeometryPreviewWithSelection()
    ↓
┌─────────────────────────────────────────┐
│ WireframeMesh: 最大边界（固定）          │
│   - 基于Geometry.GetBound()              │
│   - 不随鼠标框选移动                     │
├─────────────────────────────────────────┤
│ ProceduralMesh: 实际选中的体素（动态）    │
│   - 基于CalculateSelection()计算          │
│   - 随鼠标框选实时更新                    │
│   - 使用AddCubeMeshData()生成网格         │
├─────────────────────────────────────────┤
│ InnerMesh: 隐藏                           │
│   - 选区工具使用ProceduralMesh替代        │
├─────────────────────────────────────────┤
│ ThicknessMesh: 隐藏                       │
│   - 选区工具不使用厚度                    │
└─────────────────────────────────────────┘
```

## 六、性能优化建议

### 6.1 当前实现

- 每次预览更新都调用 `UVoxelSelectionTool::CalculateSelection()` 计算选区
- 为每个选中体素生成独立的立方体网格

### 6.2 优化方向

1. **缓存选区数据**: 在StateComponent中缓存上次计算的选区，只在几何变化时重新计算
2. **网格合并**: 将多个体素的立方体网格合并为一个网格，减少DrawCall
3. **实例化渲染**: 使用Instance Mesh渲染大量相同的立方体
4. **LOD优化**: 选区体素数量过多时使用简化的预览
