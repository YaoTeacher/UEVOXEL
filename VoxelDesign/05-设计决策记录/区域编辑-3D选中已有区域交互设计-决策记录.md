# 区域编辑 - 3D 选中已有区域交互设计

> **日期**: 2026-06-20
> **状态**: 已批准
> **关联**: 交互系统-射线检测通道统一与状态驱动设计-决策记录

## 1. 背景与问题

### 1.1 现状

区域编辑模式（`Tool.AreaEdit`）下，玩家**无法在 3D 场景中直接点击选中已有区域**，只能通过 UI 列表（`M8_AreaInfoModule` 的 `UVoxelAreaItemWidget`）选中。

### 1.2 根因

一次射线检测通道统一重构（见 [交互系统-射线检测通道统一决策记录](../05-设计决策记录/交互系统-射线检测通道统一与状态驱动设计-决策记录.md)）移除了旧蓝图 `BP_TopDownPlayerController` 中使用 Area 通道（`ECC_GameTraceChannel3`）的 LineTrace。

该重构的初衷是修复 Gizmo 通道错误（旧代码用 `ECC_Visibility`，应为 `ECC_GameTraceChannel6`），但重构时把"用 Area 通道选中 Area Actor"这个本身合理的功能一并移除了。决策记录中"通道不该是 Area"的结论是针对 Gizmo 的，不适用于 Area Actor 本身的选中检测。

### 1.3 现有基础设施（均已就绪，无需新建）

| 设施 | 位置 | 状态 |
|------|------|------|
| Area 碰撞通道 `ECC_GameTraceChannel3` | `Config/DefaultEngine.ini:525` (Name="Area", bTraceType=True) | 已配置 |
| "Area" 碰撞 Profile | `Config/DefaultEngine.ini:520` (ObjectType=AreaBlock, QueryOnly, 对 Area 通道 Block, 对其它 Ignore) | 已配置 |
| BoxVisual 碰撞配置 | 蓝图子类 `DefaultAreaType` 中应用 "Area" Profile | 已配置 |
| `SelectArea()` 选中入口 | `VoxelControllerInteractComponent.cpp:510` | 已实现 |
| `InternalSetCurrentArea()` 状态流转 | `VoxelControllerStateComponent.cpp:227` | 已实现 |
| `SetCurrentArea(nullptr)` 级联回退 | `VoxelControllerStateComponent.cpp:206` | 已实现 |
| `UpdateSubAreasVisual()` 子区域显隐 | `VoxelAreaWorldSubsystem.cpp:387` | 已实现 |
| `UpdateAreaVisual()` 可视化控制 | `VoxelAreaBaseInstance.cpp:231` | 已实现（需扩展权限态） |
| `OnCurrentAreaChanged` 广播 | `VoxelControllerStateComponent` | 已实现 |

## 2. 设计目标

1. 进入区域编辑模式后，3D 场景中自动显示当前父区域的直接子区域边界
2. 玩家可在 3D 场景中直接点击子区域选中并编辑
3. 全部子区域显示，无权限的用灰色标记（只读）
4. 层级导航走现有"进入子区域/返回父区域"
5. 右键级联回退：先清 CurArea，再降 CurParentArea，直到两个都空

---

## 3. 交互设计

### 3.1 状态互斥规则

**有 CurArea → 只拖 Gizmo（EDIT）；无 CurArea → 才能点选区域和新建（HIDDEN/BASE）**

BuildPhase 与 CurArea 严格同步：

| 状态 | BuildPhase | CurArea | 可执行操作 |
|------|-----------|---------|-----------|
| 可点选/新建 | HIDDEN | nullptr | Area 射线选中 + 地面射线新建 |
| 编辑中 | EDIT | 非空 | Gizmo 射线 + 地面参考 |

### 3.2 3D 点击选中流程

```
玩家点击鼠标（CurArea == nullptr，即 HIDDEN/BASE 阶段）
  → HandleMouseInput()
  → 射线检测 Area 通道（ECC_GameTraceChannel3）
      ├─ 命中且是当前父区域的直接子区域
      │   → SelectArea(HitArea)
      │   → InternalSetCurrentArea → SetBuildPhase(EDIT) + 广播
      │   → 进入编辑态（Gizmo 出现）
      └─ 未命中 / 命中但非直接子区域
          → 走现有地面射线（BuildGround）新建区域选点
```

射线检测范围（CurArea == nullptr 时）：
- **Area 射线**（`ECC_GameTraceChannel3`）：命中子区域则选中
- **地面射线**（`ECC_GameTraceChannel1`）：未命中 Area 时新建选点
- **不检测 Gizmo**（未选中时无 Gizmo）

射线检测范围（CurArea != nullptr 时，即 EDIT 阶段）：
- **Gizmo 射线**（`ECC_GameTraceChannel6`）：拖拽编辑
- **地面射线**（`ECC_GameTraceChannel1`）：参考位置
- **不检测 Area**（防止拖拽时误选其他区域）

### 3.3 右键级联回退

右键在区域编辑模式下调用 `SetCurrentArea(nullptr)`，利用现有级联逻辑：

```
右键 → SetCurrentArea(nullptr)
  情况1: 有 CurArea → 清空 CurArea → BuildPhase=HIDDEN → 回到可点选/新建态
  情况2: 无 CurArea 有 CurParentArea → CurParentArea 降为 CurArea，
         新 CurParentArea = 旧 CurParentArea->ParentArea → BuildPhase=EDIT
  情况3: 都空 → 什么都不做
```

连续右键交替"清空→降级→清空→降级"，直到 CurArea 和 CurParentArea 都为空。

### 3.4 子区域自动显隐

复用现有 `UpdateSubAreasVisual(ParentArea, IsVisible)`，触发时机为 `OnCurrentAreaChanged` 广播时：

- CurArea 清空（情况1）→ 显示 CurParentArea 的直接子区域（回到可点选态）
- CurParentArea 降为 CurArea（情况2）→ 显示新 CurParentArea 的直接子区域
- 选中子区域 → 保持当前层级子区域显示，选中区域变红

### 3.5 权限标记

全部子区域显示，无权限的用灰色标记：
- 有权限（`IsAreaEditable(CharId)` 为 true）→ AreaColor（默认绿色）
- 无权限 → 灰色 `FColor(128, 128, 128)`
- 选中 → 红色（现有）
- 无权限区域点击后只读（选中但不显示 Gizmo，不可编辑边界）

## 4. 核心改动点

### 4.1 `HandleMouseInput()` 增加 Area 射线（[VoxelControllerInteractComponent.cpp:737](../Source/Voxel/Private/Core/ControllerComponent/VoxelControllerInteractComponent.cpp)）

在 `CurArea == nullptr`（HIDDEN/BASE 阶段）分支增加 Area 射线检测：

```cpp
// CurArea == nullptr 时（HIDDEN/BASE）
if (SC->GetCurrentArea() == nullptr)
{
    // 新增：Area 射线
    FHitResult AreaHit;
    const bool bAreaHit = SC->GetWorld()->LineTraceSingleByChannel(
        AreaHit, WorldLocation, TraceEnd, ECC_GameTraceChannel3, Params);

    if (bAreaHit)
    {
        AVoxelAreaBaseInstance* HitArea = Cast<AVoxelAreaBaseInstance>(AreaHit.GetActor());
        // 校验是否为当前父区域的直接子区域
        if (HitArea && HitArea->ParentArea == SC->GetCurrentParentArea())
        {
            SelectArea(HitArea);
            return;
        }
    }
    // 未命中 Area → 走现有地面射线（新建区域选点）
}
// CurArea != nullptr 时（EDIT）→ 现有 Gizmo + 地面射线，不变
```

新增辅助判断：`HitArea->ParentArea == SC->GetCurrentParentArea()`（直接内联，无需独立方法）。

### 4.2 `HandleMouseCancel()` 区域编辑模式调用 `SetCurrentArea(nullptr)`（[L913](../Source/Voxel/Private/Core/ControllerComponent/VoxelControllerInteractComponent.cpp)）

```cpp
void HandleMouseCancel()
{
    UVoxelControllerStateComponent* SC = GetControllerState();
    if (!SC) return;

    FGameplayTag ToolTag = SC->GetCurrentToolTag();

    if (ToolTag.MatchesTag(FCoreTags::Tool_Edit_SingleVoxel))
    {
        bIsModyfing = false;
        return;
    }

    CancelCurrentEdit();
    RequestCancelVoxelEdit();

    // 新增：区域编辑模式下级联回退 CurArea/CurParentArea
    // 放在 CancelCurrentEdit 之后，因为 InternalSetCurrentArea 会同步 BuildPhase，
    // 避免被 CancelCurrentEdit 的 SetBuildPhase(HIDDEN) 覆盖
    if (ToolTag.MatchesTag(FCoreTags::Tool_AreaEdit))
    {
        SC->SetCurrentArea(nullptr);
    }
}
```

### 4.3 `InternalSetCurrentArea()` 同步 BuildPhase（[VoxelControllerStateComponent.cpp:227](../Source/Voxel/Private/Core/ControllerComponent/VoxelControllerStateComponent.cpp)）

```cpp
void InternalSetCurrentArea(AVoxelAreaBaseInstance* Area)
{
    if (CurArea != Area)
    {
        AVoxelAreaBaseInstance* Old = CurArea;
        CurArea = Area;

        if (Area)
        {
            // 提取信息（现有）
            TmpAreaInfo.AreaName = Area->AreaBase.AreaName;
            // ...
            TmpGeometry.Box = Area->AreaBase.AreaCoverage;
            SetCurrentParentArea(Area->ParentArea);

            // 新增：同步 BuildPhase
            SetBuildPhase(EPreviewInteractionState::EDIT);

            OnBuildModeParamsUpdated.Broadcast();
        }
        else
        {
            ResetTmpAreaInfo();
            // 新增：同步 BuildPhase
            SetBuildPhase(EPreviewInteractionState::HIDDEN);
        }
        OnCurrentAreaChanged.Broadcast(Old, CurArea);
    }
}
```

### 4.4 `UpdateAreaVisual()` 扩展权限态（[VoxelAreaBaseInstance.cpp:231](../Source/Voxel/Private/Area/VoxelAreaBaseInstance.cpp)）

```cpp
// 签名扩展
void UpdateAreaVisual(bool isVisible, bool isSelected, bool bReadOnly = false)
{
    if (!BoxVisual) return;
    BoxVisual->SetHiddenInGame(!isVisible);
    SetActorEnableCollision(isVisible);

    if (isVisible)
    {
        if (bReadOnly)
        {
            UpdateVisualColor(FColor(128, 128, 128));  // 灰色：无权限
        }
        else if (isSelected)
        {
            UpdateVisualColor(FColor::Red);            // 红色：选中
        }
        else
        {
            UpdateVisualColor(AreaColor);              // AreaColor：正常
        }
    }
}
```

### 4.5 `UpdateSubAreasVisual()` 传递权限态（[VoxelAreaWorldSubsystem.cpp:387](../Source/Voxel/Private/GameManager/WorldManager/VoxelAreaWorldSubsystem.cpp)）

扩展 `UpdateSubAreasVisual` 增加权限参数，遍历子区域时调用 `IsAreaEditable(CharId)` 判断权限并传递 `bReadOnly`：

```cpp
void UpdateSubAreasVisual(AVoxelAreaBaseInstance* ParentArea, const bool IsVisible, int32 CharId = -1)
{
    UpdateAllAreasVisual(false);

    if (!ParentArea || !ParentArea->IsValidLowLevel())
    {
        // 顶层区域
        for (const auto& Pair : AreaIndex)
        {
            if (Pair.Value && Pair.Value->IsValidLowLevel() && Pair.Value->SubAreasIndex.Num() <= 0)
            {
                bool bReadOnly = !Pair.Value->IsAreaEditable(CharId);
                Pair.Value->UpdateAreaVisual(IsVisible, false, bReadOnly);
            }
        }
        return;
    }

    ParentArea->UpdateAreaVisual(IsVisible, false);
    for (const auto& Pair : ParentArea->SubAreasIndex)
    {
        if (Pair.Value && Pair.Value->IsValidLowLevel())
        {
            bool bReadOnly = !Pair.Value->IsAreaEditable(CharId);
            Pair.Value->UpdateAreaVisual(IsVisible, false, bReadOnly);
        }
    }
}
```

### 4.6 `VisualUIComponent` 监听显隐触发

在 `HandleCurrentAreaChanged`（[L798](../Source/Voxel/Private/Core/ControllerComponent/VoxelControllerVisualUIComponent.cpp)）中，选中变化时调用 `UpdateSubAreasVisual` 刷新子区域显示：

```cpp
void HandleCurrentAreaChanged(AVoxelAreaBaseInstance* OldArea, AVoxelAreaBaseInstance* NewArea)
{
    if (OldArea && OldArea->IsValidLowLevel()) OldArea->UpdateAreaVisual(true, false);
    if (NewArea && NewArea->IsValidLowLevel()) NewArea->UpdateAreaVisual(true, true);

    // 新增：刷新当前层级的子区域显示
    // InternalSetCurrentArea 已同步 CurParentArea，直接使用即可
    if (auto* AreaSubsystem = GetWorld()->GetSubsystem<UVoxelAreaWorldSubsystem>())
    {
        AVoxelAreaBaseInstance* DisplayParent = SC->GetCurrentParentArea();
        int32 CharId = /* 从 PlayerController/StateComponent 获取当前角色 ID */;
        AreaSubsystem->UpdateSubAreasVisual(DisplayParent, true, CharId);
    }
}
```

## 6. 边界情况

| 场景 | 处理 |
|------|------|
| 点击非当前父区域的直接子区域（如兄弟区域的子区域） | 忽略，不选中（`HitArea->ParentArea != CurParentArea`） |
| 区域内无方块（空心区域） | Area 射线命中 BoxVisual 边界框，正常选中 |
| 嵌套区域重叠 | 只命中最近的（LineTraceSingleByChannel 返回最近命中） |
| 无权限区域点击 | 选中但只读（不显示 Gizmo，不可编辑边界） |
| 右键到最顶层（CurArea 和 CurParentArea 都空） | 什么都不做（情况3） |
| 选中后点击空白地面 | CurArea 非空 → EDIT 阶段 → 只检测 Gizmo + 地面参考，不新建 |

- Area 通道（`ECC_GameTraceChannel3`）用于检测 Area Actor 本身是正当用法
- 与 Gizmo(3DUI)、地面(BuildGround) 通过碰撞响应矩阵天然隔离（Area Profile 对其它通道均 Ignore）

## 8. 测试要点

1. 进入区域编辑模式 → 当前父区域的直接子区域自动显示边界
2. 点击子区域 → 选中（变红）、Gizmo 出现、可拖拽编辑
