## 八、Recenter旋转计算逻辑决策

> **决策日期**：2026-01-17  
> **决策状态**：✅ 已确定

---

### 问题

Box 存储在索引空间（不旋转），但视觉上盒子已经旋转。Recenter 时需要计算"旋转后的实际几何中心"。

### 方案

**选择方案B**：`Center = 将 C 绕 A 旋转 Rotation 角度后的位置`

其中：
- C = 未旋转的几何中心（基于 Box 计算）
- A = 当前的 Center（旋转轴心）
- Rotation = 当前旋转角度

### 计算流程

```
1. 计算几何中心 C（未旋转）
2. 获取当前旋转中心 A
3. 计算向量 AC = C - A
4. 旋转向量：RotatedAC = AC.RotateVector(Rotation)
5. 计算新位置：B = A + RotatedAC
6. 体素对齐：Center = Round(B / BlockLength) * BlockLength
```

### 理由

- 符合用户看到的视觉状态
- Recenter 后 Center 在"旋转后的包围盒"中心
- 语义正确：重置到"当前状态下的几何中心"

### 边界检查

- Box 约束：MinIndex <= MaxIndex
- Center 有效性：非 NaN、非 Infinity
- Rotation 不检查：允许任意角度
