# 区域树展示组件设计

> **日期**: 2026-06-20
> **状态**: 已批准
> **关联**: 区域编辑-3D选中已有区域交互设计-决策记录

---

## 1. 背景与问题

### 1.1 现状

区域编辑模式下区域展示采用"逐级钻取"模式：面包屑导航（水平路径）+ 扁平列表（VerticalBox）。只能看到当前层级的直接子区域，无法展开/折叠、多级概览。项目中**没有任何 Tree View 组件**。

### 1.2 问题

- 无法在一个视图中看到多层级嵌套的全貌
- 列表项没有展开按钮，无法查看孙级及更深层级
- 扁平 VerticalBox 无缩进，无法直观体现父子嵌套关系
- 区域层级较深时（场景→楼层→房间→功能区→货架区），查看深层区域需要多次点击

### 1.3 目标

制作一个**通用区域树列表组件**，两处复用：
1. **M13a 中的当前区域下属树**：以当前选中区域为根，展示其子区域树
2. **全局区域树**：面包屑位置，默认面包屑，点击展开按钮切换为完整区域树

---

## 2. 技术方案

使用 **UE5 UMG UTreeView** 实现树形控件，原生支持展开/折叠、缩进、虚拟化，与项目现有 UMG 体系一致。

---

## 3. 组件架构

### 3.1 新增组件一览

| 组件 | 基类 | 职责 |
|------|------|------|
| `UVoxelAreaTreeNode` | UObject | 树节点数据，持有 Area + Children + bIsReadOnly |
| `UVoxelAreaTreeEntryWidget` | UUserWidget | 树节点列表项，展开箭头 + 区域信息 + 权限颜色 |
| `UVoxelAreaTreeWidget` | UUserWidget | 通用树容器，封装 UTreeView + 数据填充 + 展开控制 |
| `UVoxelAreaNavigatorWidget` | UUserWidget | 区域导航器，面包屑 + 树视图切换 |

### 3.2 组件关系

```
[全局导航]                                    [M13a 下属树]
UBuildPanelWidget                             UM13a_AreaBasicInfoEditModule
└── UVoxelAreaNavigatorWidget                 └── SubAreaTreeContainer
    ├── BreadcrumbContainer（面包屑-默认）          └── UVoxelAreaTreeWidget（直接使用）
    ├── ExpandToggleButton（展开/收起按钮）
    └── AreaTreeWidget（UVoxelAreaTreeWidget）
        └── UTreeView
            └── UVoxelAreaTreeEntryWidget × N
```

`UVoxelAreaNavigatorWidget` 内部组合了面包屑 + `UVoxelAreaTreeWidget`；M13a 只用 `UVoxelAreaTreeWidget` 本身。

## 4. 组件详细设计

### 4.1 `UVoxelAreaTreeNode`（树节点数据）

**文件**: `Public/Core/UI/Build/AreaTree/VoxelAreaTreeNode.h`

```cpp
UCLASS(BlueprintType)
class UVoxelAreaTreeNode : public UObject
{
    GENERATED_BODY()
public:
    UPROPERTY()
    AVoxelAreaBaseInstance* Area = nullptr;  // nullptr = 世界根节点

    UPROPERTY()
    TArray<UVoxelAreaTreeNode*> Children;    // 子节点

    UPROPERTY()
    bool bIsReadOnly = false;                // 无权限标记

    // 从指定父区域递归构建子树
    // RootArea=nullptr 表示从世界根开始（全局树）
    // CharId 用于权限判定（IsAreaEditable）
    UFUNCTION()
    static UVoxelAreaTreeNode* BuildTree(AVoxelAreaBaseInstance* RootArea, int32 CharId);
};
```

`BuildTree` 逻辑（需通过 `GetWorld()` 获取 `UVoxelAreaWorldSubsystem`）：
1. 创建当前节点，设置 `Area = RootArea`
2. 若 `RootArea == nullptr`：通过 `GetWorld()->GetSubsystem<UVoxelAreaWorldSubsystem>()` 获取所有区域，筛选 `ParentArea == nullptr` 的顶级区域作为子节点
3. 若 `RootArea != nullptr`：遍历 `RootArea->SubAreasIndex` 作为子节点
4. 对每个子区域调用 `IsAreaEditable(CharId)` 设置 `bIsReadOnly`
5. 递归构建子节点的子树

### 4.2 `UVoxelAreaTreeEntryWidget`（列表项控件）

**文件**: `Public/Core/UI/Build/AreaTree/VoxelAreaTreeEntryWidget.h` + `.cpp`

绑定的 UMG 控件：
- `ExpandButton`（UButton）- 展开/折叠箭头（UTreeView 原生管理展开状态，此按钮仅触发 `TreeView->SetItemExpansion`）
- `AreaNameText`（UTextBlock）- 区域名（nullptr 显示 "World Root"）
- `AreaTypeText`（UTextBlock）- 区域类型（通过 ConfigDataSubsystem 查配置表）
- `ItemClickButton`（UButton）- 覆盖整行的透明按钮，点击调用 `SelectArea`

颜色规则（复用 `UpdateAreaVisual` 的权限态逻辑）：
- `bReadOnly = true` → 灰色文字
- `bReadOnly = false`，非选中 → 正常色（白色）
- 当前选中区域 → 红色文字

初始化入口：
```cpp
void Setup(UVoxelAreaTreeNode* Node, UTreeView* OwnerTreeView, bool bIsSelected);
```

点击行为：
```cpp
void OnItemClick()
{
    if (PC && PC->InteractComp)
    {
        PC->InteractComp->SelectArea(Node->Area);
    }
}
```

展开按钮行为：
```cpp
void OnExpandClicked()
{
    if (OwnerTreeView && Node)
    {
        bool bExpanded = OwnerTreeView->IsItemExpanded(Node);
        OwnerTreeView->SetItemExpansion(Node, !bExpanded);
    }
}
```

### 4.3 `UVoxelAreaTreeWidget`（通用树容器）

**文件**: `Public/Core/UI/Build/AreaTree/VoxelAreaTreeWidget.h` + `.cpp`

```cpp
UCLASS()
class UVoxelAreaTreeWidget : public UUserWidget
{
    GENERATED_BODY()
public:
    /**
     * 初始化树：指定根区域，构建并填充 TreeView
     * @param RootArea 根区域，nullptr 表示从世界根开始
     * @param CharId 当前角色 ID，用于权限判定
     * 默认展开根节点的直接子节点（第一级），其他层级折叠
     */
    void InitializeTree(AVoxelAreaBaseInstance* RootArea, int32 CharId);

    /** 高亮指定区域（当前选中区域） */
    void SetSelectedArea(AVoxelAreaBaseInstance* SelectedArea);

protected:
    UPROPERTY(meta = (BindWidget))
    UTreeView* AreaTreeView;

    UPROPERTY(meta = (BindWidgetOptional))
    TSubclassOf<UVoxelAreaTreeEntryWidget> EntryWidgetClass;

    UPROPERTY()
    UVoxelAreaTreeNode* RootNode = nullptr;

    UPROPERTY()
    AVoxelAreaBaseInstance* CurrentSelected = nullptr;

    // UTreeView 回调
    UFUNCTION() void OnGetChildren(UObject* Item, TArray<UObject*>& OutChildren);
    UFUNCTION() void OnEntryGenerated(UWidget* EntryWidget);
    UFUNCTION() void OnEntrySelectionChanged(UObject* Item);

    // 辅助：在树中查找指定 Area 对应的节点
    UVoxelAreaTreeNode* FindNodeForArea(UVoxelAreaTreeNode* Node, AVoxelAreaBaseInstance* TargetArea);
};
```

`InitializeTree` 逻辑：
1. `RootNode = UVoxelAreaTreeNode::BuildTree(RootArea, CharId)`
2. `AreaTreeView->ClearListItems()`
3. `AreaTreeView->SetListItems({ RootNode })`（UTreeView 通过 OnGetChildren 自动展开子节点）
4. 默认展开根节点的直接子节点：
   ```cpp
   for (UVoxelAreaTreeNode* Child : RootNode->Children)
   {
       AreaTreeView->SetItemExpansion(Child, true);
   }
   ```
5. 调用 `SetSelectedArea` 高亮当前选中区域

### 4.4 `UVoxelAreaNavigatorWidget`（区域导航器）

**文件**: `Public/Core/UI/Build/AreaTree/VoxelAreaNavigatorWidget.h` + `.cpp`

```cpp
UCLASS()
class UVoxelAreaNavigatorWidget : public UUserWidget
{
    GENERATED_BODY()
public:
    /** 从 StateComponent 刷新导航器（内部缓存 SC 引用） */
    void Refresh(UVoxelControllerStateComponent* SC);

protected:
    UPROPERTY()
    TObjectPtr<UVoxelControllerStateComponent> CachedStateComponent;  // Refresh 时缓存
    // ===== 面包屑模式 =====
    UPROPERTY(meta = (BindWidget))
    UPanelWidget* BreadcrumbContainer;

    UPROPERTY(meta = (BindWidgetOptional))
    TSubclassOf<UVoxelAreaItemWidget> BreadcrumbItemClass;

    // ===== 树视图模式 =====
    UPROPERTY(meta = (BindWidget))
    UVoxelAreaTreeWidget* AreaTreeWidget;

    // ===== 切换按钮 =====
    UPROPERTY(meta = (BindWidget))
    UButton* ExpandToggleButton;

    bool bTreeMode = false;

    UFUNCTION() void OnExpandToggleClicked();

    // 面包屑刷新（从 BuildPanelWidget::UpdateBreadcrumbs 迁移）
    void UpdateBreadcrumbs(UVoxelControllerStateComponent* SC);
    // 树刷新
    void UpdateTree(UVoxelControllerStateComponent* SC);
};
```

`Refresh` 逻辑：
```cpp
void Refresh(UVoxelControllerStateComponent* SC)
{
    if (bTreeMode)
    {
        UpdateTree(SC);
    }
    else
    {
        UpdateBreadcrumbs(SC);
    }
}
```

`OnExpandToggleClicked` 逻辑：
```cpp
void OnExpandToggleClicked()
{
    bTreeMode = !bTreeMode;
    if (bTreeMode)
    {
        BreadcrumbContainer->SetVisibility(ESlateVisibility::Collapsed);
        AreaTreeWidget->SetVisibility(ESlateVisibility::Visible);
        // 按钮图标切换为"收起"
    }
    else
    {
        BreadcrumbContainer->SetVisibility(ESlateVisibility::Visible);
        AreaTreeWidget->SetVisibility(ESlateVisibility::Collapsed);
        // 按钮图标切换为"展开"
    }
    // 切换后立即刷新
    if (CachedStateComponent) Refresh(CachedStateComponent);
}
```

`UpdateBreadcrumbs` 逻辑：从 `BuildPanelWidget::UpdateBreadcrumbs`（cpp L159-195）原样迁移。

`UpdateTree` 逻辑：
```cpp
void UpdateTree(UVoxelControllerStateComponent* SC)
{
    int32 CharId = -1;
    if (auto* GI = GetWorld()->GetGameInstance<UVoxelGameInstance>())
        CharId = GI->CurPlayerId;
    // 全局树：从世界根开始
    AreaTreeWidget->InitializeTree(nullptr, CharId);
    AreaTreeWidget->SetSelectedArea(SC->GetCurrentArea());
}
```

## 5. 交互流程

### 5.1 面包屑 ↔ 树视图切换

```
默认状态：面包屑模式（bTreeMode = false）
  └── 显示 BreadcrumbContainer，隐藏 AreaTreeWidget
  └── ExpandToggleButton 显示"展开"图标

点击 ExpandToggleButton：
  → bTreeMode = !bTreeMode
  → true：隐藏面包屑，显示树，InitializeTree(全局根)，展开当前层第一级
  → false：隐藏树，显示面包屑
  → 切换后立即 Refresh
```

### 5.2 树节点交互

```
树节点（UVoxelAreaTreeEntryWidget）：
  ├── 点击展开箭头 → UTreeView 原生展开/折叠子节点
  └── 点击区域名 → SelectArea(Area)
      ├── 选中成功 → 变红 + Gizmo 出现（有权限时）
      └── 只读区域 → 选中但灰色不变，不显示 Gizmo
```

树视图中点击的区域**不限于当前父区域的直接子区域**（与 3D 点击不同），因为树视图的价值就是能看到多层级。点击任意层级的区域都会调用 `SelectArea`，`InternalSetCurrentArea` 内部会自动更新 `CurParentArea`。

### 5.3 初始展开策略

`InitializeTree` 调用时：
1. 构建完整树数据
2. 填充到 UTreeView
3. **只展开根节点的直接子节点**（第一级）
4. 其他层级默认折叠
5. 高亮当前选中区域

### 5.4 刷新时机

`UVoxelAreaNavigatorWidget::Refresh(SC)` 在以下时机调用：
- `OnCurrentAreaChanged` 广播时（选中/取消/切换区域）
- `OnBuildModeParamsUpdated` 广播时（进入/退出区域编辑模式）

### 5.5 与 3D 选中的联动

树视图点击和 3D 点击都调用同一个 `SelectArea`，`OnCurrentAreaChanged` 广播后：
- 面包屑自动刷新
- 树视图高亮自动更新
- 3D 场景中子区域显隐自动更新

三种入口（树视图、3D 点击、面包屑）完全联动，统一通过 `SelectArea` + `OnCurrentAreaChanged` 广播。

## 8. 边界情况

| 场景 | 处理 |
|------|------|
| 区域层级极深 | UTreeView 虚拟化，只渲染可见节点，性能无忧 |
| 无子区域的叶节点 | 展开箭头隐藏（`SetVisibility(Hidden)`） |
| 无权限区域 | 灰色显示，点击选中但只读（不显示 Gizmo） |
| 树模式切换回面包屑 | 每次切换到树模式都重新 InitializeTree，展开状态重置为默认（第一级展开） |
| 区域在树展示期间被删除 | 下次 Refresh 时重建树数据，已删除节点自然消失 |
| World Root 节点 | Area=nullptr，名称显示 "World Root"，点击调用 SelectArea(nullptr) 触发级联回退 |
