# 通用物品库组件使用指南

## 📋 概述

`UItemLibraryWidgetBase` 是一个**自给自足**的通用物品浏览组件，支持动态分类TAB、搜索、分页等功能。

**设计目标：**
- ✅ 一键初始化 - 外部只需调用 `Initialize()` 即可完成所有初始化
- ✅ DEFAULT 配置 - 通过蓝图默认值配置大类 TAG
- ✅ 可复用于背包、材料、菜品、建造库等多个场景
- ✅ 配置驱动，支持任意分类维度（类型、DLC、稀有度等）
- ✅ 扩展性强，新增分类不需要修改代码

---

## 🏗️ 架构设计

### 核心组件

```
UItemLibraryWidgetBase (通用基类，自给自足)
├─ M1_BuildLibraryModule (方块库) → 组合模式
├─ M1b_TemplateLibraryModule (模板库) → 组合模式
├─ BackpackWidget (背包) → 组合模式 (TODO)
├─ MaterialLibraryWidget (材料库) → 组合模式 (TODO)
└─ RecipeLibraryWidget (食谱库) → 组合模式 (TODO)
```

### 数据流（简化版）

```
1. 父组件调用 Initialize()
    ↓
2. ItemLibrary 自动生成分类 TAB
    ↓
3. 从 ConfigDataSubsystem 加载物品
    ↓
4. 显示"全部"分类的物品列表
    ↓
5. 用户点击物品 → 触发 OnItemClicked 代理
```

## 🎯 使用方式（推荐）

### 方案 A：组合方式（推荐）

适用于需要保留原有继承关系的场景（如 M1、M1b 继承 `UToolDetailModuleBase`）。

#### 1. 在父组件中组合 ItemLibrary

```cpp
// M1_BuildLibraryModule.h
class VOXEL_API UM1_BuildLibraryModule : public UToolDetailModuleBase
{
    GENERATED_BODY()

protected:
    /** 通用物品库组件（组合） */
    UPROPERTY(meta = (BindWidget))
    UItemLibraryWidgetBase* ItemLibraryComponent;

    /** 最大查询类型TAG（在蓝图 DEFAULT 中配置） */
   	UPROPERTY(EditDefaultsOnly, Category = "M1|Config")
    FGameplayTag MaxQueryTypeTag;
};
```

#### 2. 在 UMG 中绑定 UI 控件

```cpp
// 在 UMG 蓝图中：
// 1. 将 ItemLibraryWidgetBase 的子控件绑定到 M1 的对应控件
// 2. SearchTextBox → ItemLibraryComponent.SearchTextBox
// 3. CategoryTabContainer → ItemLibraryComponent.CategoryTabContainer
// 4. ItemListContainer → ItemLibraryComponent.ItemListContainer
// 5. PrevPageButton / NextPageButton → ItemLibraryComponent.*
// 6. PageNumberText → ItemLibraryComponent.*
```

#### 3. 配置 MaxQueryTypeTag

```cpp
// 在蓝图 DEFAULT 中配置：
// M1_BuildLibraryModule
// └── MaxQueryTypeTag = "Voxel.Block"
```

或在 C++ 构造函数中设置：

```cpp
UM1_BuildLibraryModule::UM1_BuildLibraryModule()
{
    // 配置大类 TAG
    MaxQueryTypeTag = FCoreTags::Item_Type_Block;
}
```

#### 4. 调用 Initialize()

```cpp
// M1_BuildLibraryModule.cpp
void UM1_BuildLibraryModule::NativeConstruct()
{
    Super::NativeConstruct();

    // 只需一行代码，完成所有初始化！
    if (ItemLibraryComponent)
    {
        ItemLibraryComponent->Initialize();
    }
}
```

#### 5. 绑定事件处理（可选）

```cpp
void UM1_BuildLibraryModule::BindItemLibraryDelegates()
{
    if (!ItemLibraryComponent)
    {
        return;
    }

    // 绑定物品点击事件
    ItemLibraryComponent->OnItemClicked.AddDynamic(
        this,
        &UM1_BuildLibraryModule::HandleItemClicked
    );

    // 绑定创建物品槽位事件
    ItemLibraryComponent->OnCreateItemSlot.AddDynamic(
        this,
        &UM1_BuildLibraryModule::HandleCreateItemSlot
    );
}

// 处理物品点击
void UM1_BuildLibraryModule::HandleItemClicked(FGameplayTag ItemTag)
{
    // 更新手持物品
    if (StateComponent)
    {
        StateComponent->SetItemInHand(ItemTag);
    }
}

// 创建物品槽位
void UM1_BuildLibraryModule::HandleCreateItemSlot(FGameplayTag ItemTag)
{
    if (!BuildSlotWidgetClass)
    {
        return;
    }

    UBuildSlotWidget* SlotWidget = CreateWidget<UBuildSlotWidget>(this, BuildSlotWidgetClass);
    if (SlotWidget)
    {
        UConfigDataSubsystem* CDS = GetWorld()->GetGameInstance()->GetSubsystem<UConfigDataSubsystem>();
        // 物品查询按句柄；只有 Tag 时走品类查询（O(n)，适合低频 UI）
        const TArray<FVoxelItemBase*> Matches = CDS->GetItemTypeArrayByCategory<FVoxelItemBase>(ItemTag);
        if (Matches.Num() > 0)
        {
            SlotWidget->InitSlotData(ItemTag, Matches[0]->AssetFragment.Icon);
        }

        // 添加到列表容器
        ItemLibraryComponent->ItemListContainer->AddChild(SlotWidget);
    }
}
```

## 🔧 配置详解

### 1. MaxQueryTypeTag 配置

**作用：** 限制物品查询范围，只显示指定类型及其子类型的物品

**配置位置：** 蓝图 DEFAULT 面板或 C++ 构造函数

**示例：**

| 模块 | MaxQueryTypeTag | 说明 |
|------|-----------------|------|
| M1 建造库 | `Voxel.Block` | 只显示方块类物品 |
| M1b 模板库 | `Voxel.Template` | 只显示模板类物品 |
| 背包 | `Voxel.Item` | 显示所有物品 |
| 材料库 | `Voxel.Item.Material` | 只显示材料类物品 |

**TAG 层级示例：**

```
Voxel.Item (所有物品)
├── Voxel.Item.Block (方块)
│   ├── Voxel.Block.Stone (石材)
│   ├── Voxel.Block.Wood (木材)
│   └── Voxel.Block.Metal (金属)
├── Voxel.Item.Tool (工具)
│   ├── Voxel.Tool.Pickaxe (镐)
│   └── Voxel.Tool.Axe (斧)
└── Voxel.Item.Material (材料)
    ├── Voxel.Material.Wood (木料)
    └── Voxel.Material.Stone (石料)
```

### 2. bAutoGenerateAllCategory 配置

**作用：** 是否自动生成"全部"分类

**默认值：** `true`

**建议：** 保持默认值，除非有特殊需求

### 2. 分类筛选

**当前实现：** 只显示全部物品

**未来扩展：** 根据 FilterTags 筛选物品

```cpp
void UItemLibraryWidgetBase::SwitchToCategory(FString CategoryId)
{
    SelectedCategoryId = CategoryId;
    CurrentPage = 0;
    UpdateCategoryTabStates();

    // 根据分类筛选物品
    if (CategoryId == TEXT("All"))
    {
        FilteredItems = AllItems;
    }
    else
    {
        // 使用 FilterTags 筛选
        FItemCategoryConfig* Category = CachedCategories.FindByPredicate(
            [&](const FItemCategoryConfig& Cat) { return Cat.CategoryId == CategoryId; }
        );

        if (Category)
        {
            FilteredItems = FilterItemsByTags(AllItems, Category->FilterTags);
        }
    }

    RenderCurrentPageItems();
}
```

## 📝 总结

**使用通用物品库组件的优势（v2.0）：**

1. ✅ **极简使用** - 只需调用 `Initialize()` 一行代码
2. ✅ **配置驱动** - 通过 DEFAULT 配置大类 TAG
3. ✅ **自给自足** - 组件自己管理初始化，无需外部干预
4. ✅ **统一体验** - 所有物品库界面一致
5. ✅ **开发效率** - 新建物品库只需 3 步
6. ✅ **易于维护** - 核心逻辑集中在一处
7. ✅ **灵活扩展** - 支持任意分类维度和组合条件
