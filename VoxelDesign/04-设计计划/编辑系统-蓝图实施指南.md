## 1. 蓝图需要实现的方法清单

### 1.1 输入处理方法

#### 1.1.1 鼠标/触摸输入

**IA_Click**
- **功能**：处理鼠标点击事件
- **调用时机**：用户点击鼠标左键
- **实现逻辑**：
  1. 获取鼠标射线检测结果
  2. 提取世界位置
  3. 根据当前状态调用不同的 C++ 接口
- **调用 C++ 接口**：
  - Hidden 状态：调用 `SetFirstPoint(VoxelIndex)`
  - Base 状态：调用 `SetSecondPoint(VoxelIndex)`
  - Edit 状态：检测 Gizmo，调用 `StartGizmoInteraction()`

**IA_Hold**
- **功能**：处理鼠标持续按住
- **调用时机**：用户按住鼠标左键
- **实现逻辑**：
  1. 获取当前鼠标位置
  2. 转换为体素索引
  3. 调用 C++ 接口更新
- **调用 C++ 接口**：
  - Base 状态：调用 `UpdateSecondPoint(VoxelIndex)`
  - Edit 状态：调用 `UpdateGizmoInteraction(WorldPosition)`

**IA_Release**
- **功能**：处理鼠标释放
- **调用时机**：用户释放鼠标左键
- **实现逻辑**：
  1. 根据当前状态处理
  2. Base 状态：切换到 Edit 状态
  3. Edit 状态：结束 Gizmo 交互
- **调用 C++ 接口**：
  - Edit 状态：调用 `ReleaseGizmoInteraction()`

#### 1.1.2 键盘快捷键

**IA_Confirm**
- **功能**：确认当前编辑
- **调用时机**：用户按 Enter 或 Space
- **实现逻辑**：
  1. 检查是否在可确认状态
  2. 调用 C++ 提交编辑
  3. 显示成功/失败提示
- **调用 C++ 接口**：
  - `CommitBatchEditPreview()`

**IA_Cancel**
- **功能**：取消当前编辑
- **调用时机**：用户按 Esc
- **实现逻辑**：
  1. 检查是否有进行中的编辑
  2. 调用 C++ 取消编辑
  3. 显示取消提示
- **调用 C++ 接口**：
  - `CancelCurrentEdit()`

**IA_Undo**
- **功能**：撤销上次操作
- **调用时机**：用户按 Ctrl+Z
- **实现逻辑**：
  1. 检查是否可以撤销
  2. 调用 C++ 撤销
  3. 播放撤销音效
- **调用 C++ 接口**：
  - `HistoryComponent->CanUndo()` 先检查
  - `HistoryComponent->Undo()` 执行撤销

**IA_Redo**
- **功能**：重做已撤销操作
- **调用时机**：用户按 Ctrl+Y
- **实现逻辑**：
  1. 检查是否可以重做
  2. 调用 C++ 重做
  3. 播放重做音效
- **调用 C++ 接口**：
  - `HistoryComponent->CanRedo()` 先检查
  - `HistoryComponent->Redo()` 执行重做

#### 1.1.3 工具快捷键

**IA_Rotate**
- **功能**：旋转预览
- **调用时机**：用户按 R
- **实现逻辑**：
  1. 获取当前几何数据
  2. 计算新旋转角度
  3. 更新几何数据
- **调用 C++ 接口**：
  - `GetTmpGeometry()` 获取当前几何
  - `SetTmpGeometry(NewGeometry)` 更新几何

**IA_NextShape**
- **功能**：切换形状类型
- **调用时机**：用户按 Tab 或数字键
- **实现逻辑**：
  1. 获取当前形状类型
  2. 切换到下一个形状
  3. 更新几何数据
- **调用 C++ 接口**：
  - `GetTmpGeometry()` 获取当前几何
  - `SetTmpGeometry(NewGeometry)` 更新几何

**IA_ToggleThickness**
- **功能**：切换厚度模式
- **调用时机**：用户按 T
- **实现逻辑**：
  1. 获取当前厚度设置
  2. 切换厚度模式
  3. 更新几何数据
- **调用 C++ 接口**：
  - `GetTmpGeometry()` 获取当前几何
  - `SetTmpGeometry(NewGeometry)` 更新几何

**IA_Delete**
- **功能**：切换到删除模式
- **调用时机**：用户按 Delete
- **实现逻辑**：
  1. 切换编辑模式为删除
  2. 更新 UI 显示
- **调用 C++ 接口**：
  - `SetEditMode(Delete)`

### 1.2 射线检测和数据获取方法

#### 1.2.1 基础射线检测

**GetMouseWorldPosition**
- **功能**：获取鼠标指向的世界位置
- **实现步骤**：
  1. 调用 `GetHitResultUnderCursor()` 获取命中结果
  2. 检查命中是否有效
  3. 返回 `ImpactPoint`
- **UE 方法**：
  - `GetHitResultUnderCursor(ECollisionChannel, bool, FHitResult&)`

**GetMouseVoxelIndex**
- **功能**：获取鼠标指向的体素索引
- **实现步骤**：
  1. 调用 `GetMouseWorldPosition()` 获取世界位置
  2. 调用 C++ 工具方法转换坐标
- **调用 C++ 接口**：
  - `WorldToVoxelIndex(WorldPosition)`

**GetClickedActor**
- **功能**：获取点击的 Actor
- **实现步骤**：
  1. 调用 `GetHitResultUnderCursor()` 获取命中结果
  2. 检查 `HitActor` 是否有效
  3. 返回 Actor 引用
- **用途**：检测 Gizmo 点击

#### 1.2.2 Gizmo 交互检测

**IsClickedGizmo**
- **功能**：检测是否点击了 Gizmo
- **实现步骤**：
  1. 获取点击的 Actor
  2. 类型转换为 `AVoxel3DUIActor`
  3. 返回检测结果
- **用途**：判断是否进入 Gizmo 交互模式

**IsClickedArea**
- **功能**：检测是否点击了区域
- **实现步骤**：
  1. 获取点击的 Actor
  2. 类型转换为 `AVoxelAreaBaseInstance`
  3. 返回区域引用
- **用途**：区域编辑模式

### 1.3 编辑操作协调方法

#### 1.3.1 底面定义阶段（Base 状态）

**OnBasePhaseClick**
- **功能**：处理底面定义阶段的点击
- **输入**：WorldPosition
- **实现步骤**：
  1. 调用 `GetMouseVoxelIndex()` 获取索引
  2. 调用 `InteractComponent->SetFirstPoint(VoxelIndex)`
  3. 触发预览更新（通过 C++ 事件自动处理）
- **调用 C++ 接口**：
  - `SetFirstPoint(VoxelIndex)`

**OnBasePhaseHold**
- **功能**：处理底面定义阶段的拖动
- **输入**：WorldPosition
- **实现步骤**：
  1. 调用 `GetMouseVoxelIndex()` 获取当前索引
  2. 调用 `InteractComponent->UpdateSecondPoint(VoxelIndex)`
- **调用 C++ 接口**：
  - `UpdateSecondPoint(VoxelIndex)`

**OnBasePhaseRelease**
- **功能**：处理底面定义阶段的释放
- **输入**：WorldPosition
- **实现步骤**：
  1. 调用 `GetMouseVoxelIndex()` 确定最终点
  2. 调用 `InteractComponent->SetSecondPoint(VoxelIndex)`
  3. C++ 自动切换状态到 Edit
- **调用 C++ 接口**：
  - `SetSecondPoint(VoxelIndex)`

#### 1.3.2 编辑阶段（Edit 状态）

**OnEditPhaseGizmoClick**
- **功能**：处理 Gizmo 点击
- **输入**：GizmoActor, WorldPosition
- **实现步骤**：
  1. 检测 Gizmo 类型
  2. 调用 C++ 开始交互
- **调用 C++ 接口**：
  - `StartGizmoInteraction(GizmoActor, WorldPosition)`

**OnEditPhaseGizmoDrag**
- **功能**：处理 Gizmo 拖动
- **输入**：WorldPosition
- **实现步骤**：
  1. 调用 C++ 更新交互
- **调用 C++ 接口**：
  - `UpdateGizmoInteraction(WorldPosition)`

**OnEditPhaseGizmoRelease**
- **功能**：处理 Gizmo 释放
- **实现步骤**：
  1. 调用 C++ 结束交互
- **调用 C++ 接口**：
  - `ReleaseGizmoInteraction()`

#### 1.3.3 确认/取消操作

**OnConfirmEdit**
- **功能**：确认编辑
- **实现步骤**：
  1. 调用 C++ 提交编辑
  2. 等待编辑完成
  3. 显示成功提示
  4. 播放确认音效
- **调用 C++ 接口**：
  - `CommitBatchEditPreview()`

**OnCancelEdit**
- **功能**：取消编辑
- **实现步骤**：
  1. 调用 C++ 取消编辑
  2. 显示取消提示
  3. 播放取消音效
- **调用 C++ 接口**：
  - `CancelCurrentEdit()`

### 1.4 撤销/重做协调方法

#### 1.4.1 撤销操作

**OnUndo**
- **功能**：执行撤销
- **实现步骤**：
  1. 调用 `CanUndo()` 检查是否可撤销
  2. 如果可撤销，调用 `Undo()`
  3. 播放撤销音效
  4. 显示撤销提示
- **调用 C++ 接口**：
  - `HistoryComponent->CanUndo()`
  - `HistoryComponent->Undo()`

#### 1.4.2 重做操作

**OnRedo**
- **功能**：执行重做
- **实现步骤**：
  1. 调用 `CanRedo()` 检查是否可重做
  2. 如果可重做，调用 `Redo()`
  3. 播放重做音效
  4. 显示重做提示
- **调用 C++ 接口**：
  - `HistoryComponent->CanRedo()`
  - `HistoryComponent->Redo()`

### 1.5 UI 更新协调方法

#### 1.5.1 状态变更监听

**OnBuildStateChanged**
- **功能**：响应建造状态变更
- **输入**：EVoxelControllerBuildState
- **实现步骤**：
  1. 根据新状态切换 UI 显示
  2. 显示/隐藏相关 UI 元素
  3. 更新提示文本
- **状态对应 UI**：
  - Hidden：隐藏所有编辑 UI
  - Base：显示底面定义提示
  - Edit：显示编辑提示和 Gizmo
  - Confirm：显示确认动画

#### 1.5.2 预览信息监听

**OnPreviewInfoChanged**
- **功能**：响应预览信息变更
- **输入**：FEditPreviewInfo
- **实现步骤**：
  1. 更新体素数量显示
  2. 更新编辑模式显示
  3. 更新方块类型显示
- **UI 元素**：
  - TextBlock_VoxelCount
  - TextBlock_EditMode
  - TextBlock_BlockType

#### 1.5.3 历史变更监听

**OnHistoryChanged**
- **功能**：响应历史记录变更
- **实现步骤**：
  1. 更新撤销按钮状态
  2. 更新重做按钮状态
  3. 更新历史统计显示
- **调用 C++ 接口**：
  - `CanUndo()` 更新撤销按钮
  - `CanRedo()` 更新重做按钮
  - `GetEditCount()` 更新统计

## 4. 常见问题

### 4.1 射线检测不准确

**可能原因**：
- 碰撞通道设置错误
- 摄像机位置不正确
- 没有考虑方块尺寸

**解决方案**：
- 检查 Trace Channel 配置
- 确保摄像机在正确位置
- 使用正确的坐标转换方法

### 4.2 状态不更新

**可能原因**：
- C++ 接口调用失败
- 事件绑定不正确
- 状态验证失败

**解决方案**：
- 检查接口返回值
- 验证事件绑定
- 查看调试输出

### 4.3 UI 不刷新

**可能原因**：
- 事件未触发
- UI 更新逻辑错误
- Widget 未正确初始化

**解决方案**：
- 确认事件绑定
- 检查更新逻辑
- 验证 Widget 创建
