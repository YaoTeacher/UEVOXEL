### 🔴 HIGH 风险缓解措施

#### T1: Center 字段未初始化风险

**风险描述**: 新增 `Center` 字段后未初始化，所有使用 Geometry 的地方会获得未初始化的值 (0,0,0)

**缓解措施**:
1. **惰性初始化** (Phase 1, Task 1.1)
   ```cpp
   // 在 FVoxelGeometryDesc 中
   private:
       FVector Center = FVector::ZeroVector;
       bool bCenterInitialized = false;

   public:
       // 获取 Center，如果未初始化则自动计算
       FVector GetCenter() const
       {
           if (!bCenterInitialized)
           {
               // 惰性初始化：计算几何中心
               const_cast<FVoxelGeometryDesc*>(this)->Recenter(100.0f);
           }
           return Center;
       }
   ```

2. **添加 IsValid() 检查**
   ```cpp
   bool IsValid() const
   {
       return Box.isValid() && bCenterInitialized;
   }
   ```

3. **单元测试覆盖**
   ```cpp
   TEST(FVoxelGeometryDesc, UninitializedCenter_AutoInitializes)
   {
       FVoxelGeometryDesc Geo;
       Geo.Box = FAreaCoverageFragment(FIntVector(0, 0, 0), FIntVector(10, 10, 10));

       EXPECT_FALSE(Geo.bCenterInitialized);
       FVector Center = Geo.GetCenter();
       EXPECT_TRUE(Geo.bCenterInitialized);
       EXPECT_EQ(Center, FVector(500, 500, 500));
   }
   ```

**验证方式**: 单元测试 + 运行时断言

#### T2: BlockLength 参数传递链断裂风险

**风险描述**: 所有操作方法接受 BlockLength 参数，调用者可能忘记传递或传递错误值

**缓解措施** (Phase 1, Task 1.3, 1.4, 1.5, 1.6):
1. **明确方法签名，所有需要 BlockLength 的方法都显式传入参数**
   ```cpp
   // FVoxelGeometryDesc 方法签名（明确需要 BlockLength）
   void MoveGEO(FIntVector Delta, float BlockLength);
   void Recenter(float BlockLength);

   // 不需要 BlockLength 的方法
   void RotateGEO(FRotator DeltaRotation);
   void ModifyCoverage(EAxis::Type Axis, bool bMaxSide, int32 Delta);

   // 访问器方法
   FVector GetCenter() const;  // 返回存储的 Center，不需要参数
   FVector GetGeometricCenter(float BlockLength) const;  // 计算几何中心
   FBox GetBound(float BlockLength) const;
   FVector GetSize(float BlockLength) const;
   FVector GetExtents(float BlockLength) const;
   ```

2. **StateComponent 提供统一的 BlockLength 访问接口（从 GameInstance 实时获取）**
   ```cpp
   // VoxelControllerStateComponent.h
   public:
       /** 获取当前 BlockLength（从 GameInstance 的 ConfigDataSubsystem 实时读取） */
       float GetBlockLength() const
       {
           if (UWorld* World = GetWorld())
           {
               if (UGameInstance* GameInstance = World->GetGameInstance())
               {
                   if (UConfigDataSubsystem* ConfigData = GameInstance->GetSubsystem<UConfigDataSubsystem>())
                   {
                       return ConfigData->GetWorldConfig().BlockLength;
                   }
               }
           }
           return 100.0f;  // 默认值
       }

       /** Geometry 操作便捷方法（显式传递 BlockLength） */
       void MoveGEO(FIntVector Delta)
       {
           const float BlockLength = GetBlockLength();
           TmpGeometry.MoveGEO(Delta, BlockLength);
           OnTmpGeometryChanged.Broadcast(TmpGeometry);
       }

       void Recenter()
       {
           const float BlockLength = GetBlockLength();
           TmpGeometry.Recenter(BlockLength);
           OnTmpGeometryChanged.Broadcast(TmpGeometry);
       }
   ```

3. **VisualUIComponent 调用时从 StateComponent 获取**
   ```cpp
   // VoxelControllerVisualUIComponent.cpp
   void UVoxelControllerVisualUIComponent::HandleMoveGEO(FIntVector MoveDelta)
   {
       if (UVoxelControllerStateComponent* StateComp = GetStateComponent())
       {
           const float BlockLength = StateComp->GetBlockLength();
           FVoxelGeometryDesc Geometry = StateComp->GetTmpGeometry();
           Geometry.MoveGEO(MoveDelta, BlockLength);
           StateComp->SetTmpGeometry(Geometry);
           UpdatePreviewGeometry(Geometry);
       }
   }
   ```

4. **单元测试使用固定 BlockLength**
   ```cpp

   {
       constexpr float TestBlockLength = 100.0f;
   ```

#### T5: 约束检查实现不完整

**风险描述**: ModifyCoverage 可能创建无效的包围盒（MinIndex > MaxIndex）

**缓解措施** (Phase 1, Task 1.4):
1. **明确边界条件**
   ```cpp
   void FVoxelGeometryDesc::ModifyCoverage(EAxis::Type Axis, bool bMaxSide, int32 Delta)
   {
       int32 NewValue;
       int32 MinValue, MaxValue;

       switch (Axis)
       {
       case EAxis::X:
           MinValue = Box.MinIndex.X;
           MaxValue = Box.MaxIndex.X;
           NewValue = (bMaxSide ? MaxValue : MinValue) + Delta;

           // 约束检查：拒绝无效操作
           if (bMaxSide && NewValue < MinValue)
           {
               UE_LOG(LogTemp, Warning, TEXT("ModifyCoverage rejected: New Max.X < Min.X"));
               return;
           }
           if (!bMaxSide && NewValue > MaxValue)
           {
               UE_LOG(LogTemp, Warning, TEXT("ModifyCoverage rejected: New Min.X > Max.X"));
               return;
           }

           // 应用修改
           if (bMaxSide)
               Box.MaxIndex.X = NewValue;
           else
               Box.MinIndex.X = NewValue;
           break;
       // ... Y, Z 同理
       }
   }
   ```

2. **返回 bool 表示成功/失败**
   ```cpp
   UFUNCTION(BlueprintCallable, Category = "Voxel|Geometry")
   bool ModifyCoverage(EAxis::Type Axis, bool bMaxSide, int32 Delta);
   ```

3. **单元测试覆盖边界情况**

```cpp
void FVoxelGeometryDesc::Recenter(float BlockLength)
{
    // 步骤1：计算未旋转的几何中心 C
    const FVector C = FVector(
        (Box.MinIndex.X + Box.MaxIndex.X + 1) * 0.5f,
        (Box.MinIndex.Y + Box.MaxIndex.Y + 1) * 0.5f,
        (Box.MinIndex.Z + Box.MaxIndex.Z + 1) * 0.5f
    ) * BlockLength;

    // 步骤2：获取当前旋转中心 A
    const FVector A = Center;

    // 步骤3：计算旋转后的位置 B
    const FVector AC = C - A;
    const FVector RotatedAC = Rotation.RotateVector(AC);
    const FVector B = A + RotatedAC;

    // 步骤4：体素对齐
    Center = FMath::RoundToInt(B / BlockLength) * BlockLength;
}
```

```cpp
FInputAction UVoxelControllerInputHandlerComponent::DetectInput(const FInputDeviceState& InputState)
{
    FInputAction Action;
    Action.Target = EInputTarget::None;

    // 获取玩家控制器
    APlayerController* PC = Cast<APlayerController>(GetOwner());
    if (!PC)
    {
        return Action;
    }

    // 射线检测
    FVector WorldLocation, WorldDirection;
    PC->DeprojectScreenPositionToWorld(InputState.MousePosition.X, InputState.MousePosition.Y, WorldLocation, WorldDirection);

    FVector TraceEnd = WorldLocation + WorldDirection * 10000.0f;
    FHitResult HitResult;

    if (GetWorld()->LineTraceSingleByChannel(HitResult, WorldLocation, TraceEnd, ECC_Visibility))
    {
        Action.Target = GetInputPriority(HitResult);
        Action.WorldPosition = HitResult.Location;

        // 转换为体素索引
        Action.BlockPosition = FIntVector(
            FMath::FloorToInt(HitResult.Location.X / 100.0f),
            FMath::FloorToInt(HitResult.Location.Y / 100.0f),
            FMath::FloorToInt(HitResult.Location.Z / 100.0f)
        );
    }

    Action.bPressed = InputState.bLeftMouseButton && !bWasPressedLastFrame;
    Action.bReleased = !InputState.bLeftMouseButton && bWasPressedLastFrame;
    bWasPressedLastFrame = InputState.bLeftMouseButton;

    return Action;
}
```

```cpp
EInputTarget UVoxelControllerInputHandlerComponent::GetInputPriority(const FHitResult& HitResult)
{
    if (!HitResult.IsValidBlockingHit())
    {
        return EInputTarget::None;
    }

    // 优先级 1: Gizmo 控件
    if (HitResult.GetActor()->ActorHasTag(TEXT("Gizmo")))
    {
        return EInputTarget::Gizmo;
    }

    // 优先级 2: UI 元素
    if (HitResult.GetActor()->ActorHasTag(TEXT("UIElement")))
    {
        return EInputTarget::UI;
    }

    // 优先级 3: 世界对象
    return EInputTarget::World;
}
```

```cpp
{
    if (!InteractComponent)

    }

    if (InteractComponent)

            {
```

```cpp
void AVoxelPreviewActor::UpdateFaceGizmosPosition(const FVoxelGeometryDesc& Geometry, float BlockLength)
{
    const FBox Bounds = Geometry.GetBound(BlockLength);
    const FVector Min = Bounds.Min;
    const FVector Max = Bounds.Max;

    // 6 个面的中心位置
    const FVector FaceCenters[6] = {
        FVector(Min.X, (Min.Y + Max.Y) * 0.5f, (Min.Z + Max.Z) * 0.5f),  // -X
        FVector(Max.X, (Min.Y + Max.Y) * 0.5f, (Min.Z + Max.Z) * 0.5f),  // +X
        FVector((Min.X + Max.X) * 0.5f, Min.Y, (Min.Z + Max.Z) * 0.5f),  // -Y
        FVector((Min.X + Max.X) * 0.5f, Max.Y, (Min.Z + Max.Z) * 0.5f),  // +Y
        FVector((Min.X + Max.X) * 0.5f, (Min.Y + Max.Y) * 0.5f, Min.Z),  // -Z
        FVector((Min.X + Max.X) * 0.5f, (Min.Y + Max.Y) * 0.5f, Max.Z),  // +Z
    };

    for (int32 i = 0; i < 6 && i < FaceGizmos.Num(); ++i)

        if (FaceGizmos[i])
        {
            FaceGizmos[i]->SetActorLocation(FaceCenters[i]);
```

## 关键设计决策

### 决策 1: Center 字段的 BlockLength 参数问题

**问题**: FVoxelGeometryDesc 是一个 struct，无法访问 BlockLength 配置

**方案 A**: Center 存储为世界坐标，所有操作方法接受 BlockLength 参数
```cpp
void MoveGEO(FIntVector Delta, float BlockLength);
void ModifyCoverage(...);  // 不需要 BlockLength
void Recenter(float BlockLength);
```

**方案 B**: Center 存储为索引坐标，使用时转换
```cpp
FIntVector CenterIndex;
FVector GetCenter(float BlockLength) const { return FVector(CenterIndex) * BlockLength; }
```

**✅ 用户决策**: 采用方案 A（显式参数传递）

**理由**:
1. 符合架构设计文档
2. Center 世界坐标更直观
3. 避免 INDEX vs POSITION 混淆
4. 调用者明确知道需要传递 BlockLength，避免隐式依赖
5. **不在任何地方缓存 BlockLength，每次都从 GameInstance 获取**

**实施**:
- 所有需要 BlockLength 的方法都显式传入参数
- StateComponent.GetBlockLength() 从 GameInstance 的 ConfigDataSubsystem 实时读取（不缓存）
- StateComponent 提供便捷方法（内部实时获取 BlockLength 后调用底层方法）
- VisualUIComponent 调用时从 StateComponent 获取 BlockLength
- 单元测试使用固定的测试 BlockLength 值

### 决策 2: InputHandlerComponent 组件引用方式

**问题**: InputHandlerComponent 需要引用 InteractComponent 和 VisualUIComponent

**方案 A**: 成员变量引用
```cpp
UPROPERTY()
TObjectPtr<UVoxelControllerInteractComponent> InteractComponent;
```

**方案 B**: 动态查找
```cpp
UVoxelControllerInteractComponent* GetInteractComponent() const
{
    return GetOwner()->FindComponentByClass<UVoxelControllerInteractComponent>();
}
```

**推荐方案**: 方案 B（延迟初始化）

**理由**:
1. 避免组件初始化时序问题
2. 减少依赖
3. 更灵活

### 决策 3: 回调数据流的设计方式

**问题**: 如何设计 Geometry 操作的回调机制

**方案 A**: 使用统一回调 + 枚举
```cpp
DECLARE_DYNAMIC_MULTICAST_DELEGATE_TwoParams(FGeometryOperationCallback,
    EGeometryOperationType, OperationType,
    const FGeometryOperationParams&, Parameters);
```

**方案 B**: 使用独立的回调委托
```cpp
DECLARE_DYNAMIC_MULTICAST_DELEGATE_OneParam(FOnMoveGizmoDraged, FIntVector, MoveDelta);
DECLARE_DYNAMIC_MULTICAST_DELEGATE_OneParam(FOnRotateGizmoDragged, FRotator, RotateDelta);
DECLARE_DYNAMIC_MULTICAST_DELEGATE_FourParams(FOnModifyCoverage,
    EAxis::Type, Axis, bool, bMaxSide, int32, Delta, float, BlockLength);
DECLARE_DYNAMIC_MULTICAST_DELEGATE_OneParam(FOnRecenter, float, BlockLength);
```

**推荐方案**: 方案 B（独立回调委托）

**理由**:
1. **类型安全**: 每个回调的参数明确，避免使用通用结构体
2. **代码清晰**: 调用方直接调用对应的委托，不需要枚举 switch
3. **易于维护**: 添加新操作只需添加新委托，不影响现有代码
4. **符合用户要求**: 用户明确表示不需要枚举类，只要有方法就行
3. 便于调试
