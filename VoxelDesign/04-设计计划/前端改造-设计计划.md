## 一、目标框架

```
UI 层：  UGameViewportClient → UVoxelPrimaryGameLayout（Layer.Game/GameMenu/Modal 栈 + Toast）
         Widget 只绑 ViewModel(FieldNotify)，跨系统事件走 GameplayMessage 频道
Controller：AVoxelPlayerController（薄：IA/IMC UPROPERTY + 组件持有 + 相机转发）
         ├─ UVoxelToolComponent        工具注册/输入分发/50ms统一鼠标射线
         ├─ UVoxelBuildStateComponent  建造域状态 + 细粒度事件
         ├─ UVoxelSelectionComponent   选区域状态 + 细粒度事件
         ├─ UVoxelPreviewComponent     预览/Gizmo（只订阅不写入）
         └─ UVoxelHistoryComponent     Undo/Redo（已归位，不动）
工具层： UVoxelToolBase × 10（8 现有 + Sample/Magic 占位）
         状态机收编基类模板方法；激活走 OnToolActivated/Deactivated
```

跨系统事件：GameplayMessageSubsystem 频道（UI.Toast.Show / UI.Mode.Changed / Build.Selection.Changed）
