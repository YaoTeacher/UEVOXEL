# Voxel 编辑系统实施路线图

> **基于正确架构理解的实施计划**
> **创建日期**: 2026-01-09
> **核心原则**: 状态在 StateComponent，操作在 InteractComponent，工具是无状态方法
> **关键洞察**: 统一的预览-确认模式，所有编辑操作共用同一流程

### 统一的预览-确认模式

**所有编辑操作共用同一个流程**：

```
编辑操作流程（统一）
│
├── 1. 开始预览
│   ├── 用户操作（框选、粘贴、加载蓝图等）
│   ├── StateComponent->TmpGeometry = 几何数据
│   ├── InteractComponent 调用预览方法
│   └── VisualComponent->ShowPreview(TmpGeometry)
│
├── 2. 更新预览（可选，重复）
│   ├── 用户调整（鼠标移动、旋转、Gizmo 拖拽等）
│   ├── StateComponent->TmpGeometry = 更新数据
│   ├── InteractComponent 调用更新方法
│   └── VisualComponent->UpdatePreview(TmpGeometry)
│
├── 3. 确认编辑
│   ├── 用户按 Enter/左键确认
│   ├── InteractComponent->RequestConfirmVoxelEdit()
│   ├── 捕获编辑前状态
│   ├── 调用工具方法计算受影响体素
│   ├── 执行编辑（调用 BlockWorld）
│   ├── 捕获编辑后状态
│   ├── 创建编辑命令
│   ├── HistoryComponent->SaveEditSnapshot(Command)
│   ├── HistoryComponent->LogOperation(Log)
│   ├── HistoryComponent->UpdateStatistics(Command)
│   └── VisualComponent->ClearPreview()
│
└── 4. 取消编辑
    ├── 用户按 Esc/右键取消
    ├── InteractComponent->RequestCancelVoxelEdit()
    └── VisualComponent->ClearPreview()
```

### 职责分工矩阵

| 组件 | 职责 | 存储的数据 | 提供的方法 |
|------|------|----------|----------|
| **StateComponent** | 当前状态存储 | 模式、选择、剪贴板、TmpGeometry、蓝图收藏 | Get/Set 状态访问接口 |
| **HistoryComponent** | 历史管理 | UndoStack、RedoStack、Logs、Stats | SaveSnapshot、Undo、Redo、Log、GetStats |
| **InteractComponent** | 操作控制 | 临时输入数据（FirstP、SecondP） | Request* 系列方法 |
| **VisualComponent** | 视觉渲染 | PreviewActor、Gizmo | Show/Update/Clear 预览、Gizmo 控制 |
| **工具类** | 无状态方法 | ❌ 不存储数据 | 静态方法（Calculate*、Execute*） |
| **EditorModeSubsystem** | 服务协调 | 工具类注册表（非玩家状态） | Get* 访问接口、RegisterTool |

## 🎯 Phase 1: 核心架构重构（Week 1-2）

### 目标
创建 HistoryComponent，将所有工具改为无状态方法类，删除不需要的 Manager

### 1.1 创建 HistoryComponent（2 天）✨

**设计思路**：

```
VoxelControllerHistoryComponent（UActorComponent）
│
├── 核心功能
│   ├── SaveEditSnapshot(Command)
│   │   ├── 将 Command 压入 UndoStack
│   │   ├── 清空 RedoStack
│   │   ├── 限制历史大小（MaxHistorySize）
│   │   └── 广播 OnHistoryChanged
│   ├── Undo()
│   │   ├── 从 UndoStack 弹出 Command
│   │   ├── 恢复 PreviousState（调用 BlockWorld）
│   │   ├── 压入 RedoStack
│   │   ├── 更新统计
│   │   └── 广播 OnUndoExecuted
│   ├── Redo()
│   │   ├── 从 RedoStack 弹出 Command
│   │   ├── 应用 NewState（调用 BlockWorld）
│   │   ├── 压入 UndoStack
│   │   ├── 更新统计
│   │   └── 广播 OnRedoExecuted
│   └── ClearHistory()
│       └── 清空 UndoStack 和 RedoStack
│
├── 操作日志
│   ├── LogOperation(Log)
│   │   ├── 添加到 OperationLogs
│   │   ├── 限制日志大小（MaxLogSize）
│   │   └── 广播 OnOperationLogged
│   └── GetOperationLogs(Count)
│       └── 返回最近的 N 条日志
│
└── 统计信息
    ├── UpdateStatistics(Command)
    │   └── 根据操作类型累加统计
    ├── GetStatistics()
    │   └── 返回统计信息
    └── ResetStatistics()
        └── 重置所有计数器

数据结构：
├── FVoxelEditCommand
│   ├── Timestamp（FDateTime）
│   ├── Description（FText）
│   ├── OperationType（enum：Single/Batch/Copy/Paste/Fill/Replace/Hollow/Delete/Blueprint）
│   ├── AffectedVoxels（TSet<FIntVector>）
│   ├── PreviousState（TMap<FIntVector, FGameplayTag>）
│   ├── NewState（TMap<FIntVector, FGameplayTag>）
│   └── AssociatedArea（AVoxelAreaBaseInstance*，可选）
│
├── FVoxelOperationLog
│   ├── Timestamp（FDateTime）
│   ├── OperationType（enum）
│   ├── Description（FText）
│   ├── AffectedVoxelCount（int32）
│   ├── ExecutionTimeMs（float）
│   ├── Success（bool）
│   ├── ErrorMessage（FString）
│   └── AssociatedArea（AVoxelAreaBaseInstance*，可选）
│
└── FVoxelEditStatistics
    ├── TotalEdits（int32）
    ├── TotalUndos（int32）
    ├── TotalRedos（int32）
    ├── TotalBlocksEdited（int32）
    ├── BlocksAdded/Deleted/Replaced（int32）
    ├── Copy/Paste/Blueprint 操作计数（int32）
    └── SessionStartTime（FDateTime）
```

**集成到编辑流程**：

```
InteractComponent->RequestConfirmVoxelEdit()
  ↓
1. 捕获编辑前状态
   BeforeState = BlockWorld->GetBlocksState(AffectedVoxels)
  ↓
2. 执行编辑
   BlockWorld->SetBlocks(AffectedVoxels, NewBlockType)
  ↓
3. 捕获编辑后状态
   AfterState = BlockWorld->GetBlocksState(AffectedVoxels)
  ↓
4. 创建编辑命令
   Command = {
       Timestamp: Now(),
       Description: GenerateDescription(),
       OperationType: BatchEdit,
       AffectedVoxels: AffectedVoxels,
       PreviousState: BeforeState,
       NewState: AfterState
   }
  ↓
5. 记录历史
   HistoryComponent->SaveEditSnapshot(Command)
  ↓
6. 记录日志
   Log = {
       Timestamp: Now(),
       OperationType: BatchEdit,
       ExecutionTimeMs: 15.5f,
       Success: true
   }
   HistoryComponent->LogOperation(Log)
  ↓
7. 更新统计
   HistoryComponent->UpdateStatistics(Command)
```

**验收标准**：
- ✅ HistoryComponent 正确创建并注册到玩家
- ✅ SaveEditSnapshot、Undo、Redo 功能正常
- ✅ 多玩家历史互不干扰
- ✅ 操作日志正确记录
- ✅ 统计信息准确更新
- ✅ 事件正确广播
- ✅ 支持配置历史大小和日志大小

### 1.2 将 BatchEditManager 改为工具类（2 天）

**当前问题**：
- BatchEditManager 作为 WorldSubsystem 存在
- 工具不应该作为 Subsystem

**重构目标**：
- 删除 VoxelBatchEditManager
- 创建 UVoxelBatchEditTool 无状态工具类
- 只保留编辑执行方法，参数通过 Request 传递

**设计思路**：

```
UVoxelBatchEditTool（无状态方法类）
├── CalculateAffectedVoxels(Request, BlockSize)
│   ├── 根据 Request.Geometry.ShapeType 调用不同方法
│   ├── Box: 遍历盒体范围内的体素
│   ├── Sphere: 计算球体范围内的体素
│   ├── Cylinder: 计算圆柱范围内的体素
│   └── 返回 TSet<FIntVector>
├── ValidateBatchEditParams(Request)
│   └── 验证参数有效性
└── ExecuteBatchEdit(AffectedVoxels, Request, World)
    └── 调用 BlockWorld->SetBlocks(...)

调用方式：
InteractComponent->RequestConfirmVoxelEdit()
  ↓
Request = StateComponent->GetTmpEditRequest()
  ↓
AffectedVoxels = UVoxelBatchEditTool::CalculateAffectedVoxels(
    Request,
    BlockSize
)
  ↓
// 捕获历史、执行编辑、记录历史（见 1.1）
```

**验收标准**：
- ✅ UVoxelBatchEditTool 只包含静态方法
- ✅ 无 UPROPERTY 状态成员
- ✅ 通过 Request 参数传递数据
- ✅ InteractComponent 调用工具方法
- ✅ 历史正确记录
- ✅ 删除 VoxelBatchEditManager

### 2.2 剪贴板工具（2 天）

**设计思路**：

```
UVoxelClipboardTool（无状态工具类）
├── CopyFromSelection(Selection, Origin, World)
│   ├── 遍历选择区域
│   ├── 读取方块类型（调用 BlockWorld->GetBlock）
│   ├── 计算相对坐标
│   └── 返回 FVoxelClipboardData
├── CutSelection(Selection, Origin, World)
│   ├── 调用 CopyFromSelection

│   └── 返回 FVoxelClipboardData
└── PasteToLocation(Clipboard, Location, Rotation, Flip, World)
    ├── 计算粘贴位置的绝对坐标
    ├── 应用旋转变换
    ├── 应用翻转变换
    └── 返回需要粘贴的方块列表（TMap<FIntVector, FVoxelBlockData>）

调用方式：
InteractComponent->RequestCopySelection()

Selection = StateComponent->CurrentSelection
  ↓
Clipboard = UVoxelClipboardTool::CopyFromSelection(
    Selection,
    CursorPosition,
    EditorModeSubsystem->GetBlockWorld()
)
  ↓
StateComponent->PlayerClipboard = Clipboard
  ↓
HistoryComponent->LogOperation({OperationType: Copy, Success: true})
```

### 2.3 粘贴操作（预览-确认流程）（2 天）

**设计思路**：

```
粘贴流程（统一的预览-确认）：

1. 用户按 Ctrl+V
   ↓
   InteractComponent->RequestPaste()
   ├── 读取 StateComponent->PlayerClipboard
   ├── 计算粘贴位置（鼠标位置）
   ├── StateComponent->TmpGeometry = 剪贴板几何
   │   ├── FirstP = Clipboard.Origin
   │   ├── SecondP = Clipboard.Origin + Clipboard.Size
   │   ├── Rotation = FRotator::ZeroRotator
   │   └── Scale = FVector::OneVector
   └── 开始预览

2. VisualComponent 显示预览
   ↓
   VisualComponent->UpdateBatchEditPreview(Request)

3. 用户调整（鼠标移动）
   ↓
   InteractComponent->UpdatePastePosition(NewPos)
   ├── 更新 StateComponent->TmpGeometry.Origin
   └── RequestUpdateVoxelPreview()

4. 用户调整旋转（按 R 键）
   ↓
   InteractComponent->RequestRotatePaste(DeltaRotation)
   ├── 更新 StateComponent->TmpGeometry.Rotation
   └── RequestUpdateVoxelPreview()

5. 用户调整翻转（按 F 键）
   ↓
   InteractComponent->RequestFlipPaste(Axis)
   ├── 更新 StateComponent->TmpGeometry.Scale（翻转对应轴）
   └── RequestUpdateVoxelPreview()

6. 用户确认（Enter）
   ↓
   InteractComponent->RequestConfirmVoxelEdit()
   ├── 捕获历史（BeforeState）
   ├── AffectedVoxels = UVoxelClipboardTool::PasteToLocation(...)
   ├── 执行粘贴
   ├── 捕获历史（AfterState）
   ├── HistoryComponent->SaveEditSnapshot(Command)
   ├── HistoryComponent->LogOperation({OperationType: Paste, ...})
   ├── HistoryComponent->UpdateStatistics(Command)
   └── ClearPreview()
```

## 🎯 关键设计要点

### 1. 职责清晰

| 组件 | 职责 | 存储的数据 | 不要存储 |
|------|------|----------|---------|
| **StateComponent** | 当前状态存储 | 模式、选择、剪贴板、TmpGeometry、蓝图收藏 | 历史、日志、统计 |
| **HistoryComponent** | 历史管理 | UndoStack、RedoStack、Logs、Stats | 当前状态、预览数据 |
| **InteractComponent** | 操作控制 | 临时输入数据 | 持久状态 |
| **VisualComponent** | 视觉渲染 | PreviewActor、Gizmo | 业务逻辑 |
| **工具类** | 无状态方法 | ❌ 不存储任何数据 | ❌ 无状态 |
| **EditorModeSubsystem** | 服务协调 | 工具类注册表（非玩家状态） | 玩家状态 |

### 2. 统一的预览-确认模式

```
所有编辑操作共用：
1. RequestStartVoxelPreview() - 开始预览
2. RequestUpdateVoxelPreview() - 更新预览
3. RequestConfirmVoxelEdit() - 确认编辑
4. RequestCancelVoxelEdit() - 取消编辑

每个操作都：
- 使用 TmpGeometry 存储预览数据
- 使用 VisualComponent 渲染预览
- 确认时记录历史到 HistoryComponent
- 确认时记录日志到 HistoryComponent
- 确认时更新统计到 HistoryComponent
```

### 3. 数据流

```
用户输入
  ↓
InteractComponent（处理输入）
  ↓ 读取
StateComponent（当前状态）
  ↓ 调用
工具类（无状态方法）
  ↓ 返回结果
StateComponent（更新 TmpGeometry）
  ↓ 通知
VisualComponent（更新预览）
  ↓ 确认
HistoryComponent（记录历史、日志、统计）
  ↓ 执行
BlockWorldSubsystem（修改世界）
```

### 4. 多玩家支持

- ✅ 每个玩家的 StateComponent 独立
- ✅ 每个玩家的 HistoryComponent 独立
- ✅ 每个玩家的 VisualComponent 独立
- ✅ 工具类是无状态的，可安全共享
- ✅ EditorModeSubsystem 只提供服务，不存储玩家状态
