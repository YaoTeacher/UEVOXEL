# 选区编辑系统拆分改造计划

> **目标**：
> 1. 拆分选区工具与编辑工具的状态机逻辑（选区松手即应用）
> 2. 复用已有编辑工具能力（Fill/Delete/Replace）作为选区操作
> 3. 新增剪切板系统（Copy/Cut/Paste）
>
> **设计原则**（参考 PS / Axiom）：
> - **选区是约束**，不是新工具。选区建立后，用户用"已有编辑工具"在选区内操作，选区只限制作用范围
> - **Fill/Delete/Replace 不是新工具**，是已有几何体编辑工具的"选区模式"
> - **Copy/Cut/Paste 是独立能力**，需要剪切板子系统支持

---

## 一、设计思路修正

### 1.1 错误设计（已废弃）

```
❌ 错误：Tool_Edit_Selection 作为独立工具，内部实现 Fill/Delete/Replace
   → 重复造轮子，与已有 Tool_Edit_SimpleGeometry 的编辑逻辑重叠
```

### 1.2 正确设计

```
✅ 正确：
   - 选区是全局约束（类似 PS 的选区蒙版）
   - 已有编辑工具（Tool_Edit_SimpleGeometry）检测到有选区时，仅在选区内操作
   - Copy/Cut/Paste 是独立的剪切板能力，不依赖工具类型
```

### 1.3 类比 Photoshop

| PS 概念 | 项目对应 |
|---------|---------|
| 选区工具（矩形选框/套索） | `Tool_Selection_*`（SimpleGeometry/Brush/Magic） |
| 选区建立后用画笔/填充/删除 | 用 `Tool_Edit_SimpleGeometry` 等编辑工具，自动约束在选区内 |
| Ctrl+C / Ctrl+X / Ctrl+V | 剪切板系统（独立快捷键，不依赖工具） |
| Ctrl+D 取消选区 | 清空 CurrentSelection |

## 二、核心设计

### 2.1 选区作为编辑约束

**关键改动**：已有编辑工具（`Tool_Edit_SimpleGeometry`）在执行 `RequestConfirmVoxelEdit` 时，检测 `StateComp->HasSelection()`：

- **有选区**：编辑操作仅作用于 `CurrentSelection` 内的体素
- **无选区**：编辑操作作用于 `TmpGeometry.Box` 定义的临时形状（当前逻辑）

### 2.2 状态机拆分

```
【选区工具（Tool_Selection.*）】
HIDDEN（有选区时显示移动 Gizmo）
  ↓ 点击空地
SELECTING（拖拽定义区域 / 笔刷涂抹）
  ↓ 松手
立即应用算法 → HIDDEN（可立即再选 / 可切换到编辑工具在选区内操作）

【编辑工具（Tool_Edit.*）】保持现状 + 选区约束
HIDDEN → BASE → EDIT → CONFIRM → HIDDEN
  ↑ 若 HasSelection()，CONFIRM 时仅修改选区内体素

【剪切板操作】独立快捷键，不依赖工具
Ctrl+C → CopySelection()
Ctrl+X → CutSelection()
Ctrl+V → PasteSelection()
```

### 2.3 数据流

```
[选区建立] → CurrentSelection（TArray<FIntVector>）
                ↓
    ┌───────────┴───────────┐
    ↓                       ↓
[已有编辑工具]           [剪切板操作]
在选区内执行              Ctrl+C/X/V
Fill/Delete/Replace
    ↓                       ↓
BatchModifyVoxelData     Copy/Cut/Paste
(仅作用于 CurrentSelection)
```

```cpp
void UVoxelControllerInteractComponent::ApplySelectionShapeImmediately()
{
    UVoxelControllerStateComponent* SC = GetControllerState();
    if (!SC) return;

    float BlockLength = 100.0f;
    if (UVoxelGameInstance* GI = GetWorld()->GetGameInstance<UVoxelGameInstance>())
        BlockLength = GI->WorldConfig.BlockLength;

    FVoxelEditRequest EditRequest = SC->GetCurrentEditRequest();
    TArray<FIntVector> EmptySelection;
    TArray<FIntVector> TempShape = UVoxelSelectionTool::CalculateSelection(
        EditRequest, BlockLength, EmptySelection, ESelectionOperationType::New);

    SC->ApplySelectionOp(TempShape, SC->GetSelectionMode());
    SC->ClearTmpGeometryTransform();
    SC->SetBuildPhase(EPreviewInteractionState::HIDDEN);
}
```

### 步骤 2：已有编辑工具增加选区约束

**目标**：`Tool_Edit_SimpleGeometry` 检测到有选区时，编辑仅作用于选区内。

**改动文件**：`VoxelControllerInteractComponent.cpp` 的 `RequestConfirmVoxelEdit`

**改动点**：在几何编辑分支（默认分支）前增加选区约束判断：

```cpp
void UVoxelControllerInteractComponent::RequestConfirmVoxelEdit()
{
    // ... 前置检查 ...

    FVoxelEditRequest EditRequest = SC->GetCurrentEditRequest();

    // 【选区工具分支保持不变】
    if (EditRequest.ToolTag.MatchesTag(FCoreTags::Tool_Selection)) { /* ... */ }

    // 【家具/模板分支保持不变】
    if (EditRequest.ToolTag.MatchesTag(FCoreTags::Tool_Edit_Furniture)) { /* ... */ }
    if (EditRequest.ToolTag.MatchesTag(FCoreTags::Tool_Edit_Template)) { /* ... */ }

    // 【新增】编辑工具 + 有选区 → 仅作用于选区内体素
    if (EditRequest.ToolTag.MatchesTag(FCoreTags::Tool_Edit) && SC->HasSelection())
    {
        ApplyEditWithinSelection(EditRequest);
        return;
    }

    // 【默认分支保持不变】无选区时走原流程
    FVoxelEditHistoryRecord HistoryRecord = UVoxelBatchEditTool::CreateHistoryRecord(EditRequest, BlockWorld);
    // ...
}
```

**新增方法** `ApplyEditWithinSelection`：
```cpp
void UVoxelControllerInteractComponent::ApplyEditWithinSelection(const FVoxelEditRequest& EditRequest)
{
    UVoxelControllerStateComponent* SC = GetControllerState();
    if (!SC || !SC->HasSelection()) return;

    AVoxelPlayerController* PC = GetOwner<AVoxelPlayerController>();
    UVoxelBlockWorldSubsystem* BlockWorld = PC ? PC->GetBlockWorldSubsystem() : nullptr;
    if (!BlockWorld) return;

    const TArray<FIntVector>& Selection = SC->GetCurrentSelection();

    // 根据 EditCommand 和 BlockType 对选区内体素执行操作
    FVoxelEditCommand EditCommand;
    EditCommand.PlacementMode = EditRequest.PlacementMode;
    EditCommand.SelectionMode = EditRequest.SelectionMode;

    // 批量修改：复用已有的 BatchModifyVoxelData(TArray<FIntVector>)
    BlockWorld->BatchModifyVoxelData(Selection, EditCommand, EditRequest.BlockType);

    // 记录历史
    UVoxelControllerHistoryComponent* HistoryComp = GetOwner()->FindComponentByClass<UVoxelControllerHistoryComponent>();
    if (HistoryComp)
    {
        // 构建选区操作的历史记录
        FVoxelEditHistoryRecord HistoryRecord;
        HistoryRecord.ToolTag = EditRequest.ToolTag;
        HistoryRecord.Description = FText::FromString(TEXT("选区内编辑"));
        HistoryRecord.Timestamp = FDateTime::Now();

        for (const FIntVector& Index : Selection)
        {
            int32 OldType = BlockWorld->GetBlockType(Index);
            int32 NewType = EditRequest.BlockType;
            // 根据 PlacementMode 调整
            if (EditRequest.PlacementMode == EVoxelPlacementMode::Complement && OldType != EBlockId::Air)
                continue; // 填充模式：跳过非空
            if (EditRequest.PlacementMode == EVoxelPlacementMode::Replace && OldType == EBlockId::Air)
                continue; // 替换模式：跳过空气

            HistoryRecord.Add(FVoxelEdit(Index, OldType, NewType));
        }

        if (HistoryRecord.Num() > 0)
        {
            HistoryComp->SaveHistoryRecord(HistoryRecord);
        }
    }

    // 重置编辑状态
    SC->ClearTmpGeometryTransform();
    SC->SetBuildPhase(EPreviewInteractionState::HIDDEN);

    UE_LOG(LogTemp, Log, TEXT("[EditChain] ApplyEditWithinSelection: %d voxels edited"), Selection.Num());
}
```

**效果**：
- 用户用 `Tool_Selection_SimpleGeometry` 框选一块区域
- 切换到 `Tool_Edit_SimpleGeometry`，选择方块类型和放置模式
- 拖拽编辑 → 编辑仅作用于选区内
- Fill = Normal 模式 + 指定方块
- Delete = Normal 模式 + Air
- Replace = Replace 模式 + 新方块类型

```cpp
#pragma once

#include "CoreMinimal.h"
#include "Voxel/Editor/VoxelHistoryData.h"  // FVoxelEdit
#include "VoxelClipboardData.generated.h"

/**
 * 体素剪切板数据
 * 存储从选区复制的体素数据，支持粘贴到任意位置
 *
 * 设计参考：
 * - PS 的剪切板：存储像素数据 + 原始尺寸
 * - Axiom 的 Clipboard：可旋转/翻转/保存为蓝图
 */
USTRUCT(BlueprintType)
struct FVoxelClipboardData
{
    GENERATED_BODY()

    /** 体素数据（位置相对于 SourceMin，存储 OldType=Air, NewType=实际类型） */
    UPROPERTY(VisibleAnywhere, BlueprintReadOnly, Category = "Voxel|Clipboard")
    TArray<FVoxelEdit> Voxels;

    /** 选区包围盒大小（X/Y/Z 维度） */
    UPROPERTY(VisibleAnywhere, BlueprintReadOnly, Category = "Voxel|Clipboard")
    FIntVector Size = FIntVector::ZeroValue;

    /** 复制时的选区 Min（世界索引，用于计算相对位置） */
    UPROPERTY(VisibleAnywhere, BlueprintReadOnly, Category = "Voxel|Clipboard")
    FIntVector SourceMin = FIntVector::ZeroValue;

    /** 是否有效 */
    bool IsValid() const { return Voxels.Num() > 0; }

    /** 清空 */
    void Clear()
    {
        Voxels.Empty();
        Size = FIntVector::ZeroValue;
        SourceMin = FIntVector::ZeroValue;
    }
};
```

### 步骤 4：实现 Copy/Cut/Paste

**改动文件**：`VoxelControllerInteractComponent.h/cpp`

**新增方法声明**：
```cpp
// ==================== 剪切板操作 ====================

/** 复制选区内容到剪切板 */
UFUNCTION(BlueprintCallable, Category = "Voxel|Interact|Clipboard")
void CopySelection();

/** 剪切选区（复制 + 删除原内容） */
UFUNCTION(BlueprintCallable, Category = "Voxel|Interact|Clipboard")
void CutSelection();

/** 粘贴剪切板内容到指定位置 */
UFUNCTION(BlueprintCallable, Category = "Voxel|Interact|Clipboard")
void PasteSelection(const FIntVector& TargetPosition);

/** 粘贴剪切板内容到鼠标位置 */
UFUNCTION(BlueprintCallable, Category = "Voxel|Interact|Clipboard")
void PasteAtMousePosition();
```

**实现**：

```cpp
void UVoxelControllerInteractComponent::CopySelection()
{
    UVoxelControllerStateComponent* SC = GetControllerState();
    if (!SC || !SC->HasSelection()) return;

    AVoxelPlayerController* PC = GetOwner<AVoxelPlayerController>();
    UVoxelBlockWorldSubsystem* BlockWorld = PC ? PC->GetBlockWorldSubsystem() : nullptr;
    if (!BlockWorld) return;

    const TArray<FIntVector>& Selection = SC->GetCurrentSelection();
    if (Selection.Num() == 0) return;

    // 计算选区 Min/Max
    FIntVector Min = Selection[0], Max = Selection[0];
    for (const FIntVector& Pos : Selection)
    {
        Min = FIntVector(FMath::Min(Min.X, Pos.X), FMath::Min(Min.Y, Pos.Y), FMath::Min(Min.Z, Pos.Z));
        Max = FIntVector(FMath::Max(Max.X, Pos.X), FMath::Max(Max.Y, Pos.Y), FMath::Max(Max.Z, Pos.Z));
    }

    // 复制体素数据到剪切板（相对位置）
    FVoxelClipboardData& Clipboard = SC->ClipboardData;
    Clipboard.Clear();
    Clipboard.SourceMin = Min;
    Clipboard.Size = Max - Min + FIntVector(1);
    Clipboard.Voxels.Reserve(Selection.Num());

    for (const FIntVector& Pos : Selection)
    {
        int32 BlockType = BlockWorld->GetBlockType(Pos);
        if (BlockType != EBlockId::Air)
        {
            FIntVector RelativePos = Pos - Min;
            // FVoxelEdit: BlockIndex 存相对位置, OldType=Air, NewType=实际类型
            Clipboard.Voxels.Add(FVoxelEdit(RelativePos, EBlockId::Air, BlockType));
        }
    }

    UE_LOG(LogTemp, Log, TEXT("[Clipboard] Copied %d voxels, size=%s, source=%s"),
        Clipboard.Voxels.Num(), *Clipboard.Size.ToString(), *Min.ToString());
}

void UVoxelControllerInteractComponent::CutSelection()
{
    UVoxelControllerStateComponent* SC = GetControllerState();
    if (!SC || !SC->HasSelection()) return;

    // 先复制
    CopySelection();

    // 再删除（用 Air 填充选区）
    AVoxelPlayerController* PC = GetOwner<AVoxelPlayerController>();
    UVoxelBlockWorldSubsystem* BlockWorld = PC ? PC->GetBlockWorldSubsystem() : nullptr;
    if (!BlockWorld) return;

    FVoxelEditCommand EditCommand;
    EditCommand.PlacementMode = EVoxelPlacementMode::Normal;
    BlockWorld->BatchModifyVoxelData(SC->GetCurrentSelection(), EditCommand, EBlockId::Air);

    UE_LOG(LogTemp, Log, TEXT("[Clipboard] Cut %d voxels"), SC->GetCurrentSelection().Num());
}

void UVoxelControllerInteractComponent::PasteSelection(const FIntVector& TargetPosition)
{
    UVoxelControllerStateComponent* SC = GetControllerState();
    if (!SC || !SC->ClipboardData.IsValid()) return;

    AVoxelPlayerController* PC = GetOwner<AVoxelPlayerController>();
    UVoxelBlockWorldSubsystem* BlockWorld = PC ? PC->GetBlockWorldSubsystem() : nullptr;
    if (!BlockWorld) return;

    const FVoxelClipboardData& Clipboard = SC->ClipboardData;

    // 构建粘贴位置和类型列表
    TArray<FIntVector> PastePositions;
    TArray<int32> PasteTypes;
    PastePositions.Reserve(Clipboard.Voxels.Num());
    PasteTypes.Reserve(Clipboard.Voxels.Num());

    for (const FVoxelEdit& Edit : Clipboard.Voxels)
    {
        FIntVector WorldPos = TargetPosition + Edit.BlockIndex;
        PastePositions.Add(WorldPos);
        PasteTypes.Add(Edit.NewType);
    }

    // 批量写入（按类型分组写入，或构建 Modification）
    // 简单实现：逐个类型写入
    FVoxelEditCommand EditCommand;
    EditCommand.PlacementMode = EVoxelPlacementMode::Normal;

    // 按类型分组批量写入（性能优化）
    TMap<int32, TArray<FIntVector>> TypeGroups;
    for (int32 i = 0; i < PastePositions.Num(); ++i)
    {
        TypeGroups.FindOrAdd(PasteTypes[i]).Add(PastePositions[i]);
    }

    for (const auto& Group : TypeGroups)
    {
        BlockWorld->BatchModifyVoxelData(Group.Value, EditCommand, Group.Key);
    }

    // 记录历史
    UVoxelControllerHistoryComponent* HistoryComp = GetOwner()->FindComponentByClass<UVoxelControllerHistoryComponent>();
    if (HistoryComp)
    {
        FVoxelEditHistoryRecord HistoryRecord;
        HistoryRecord.ToolTag = FCoreTags::Tool_Edit;
        HistoryRecord.Description = FText::FromString(TEXT("粘贴"));
        HistoryRecord.Timestamp = FDateTime::Now();

        for (int32 i = 0; i < PastePositions.Num(); ++i)
        {
            int32 OldType = BlockWorld->GetBlockType(PastePositions[i]);
            HistoryRecord.Add(FVoxelEdit(PastePositions[i], OldType, PasteTypes[i]));
        }

        if (HistoryRecord.Num() > 0)
        {
            HistoryComp->SaveHistoryRecord(HistoryRecord);
        }
    }

    UE_LOG(LogTemp, Log, TEXT("[Clipboard] Pasted %d voxels at %s"),
        PastePositions.Num(), *TargetPosition.ToString());
}

void UVoxelControllerInteractComponent::PasteAtMousePosition()
{
    // 获取鼠标射线命中位置
    APlayerController* PC = Cast<APlayerController>(GetOwner());
    if (!PC) return;

    FVector WorldLocation, WorldDirection;
    if (!PC->DeprojectMousePositionToWorld(WorldLocation, WorldDirection)) return;

    const FVector TraceEnd = WorldLocation + WorldDirection * TraceDistance;
    FHitResult GroundHit;
    FCollisionQueryParams Params;
    Params.bTraceComplex = true;

    const bool bGroundHit = GetWorld()->LineTraceSingleByChannel(
        GroundHit, WorldLocation, TraceEnd, ECC_GameTraceChannel1, Params);

    if (!bGroundHit) return;

    float BlockLength = 100.0f;
    if (UVoxelGameInstance* GI = GetWorld()->GetGameInstance<UVoxelGameInstance>())
        BlockLength = GI->WorldConfig.BlockLength;

    FIntVector TargetIndex = UChunkUtilsFunction::GetBlockIndexByPosition(GroundHit.Location, BlockLength);
    PasteSelection(TargetIndex);
}
```

## 五、用户操作流程示例

### 5.1 选区内填充

```
1. 选择 Tool_Selection_SimpleGeometry（矩形选区工具）
2. 拖拽框选一块区域 → 松手 → 选区建立（HIDDEN 状态）
3. 切换到 Tool_Edit_SimpleGeometry（几何体编辑工具）
4. 在 M1 选择方块类型（如石头）
5. 在 M2b1 选择放置模式（Normal = 覆盖）
6. 拖拽编辑（任意形状）→ 松手 → 编辑仅作用于选区内
   ※ 或者直接点确认按钮，整个选区被填充为石头
```

### 5.2 选区内删除

```
1. 框选区域
2. 切换到 Tool_Edit_SimpleGeometry
3. 选择方块类型 = Air（或专用删除按钮）
4. 点确认 → 选区内方块全部删除
```

### 5.3 选区内替换

```
1. 框选区域
2. 切换到 Tool_Edit_SimpleGeometry
3. 在 M2b1 选择 Replace 模式
4. 选择目标方块类型
5. 点确认 → 选区内所有非空方块被替换为新类型
```

### 5.4 复制粘贴

```
1. 框选区域
2. Ctrl+C → 选区内容复制到剪切板
3. 移动鼠标到目标位置
4. Ctrl+V → 粘贴剪切板内容到鼠标位置
```

### 5.5 剪切粘贴

```
1. 框选区域
2. Ctrl+X → 选区内容剪切到剪切板（原位置清空）
3. 移动鼠标到目标位置
4. Ctrl+V → 粘贴
```

## 六、风险与缓解

| 风险 | 缓解措施 |
|------|---------|
| 编辑工具拖拽形状与选区约束的交互不直观 | UI 提示"当前处于选区约束模式"，编辑范围限制在选区内 |
